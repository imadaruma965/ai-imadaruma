## 統治構造（2026-08-11改訂・最終版：四柱の是正＋AI仁子新設＋貿産省への統合）

> **経緯**: シンガポール統治機構の翻訳草案を出発点に、①「人格・内政・外交・財政」という`00_憲法府/constitution/four_pillars.md`の正しい四柱への是正、②雅称を廃したプレーン命名への統一、③法（韓非子）と監査（栄一）を対等並列にした律政省の新設、④人格教育をAIヤマトからAI仁子（仁子思想そのものの人格化）へ交代し尊徳は身体資本管理に純化、⑤「外政省」を「貿産省」へ発展的に改称し、坂本龍馬の統括下に地上リサーチ（ルパン）・思想研究（アショーカ）・ビジュアル制作（北斎）・発信文章（正篤）・技術（テスラ）を集約——という順で対話しながら確定した。

```
憲法府 …… 最高法規・理念（constitution / philosophy）

BOSS（いまだ唯仁）── 最終決定者・実行者
        │
        ├─ 執行官 AIスマートラビット（あだ名：スマラビ）…… 全ての壁打ち窓口／三省の戦略を一任・執務室で執務
        │         │
        │         ├─ 修身省 …… 人格・内政（マインド・身体）
        │         │      ├─ AI仁子 …… 人格・七徳の教育＋検証
        │         │      └─ AI尊徳 …… 身体資本管理（睡眠・食事・習慣）【仁子と並列】
        │         │
        │         ├─ 貿産省 AI坂本龍馬（統括） …… 作る・売る・届ける（外交・実業の一気通貫）
        │         │         ├─ AIルパン（地上リサーチ）
        │         │         ├─ AIアショーカ（思想研究）
        │         │         ├─ AI北斎（ビジュアル制作）
        │         │         ├─ AI正篤（発信文章制作）
        │         │         └─ AIテスラ（技術・科学者。他省への技術横断支援も維持）
        │         │
        │         └─ 財政省 AIルカ（パチョーリ） …… 収入・支出・請求漏れの実数追跡
        │
        ├─ 律政省 AI韓非子（法）＋AI栄一（監査）……【並列・対等】執行官・BOSSと同格。執行を律する側
        │
        └─ 図書館（ダヴィンチ図書館） AIダ・ヴィンチ …… 内閣付き・独立。AI-imadarumaの「脳」＝知の貯蔵庫
```

**原則:**

- **憲法府**が最上位。各省法・運用はすべてその下位
- **BOSS**が最終決定者・実行者。AIは決定を代行しない
- **四柱は「人格・内政・外交・財政」**（`00_憲法府/constitution/four_pillars.md`が正本）。法は四柱に含まれない
- **執行官（スマラビ）**は、決めると実行を分離するシンガポール型の要として、**修身省・貿産省・財政省の三省の戦略を一任される**。各省は実行に専念し、独自の戦略は立てない
- **修身省**は「人格」と「内政」の両柱を担う。**AI仁子（新設）とAI尊徳の並列体制**——仁子が人格・七徳を形作り・検証し、尊徳が身体資本（睡眠・食事・習慣）を管理する。上下関係はない
- **貿産省（龍馬統括）**は「外交」の柱の実行部隊。史実の海援隊（仲介屋である前に貿易商社だった）に倣い、**リサーチ（ルパン・アショーカ）→制作（北斎・テスラ）→発信（正篤）→対外実務（龍馬）**を一つの指揮系統でつなぐ。「何を作り、どう売り、どう届けるか」を一気通貫で担う
- **財政省（ルカ）**は経産（売り設計）と分離した**受注後**の実数追跡
- **律政省（韓非子＋栄一）は、執行官・BOSSと並列の独立機関**。韓非子＝法を作る専門（これからを律する・事前点検）、栄一＝客観的な検証と審査機関（やったことを律する・事後の義利監査）。**両者は対等な並列体制**。栄一には**一時停止勧告権**がある：義利に反すると判定した実行に対し、勧告から48時間、BOSSのレビューを経るまで一時停止とする（恒久化の権限はなく、最終判断は常にBOSS）
- **緊急バイパス規定**：執行官からの応答・意思決定が48時間以上滞留した場合、各省リーダー（仁子・尊徳・ルカ・龍馬）はBOSSへ直接エスカレーションしてよい
- **図書館（ダ・ヴィンチ）**は内閣付き・独立。AI-imadaruma全体の「脳」として、各省・律政省の記録を横断的に観察・貯蔵・編集する。貿産省（ルパン・アショーカ）が集めた知も、恒久的な蔵書としてここに集約される
- **雅称（修身院・勘定所・律令院・海援隊等）は正式な構造名として採用しない**。理由は、本国家OSの野望が「世界の国・個人が模範にしたくなる国家組織を作ること」にあり、シンガポールが世界的モデルになれたのは徹底したプレーン命名による輸出可能性の高さゆえと判断したため。独自性は部門名の飾りではなく、四柱統治フレームワークという理論そのもの、歴史上の人格の配置、そして「仁子」という国家固有の思想人格に宿る。雅称は対外発信でのみ、物語のスパイスとして任意に使ってよい
- 改定メモ: `01_内閣府/cabinet_revision_info_ministry_research_2026-08-08.md`（2026-08-08適用）。四柱是正・律政省新設・プレーン命名統一・AI仁子新設・貿産省統合は、いずれも2026-08-11適用

| 貿産省（龍馬） | 週次新規接触件数／リサーチ着手→発信までのリードタイム |

| 図書館（ダ・ヴィンチ） | 月次アーカイブ更新件数／索引整備率 |

### 運営ルール（2026-08-11追加確定）

BOSSとの対話で、健全な運営のために3点を確定した。

1. **律政省の定例会参加**：律政省（韓非子・栄一）は、執行官の朝会議に**客観的アドバイス部門として参加する**。役割は2つ——**①昨日の振り返り担当**（前日の実行が義利・規約に照らして問題なかったかの検証）、**②今日の目標設定時の客観的アドバイス**（これから執行官が立てる戦略・タスクへの事前点検）。韓非子＝これから（今日の目標設定）、栄一＝やったこと（昨日の振り返り）、という時間軸の役割分担がそのまま定例会にも反映される
2. **エスカレーションの基準**：律政省・執行官間で判断が割れた場合、**一定基準以下は執行官の裁定で足りる**とする（毎回BOSSまで上げない）。基準の具体的な線引き（金額・リスク度・戦略への影響度など）はまだ精緻化されていない。運用しながら執行官・律政省・BOSSで基準を明文化していくことを推奨する
3. **新設の条文の保管先**：新しいAI人格・省を新設する際の手続き（正本ファイル・Skill・ai_jurisdiction.mdへの反映・旧表記チェック等のチェックリスト）は、**律政省が保管する**。法と規律を扱う省として、内閣の「新設ルール」そのものの管理にも適任という判断による。詳細チェックリストは `02_律政省/agent_charter.md`（新規・律政省管理）に置く

### 未実装・次の一手（引き継ぎ）

1. **貿産省（6名体制）の意思決定速度は未検証**——龍馬統括の下にルパン・アショーカ・北斎・正篤・テスラが集まった。上記KPIで運用1ヶ月後に見直す
2. **律政省の「理論（韓非子）／実務（李斯）」という役割分担は見送り継続**。AI李斯という人格・正本ファイルはまだ存在しない
3. **フォルダの物理的なリネーム**（`01_内閣府/`→`内閣府/`等）は本改訂では行っていない。全ファイルの相互参照パスに影響する大きな作業のため、別Phaseとしてテスラと安全な移行手順を組むことを推奨する

```

  ↓
律政省（韓非子・栄一）: スマラビの戦略・R&Dテーマの法的リスク・義利を検証（一時停止勧告権あり）
  ↓

  ↓
貿産省（龍馬統括・ルパン・アショーカ）: リサーチ・研究 → 省内の北斎・テスラ・正篤へ渡す
  ↓
貿産省（龍馬統括・北斎・テスラ・正篤）: 制作（アプリ・システム・デザイン）・発信・仕事の輸入・応募・交渉・輸出実務
  ↓
図書館（ダ・ヴィンチ）: 貿産省が集めた知を横断的に貯蔵・編集（並行して継続）
  ↓

  ↓

  ↓
財政省（ルカ）: 受注後の実数（該当時）
  ↓（戦略見直し）
律政省 → 執行官スマラビ: ロードマップ更新
  ↓
```
