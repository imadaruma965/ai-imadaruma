# 内閣運用図 — 組織・格納・指示・プロジェクト

> **作成**: 2026-08-08  
> **位置づけ**: `ai_jurisdiction.md`（誰が主管か）の**使い方マニュアル**  
> **目的**: 「省庁が多くて難しい」を、毎日の判断に落とす

---

## 0. 先に一言（差別化と難しさはセット）

会社の「AIエージェントを並べる」トレンドに対し、この国づくりは違う。

| よくあるAIエージェント | いまだ国家OS |
|------------------------|--------------|
| ツール／ボットを増やす | **役割と憲法の下で動かす** |
| 何でも1チャットに頼む | **省に振り、記録が残る** |
| 成果物が散らばる | **フォルダ＝官庁の書庫** |

だから面白いし、だから難しい。難しく感じる主因は「人格が多い」ことより、

1. **レイヤーが3つある**（憲法／AI内閣／旧ドメイン六省）  
2. **毎日使う省と、たまに使う省が混ざっている**  
3. **ファイル置き場とSkillパスが歴史的にバラけている**  

下の運用図は、この3つを日常では意識しなくて済むようにするためのもの。

---

## 1. 組織図（毎日見る版・簡略）

```text
BOSS（決める・実行する）
  └─ 執行官・賢いうさぎ（朝会議・振り分け・進捗の見える化）
        │
        ├─【表の稼ぎ】経産・栄一 …… 何を売るか
        │            外務・龍馬 …… 誰に届ける・応募・交渉
        │            財務・ルカ …… 受注後の数字
        │
        ├─【体と人格】内務・尊徳 …… 体・習慣・今日の兵站
        │            教育・ヤマト …… 七徳・内省
        │
        ├─【知と表現】情報 …… 集める・渡す（交渉しない）
        │            文化 …… 文・画・音にする
        │
        └─【装置と法】科学・テスラ …… 自動化・アプリ
                     法務・韓非子 …… 規約・リスク
```

**覚え方（4ブロックだけ）**

1. 稼ぐ（経産・外務・財務）  
2. 整える（内務・教育）  
3. 知る・見せる（情報・文化）  
4. 支える（科学・法務）  

執行官はブロックをまたぐ「交通整理」だけ。各省の中身は奪わない。

---

## 2. 仕事の流れ（フローチャート）

### 基本形（1案件・1テーマ）

```text
① BOSS or 執行官がテーマを一言で置く
        ↓
② 執行官が「どのブロック？」を決める（下の早見表）
        ↓
③ 主管の省に Skill / Remote Control で指示
        ↓
④ 成果は「その省のフォルダ」か図書館に残す
        ↓
⑤ 他省が必要なら「申し送り」だけ（主管は動かさない）
        ↓
⑥ BOSSが承認・実行（応募・公開・請求など）
```

### 稼ぎの流れ（いまの主力）

```text
経産：商品階段・価格・勝ち筋
  ↓
情報：リサーチ原料を渡す
  ↓
外務：応募・交渉・輸出実務
  ↓
文化：必要なら稿・ビジュアル
  ↓
内務：体を壊さない日程
  ↓
財務：受注後の実数
```

科学は装置（Gmail→Sheet等）。法務は危ない自動化の前に一声。

## 3. 早見表 — 「誰に指示するか」

迷ったら**この表だけ**見る。

| いま聞きたいこと | 指示先 |
|------------------|--------|
| 何を売るか・単価・やらない戦 | **栄一** |
| 応募文・交渉・仕事の取り方 | **龍馬** |
| 市場・競合・案件の調査 | **ルパン**（整理はダ・ヴィンチ） |
| 思想・自己統治の研究 | **アショーカ** |
| 投稿文・Kindle・対外コピー | **正篤** |
| ビジュアル・世界観の見た目 | **北斎** |
| 今日の体・習慣・15分タスク | **尊徳** |
| 七徳・内省の設計 | **ヤマト** |
| 自動化・Sheets・Remote・アプリ | **テスラ** |
| 規約・スクレイピング可否 | **韓非子** |
| 入金・請求漏れ | **ルカ** |
| 朝の全体・振り分け | **賢いうさぎ** |
| Wantedly／ランサーズの文面正本 | ファイルは `01_内閣府/対外プロフィール/`（作業は正篤or龍馬） |

**禁止の混線（よくある失敗）**

- 情報に「応募して」→ ×（外務）  
- 内務に「売上ノルマ」→ ×（経産の設計／外務の実務）  
- 経産に「コード書いて」→ ×（科学／Cursor実装）

## 4. ファイルの格納ルール（シンプル版）

### 原則

```text
省のフォルダ ＝ その省の書庫
図書館（ダヴィンチ）＝ 長く残す知・リサーチ原本
首相官邸 ＝ 内閣の正本・BOSSの対外面・執行官
律令府 ＝ 触らない（最高法規）
```

### 何をどこに置くか

| 種類 | 置き場 |
|------|--------|
| 役割・主管の定義 | `01_内閣府/ai_jurisdiction.md` |
| 対外プロフィール・職歴 | `01_内閣府/対外プロフィール/` |
| 戦略・価格・ロードマップ | `00_律令府/strategy/` |
| 今日の実行・習慣 | `03_修身省/daily_governance/` |
| 外交・応募の実務メモ | `04_貿易省/` |
| 自動化・アプリ・docs | `04_貿易省/` |
| リサーチ原本・対話蔵書 | `08_情報省/ダヴィンチ図書館/` |
| **Cursorの重要壁打ち（決定・設計・対外文）** | **すべて** `ダヴィンチ図書館/05_AI対話/Cursor/`（他へ原本を置かない） |
| 人格プロンプト（誰として話すか） | 各省の `栄一.md` 等＋ `.claude/skills/` |

### ファイル名の方針

- **人が読む正本** → 日本語でよい（対外プロフィールは実施済み）  
- **Skillがパス参照する英名** → いきなり全部改名しない（壊れる）。索引で日本語対応表を置く（strategy/README 実施済み）  
- 新規はできるだけ `テーマ_YYYY-MM-DD.md`

## 5. 指示の出し方（型）

Remote Control / Claude Code では、毎回この型で十分。

```text
【宛先】（例：龍馬）
【目的】一文
【成果物】ファイルパス or 「チャット内で結論」
【制約】やらないこと・期限・予算
【参照】読むファイルを最大3つまで
```

例:

```text
【宛先】ルパン
【目的】副業クラウド向けの競合職種ラベルを3つ調べる
【成果物】表で返す（図書館保存はダ・ヴィンチに申し送り）
【制約】交渉しない・応募しない
【参照】01_内閣府/対外プロフィール/00_索引.md
```

執行官に朝やるなら:

```text
【宛先】賢いうさぎ
【目的】今日の一点突破を1つに絞る
【成果物】今日の15分×3と、振る省
【制約】新規事業を増やさない
【参照】today.md / roadmap の今週欄だけ
```

## 6. プロジェクトの持ち方（いまの国）

「省＝常設の役割」「プロジェクト＝期限付きの旗」と分ける。

| プロジェクト例 | 主担当 | 協力 | 成果の置き場 |
|----------------|--------|------|--------------|
| Instagram成長（@imada.rabbit） | 経産（方針） | 情報・文化・北斎 | strategy + 図書館 Instagram |
| 仕事メール→Sheet→Top20 | 科学 | 情報（原料）・外務（閲覧） | `04_貿易省/産業庁/docs/` |
| Wantedly／副業クラウド登録 | 外務（実務） | 官邸プロフィール正本 | `対外プロフィール/` |
| Kindle／自己統治コンテンツ | 文化・正篤 | アショーカ（研究） | 図書館＋出版欄 |
| 統治手帳機能追加 | 科学 | 経産（要件） | taskboard |
| 体・睡眠・食事の内政 | 内務 | 教育（人格） | daily_governance |

**ルール**: プロジェクトの主担当は**1省だけ**。他は協力。主がいないプロジェクトは作らない。

## 7. 運用を簡単に保つコツ（BOSS向け）

1. **毎日使うのは4人まで** — 執行官・尊徳・栄一・（外務 or 情報のどちらか）  
2. **残りは呼ばれたときだけ** — 全大臣を毎回起動しない  
3. **ファイルを増やす前に索引を見る** — 対外プロフィール／strategy README  
4. **迷ったら管轄正本** — `ai_jurisdiction.md` の「しないこと」  

省庁が多いのは弱点ではなく、**呼び分けられること自体が商品（Brand Architect／国家OS）のデモ**になる。ただし日常は4人運用で足りる。
