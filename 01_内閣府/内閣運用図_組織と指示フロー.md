> **v4（2026-09-21）**: 13体制から6体制へ簡素化した。主管の正本は `01_内閣府/AI主管定義.md`、作業ルールは `CLAUDE.md`。本ファイルは「誰に何を頼むか」と「指示の出し方」の運用メモ。

## 1. 指揮系統

```
BOSS（最終決定・実行）
  ├─【法】00_律令府/点検リスト.md …… 人格を置かない。公開・発注・価格・自動化の前に走らせる
  └─【執行】執行官スマラビ（壁打ちの窓口・戦略・収支）
        ├─ フランクリン（修身省）…… 体・習慣・15分タスク・七徳の検証
        ├─ 坂本龍馬（貿易省・統括）…… 売る・届ける
        │     ├─ テスラ（産業庁）…… 作る・自動化する
        │     └─ 北斎／文筆官（文化庁）…… 見せる・書く
        └─ ダ・ヴィンチ（情報省）…… 調べる・研究する・貯める・編む
```

## 2. 早見表 — 誰に指示するか

迷ったら**この表だけ**見る。

| いま聞きたいこと | 指示先 |
|---|---|
| 朝の全体・今日の一点突破・振り分け | **賢いうさぎ** |
| 入金・請求漏れ・今月の見込み | **賢いうさぎ**（旧・ルカ） |
| 何を売るか・単価・やらない戦 | **賢いうさぎ**（点検は点検リスト） |
| 応募文・交渉・仕事の取り方 | **龍馬** |
| 市場・競合・案件の調査、思想・自己統治の研究 | **ダ・ヴィンチ**（旧・ルパン／アショーカ） |
| 投稿文・Kindle・対外コピー | **文筆官（正篤）** |
| ビジュアル・世界観の見た目 | **北斎** |
| 今日の体・習慣・15分タスク・七徳 | **フランクリン**（旧・尊徳／仁子） |
| 自動化・Sheets・Remote・アプリ | **テスラ** |
| 規約・薬機法・景表法・スクレイピング可否・価格の義利 | **`00_律令府/点検リスト.md`**（旧・韓非子／栄一） |
| Wantedly／ランサーズの文面正本 | ファイルは `01_内閣府/対外プロフィール/`（作業は文筆官 or 龍馬） |

**よくある混線**

- ダ・ヴィンチに「応募して」→ ×（龍馬）
- フランクリンに「売上ノルマ」→ ×（執行官の設計／龍馬の実務）
- 龍馬に「コード書いて」→ ×（テスラ）

## 3. ファイルの格納ルール

```text
省のフォルダ ＝ その省の書庫
図書館（ダヴィンチ図書館）＝ 長く残す知・リサーチ原本
内閣府 ＝ 内閣の正本・BOSSの対外面・執行官
律令府 ＝ 最高法規と点検（勝手に触らない）
```

| 種類 | 置き場 |
|---|---|
| 役割・主管の定義 | `01_内閣府/AI主管定義.md` |
| 対外プロフィール・職歴 | `01_内閣府/対外プロフィール/` |
| 戦略・価格・ロードマップ | `00_律令府/戦略/` |
| 今日の実行・習慣 | `02_修身省/日次運用/` |
| 営業・制作・自動化の実務 | `03_貿易省/` |
| 調査の作業原料 | `05_情報省/調査記録/` |
| リサーチ原本・対話蔵書 | `05_情報省/ダヴィンチ図書館/` |
| 人格プロンプト | 各省の人格正本 ＋ `.claude/skills/` |

新規ファイルは `テーマ_YYYY-MM-DD.md`。**増やす前に索引を見る**。

## 4. 指示の出し方（型）

```text
【宛先】（例：龍馬）
【目的】一文
【成果物】ファイルパス or 「チャット内で結論」
【制約】やらないこと・期限・予算
【参照】読むファイルを最大3つまで
```

例：

```text
【宛先】ダ・ヴィンチ
【目的】副業クラウド向けの競合職種ラベルを3つ調べる
【成果物】表で返す（出所と確度つき）
【制約】交渉しない・応募しない
【参照】01_内閣府/対外プロフィール/00_索引.md
```

```text
【宛先】賢いうさぎ
【目的】今日の一点突破を1つに絞る
【成果物】今日の15分×3と、振る先
【制約】新規事業を増やさない
【参照】今日.md ／ ロードマップの今週欄だけ
```

## 5. プロジェクトの持ち方

「省＝常設の役割」「プロジェクト＝期限付きの旗」と分ける。**主担当は1人だけ**。主がいないプロジェクトは作らない。

| プロジェクト例 | 主担当 | 協力 |
|---|---|---|
| X／Substack／Instagram の発信 | 文筆官 | 北斎・ダ・ヴィンチ・執行官（ブランド声） |
| 仕事メール→Sheet→上位抽出 | テスラ | ダ・ヴィンチ（原料）・龍馬（閲覧） |
| Wantedly／副業クラウド登録 | 龍馬 | 内閣府のプロフィール正本 |
| Kindle／自己統治コンテンツ | 文筆官 | ダ・ヴィンチ（研究） |
| 任務盤の機能追加 | テスラ | 執行官（要件） |
| 体・睡眠・食事の内政 | フランクリン | — |

## 6. 運用を簡単に保つコツ

1. **毎日使うのは2〜3人まで** — 執行官・フランクリン ＋ その日の実務担当1人
2. **簡単な作業では人格を呼ばない**（`CLAUDE.md` §0）
3. **ファイルを増やす前に索引を見る**
4. **迷ったら主管正本の「しないこと」** — `01_内閣府/AI主管定義.md` §3
5. **人格を増やしたくなったら、まず既存の誰かに寄せる**（増やすなら `00_律令府/新設チェックリスト.md`）
