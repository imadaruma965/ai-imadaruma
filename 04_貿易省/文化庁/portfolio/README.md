## Canvaでの編集方法

1. Canvaのホーム画面で「デザインを作成」→「ファイルをインポート」を選択
2. `..._v3_Canva編集用.pptx` をアップロード
3. 文字、図形、写真を必要に応じて編集
4. 完成後はPDF（標準）で書き出し
