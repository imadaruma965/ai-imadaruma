## 実際に開いて確認した構成パターン（2026-08-12・2件サンプル閲覧）

29件中2件を実際に開き、ページ構成・表紙デザインを確認した。全件は未閲覧だが、共通する型が見えたので記録する。

### 表紙（1ページ目）の型

2パターンあった。どちらも「役割ラベル＋名前＋PORTFOLIO」という最小要素は共通。

1. **抽象グラデーション型**（MIYUKI NAKAJIMA例）: 淡いブルー系グラデーション背景 + 「SNS運用代行」（役割）+ 大きな氏名（ローマ字）+ 「PORTFOLIO」の4要素のみ。写真なし、静かで上品な印象
2. **実写ライフスタイル型**（荒川彩例）: コーヒーカップ・ノートなど雰囲気のある実写を背景に、「PORTFOLIO」+「インスタグラム運用代行」（役割）+ 氏名（漢字）。温かみ・親しみやすさを演出

**共通点**：表紙だけで「誰が」「何の代行か」が一瞬で分かる。文章での自己紹介はしない。

### 全体構成（MIYUKI NAKAJIMA例・上部タブで確認できた12セクション）

```
Title → index（目次）→ 自己紹介 → Mission → サービス内容
→ 全体概要 → 競合分析 → 戦略イメージ → 投稿企画例 → 投稿デザイン例
→ スケジュール → まとめ
```

これは `profile_writing_guide.md` の「目指したい流れ（①何を提供する人か→②価値→③経験→④運用方法→⑤対応業務→⑥稼働時間）」と一致する構成。ポートフォリオでは、この流れを**ページ単位に展開**していると理解してよい。

### スキル欄の見せ方（今回の確認観点）

`profile_writing_guide.md` 第8項の通り、スキル単体の羅列ページよりも、「競合分析」「戦略イメージ」「投稿企画例」など**思考プロセスが見えるページ構成**が中心だった。スキルは各ページの中で「使った結果」として自然に登場する形。

> 未確認の残り27件についても、時間のある時に数件ずつ開いて構成のバリエーションを拾い足すとよい。特に「競合分析」「投稿デザイン例」ページの作り方は、実物を見ないと再現しにくい。
