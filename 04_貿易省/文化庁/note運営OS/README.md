# note運営OS

`賢いうさぎ｜AIで自分と仕事を再設計する` のための日次リサーチ・下書き在庫管理システム。

## 毎日の流れ

1. `note伸び記事レーダー` が公開メタデータを更新し、Google SheetsとローカルJSONへ保存する。
2. 下書き・確認待ちの在庫を数える。
3. Claude Codeのクラウド・ルーティンが6:30に在庫を確認する。
4. 在庫が7本未満なら、ダヴィンチ図書館と市場データを読み、1本だけ下書きを作る。
5. 本人が体験、意見、数字、事実を加筆・確認する。
6. 月・水・金を目安にnoteで予約または公開する。

自動化するのは下書き作成まで。noteへの投稿・公開は行わない。

## 手動確認

リサーチやAI生成を実行せず、在庫判定だけ確認する。

```bash
node 04_貿易省/文化庁/note運営OS/scripts/daily-note-production.cjs --dry-run
```

リサーチ済みデータから、在庫数に関係なく下書きを1本作る。

```bash
node 04_貿易省/文化庁/note運営OS/scripts/daily-note-production.cjs --skip-research --force
```

## 自動実行

次のスクリプトでmacOSのLaunchAgentへ登録する。毎朝6:00にGoogle Sheetsとローカルの市場リサーチだけを更新し、下書き生成は6:30のClaude Codeクラウド・ルーティンに委任する。

```bash
zsh 04_貿易省/文化庁/note運営OS/scripts/install-launch-agent.sh
```

実行ログは `90_実行ログ/` に保存される。Macが停止している間は実行できないため、毎朝の実行時刻にはログイン・起動しておく。

## 在庫の数え方

`02_下書き` と `03_確認待ち` にあるMarkdown原稿を在庫として数える。公開準備へ移すと在庫から外れるため、翌日の自動実行で新しい下書きが補充される。
