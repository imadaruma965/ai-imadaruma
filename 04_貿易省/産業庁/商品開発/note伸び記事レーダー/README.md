# note伸び記事レーダー

noteの公開ページから、最近反応が伸びている記事候補を最大50件選び、Google Sheetsへ記録する個人リサーチツール。

## 重要な定義

- **初回実行**: 現在のスキ数、フォロワー数、公開後時間、スキ／日などから暫定ランキングを作る。
- **2回目以降**: 前回との差からスキ増加、フォロワー増加、時間当たり伸び率を計算する。
- note公式は全体ランキングを提供せず、読者別レコメンドを重視している。このツールの順位は「設定したテーマ内の観測順位」であり、note全体の公式順位ではない。

## 取得方針

- 公開ハッシュタグページ、公開記事メタデータ、公開プロフィールだけを低頻度で参照する。
- 記事本文、有料部分、フォロワー一覧、非公式API、`/search` は取得しない。
- robots.txtで除外されるパスはプログラム側でも拒否する。
- 発見ページは標準で1リクエスト1.4秒待機する。候補50件へ絞った後のプロフィール確認だけ最大4並列とし、短時間で終了させる。

## 標準の観測テーマ

`AI活用`、`起業`、`副業`、`仕事術`、`自己啓発`、`note収益化`

テーマは `--source` を繰り返して変更できる。

## 実行

リポジトリのルートから:

```bash
node 04_貿易省/産業庁/商品開発/note伸び記事レーダー/note-radar.cjs --dry-run
```

Google Sheetsへ書き込む:

```bash
node 04_貿易省/産業庁/商品開発/note伸び記事レーダー/note-radar.cjs
```

既定では、[note伸び記事分析](https://docs.google.com/spreadsheets/d/1ivU9yTi0cxA1jp6mybSZyb3K93A5X8BAqYoOHLgVuuY/edit)に次の2タブを書き込む。

- `note最新TOP50`: 毎回最新結果で置換
- `note観測履歴`: 毎回の結果を追記

別のスプレッドシートを使う場合:

```bash
node 04_貿易省/産業庁/商品開発/note伸び記事レーダー/note-radar.cjs \
  --spreadsheet-id YOUR_SPREADSHEET_ID
```

サービスアカウントのメールアドレスを対象スプレッドシートの編集者として共有すること。認証JSONはGitへ入れない。

## 主なオプション

```text
--limit 50
--max-age-days 30
--delay-ms 1400
--source AI活用 --source 起業
--no-sheets
--dry-run
--spreadsheet-id ID
--output-json /保存先/latest.json
--service-account /安全な場所/credentials.json
```

`--dry-run` はSheetsも観測状態も更新しない。`--no-sheets` はSheetsだけ省略し、次回比較用の状態は更新する。

## シートの分析項目

観測日時、順位、伸びスコア、タイトル、URL、著者、公開日時、公開後時間、スキ数、スキ増加、スキ／日、フォロワー数、フォロワー増加、スキ÷フォロワー、テーマ、タイトル型、対象読者、数字・括弧の有無、有料価格、発見元。

タイトル分析は公開タイトルだけを使った簡易分類であり、記事内容の良し悪しを断定しない。

## 推奨頻度

1日1回、同じ時刻に実行する。初回は基準値、翌日から本当の「伸び」が見える。短時間に何度も実行しない。

## テスト

```bash
node --test 04_貿易省/産業庁/商品開発/note伸び記事レーダー/test/core.test.cjs
```
