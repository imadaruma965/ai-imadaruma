# ページ撮りPDF（macOS）

**電子書籍のページを自動撮影し、一冊のPDFにまとめるMacツール。**

Mac版Kindleのウィンドウ全体を1ページずつ撮影し、矢印キーでページを送り、最後に画像PDFへまとめます。開始ページで右綴じ・左綴じを自動判定してから撮影を始めるため、縦書き・右開きの本でも操作なしで進みます。矢印キーを押しても画面が変わらない状態が3回続くと、念のため逆方向のキーを1回だけ試し、それでも変わらなければ最終ページと判定します。

ご自身が正当に利用できる書籍を、許可された範囲で扱ってください。作成したPDFの共有・配布や、DRMの回避を行うツールではありません。

## ワンクリック一括処理

[`この本を進める.command`](./この本を進める.command) をダブルクリックすると、次を順番に実行します。

1. Kindleのページを撮影してPDF化
2. OCRでテキスト化
3. Claude Codeで書籍を要約し、今田唯仁向けの提案を作成
4. PDFを `~/Documents/電子書籍原本/自己啓発・習慣/` へ保存
5. 要約をダヴィンチ図書館の `00_受信箱/書籍要約/` へ保存

起動後に書名と著者名を入力し、Kindleで対象書籍の最初のページを表示してください。初回のみ必要なPython環境を自動準備します。macOSに止められた場合は、ファイルを右クリックして「開く」を選びます。

既にPDFがある場合は、そのPDFを `この本を進める.command` へドラッグ＆ドロップすると、撮影を省略してOCR以降を実行できます。

コマンドラインから処理内容だけ確認する場合:

```bash
python3 book_pipeline.py --dry-run --title "書名"
```

## 準備

ターミナルでこのディレクトリへ移動し、仮想環境と依存パッケージを用意します。

```bash
cd 04_貿易省/産業庁/商品開発/ページ撮りPDF
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

AI要約を使う前に、初回だけClaude Codeへログインしてください。

```bash
claude
```

Claude Codeが起動したら `/login` を実行し、画面の案内に沿って認証します。未ログインの場合でも、PDF保存・OCR・エラー記録までは自動で残ります。

macOSの「システム設定 → プライバシーとセキュリティ」で、使用するターミナル（Terminal、iTerm、IDEなど）に次を許可してください。

- アクセシビリティ（Kindleへキーを送るため）
- 画面収録（スクリーンショットのため）

## 実行

1. Kindleで対象の本を開き、1ページ表示にする。
2. 最初に収録したいページを表示する。
3. Kindleウィンドウの上に別のウィンドウが重ならないようにする。
4. 次を実行する。

```bash
python kindle_to_pdf.py --output ~/Desktop/book.pdf --keep-images
```

5秒後に撮影が始まります。実行中はKindleや他のアプリを操作しないでください。緊急停止する場合は、マウスポインターを画面の左上隅へ動かします。`Control+C`でも停止できます。停止時点までの画像からPDFが作成されます。

動作確認後、ページ画像が不要なら `--keep-images` を外せます。

## 主な調整項目

```bash
python kindle_to_pdf.py \
  --output ~/Desktop/book.pdf \
  --page-delay 1.5 \
  --change-timeout 10 \
  --same-checks 3 \
  --threshold 0.8 \
  --skip-focus-click \
  --keep-images
```

- 読み込みが遅い本では `--page-delay` や `--change-timeout` を増やします。
- 最終ページで微小な描画変化が続いて止まらない場合は `--threshold` を少し増やします（例: `1.5`）。
- ページ変化が小さい本で誤停止する場合は `--threshold` を減らします（例: `0.3`）。
- 本文中央の自動クリックでページフリップ（目次プレビュー）が開く場合は、通常の本文表示へ戻してから `--skip-focus-click` を指定します。
- 念のため最大5000ページで停止します。`--max-pages` で変更できます。
- `--page-key` は既定で `auto`（自動判定）です。開始ページで右・左の両方向に試し送りし、実際に画面が動いた方向を採用します。判定がうまくいかない本では `--page-key right` または `--page-key left` で固定できます。
- 撮影中に矢印キーを押しても `--same-checks` 回連続で画面が変わらなかった場合、最終ページと判定する前に逆方向のキーを1回だけ試します。それで画面が動けば、以降はその方向で撮影を継続します（本の途中で操作方向が変わることは通常ありませんが、開始ページでの判定ミスに対する保険です）。

最初は数ページだけの資料で動作確認し、PDFとページ順を確認してから長い本に使うことを推奨します。
