## 保管ルール

- **小さな単体ツール**: 本フォルダに置く。
- **独立アプリ・販売サービス**: 一商品一Gitリポジトリを原則とし、本台帳には場所と状態だけを記録する。
- **国家運営の内部システム**: 利用中の場所を維持する。販売版を作るときに、個人データ・国家設定・秘密情報を含まない商品版へ分離する。
- **企画・市場調査・価格・販売計画**: 貿易省の戦略文書として管理する。
- **再利用する知識**: ダヴィンチ図書館へ編集して保存する。

## 商品化の共通段階

1. 試作品
2. 自分で実証
3. 顧客ヒアリング
4. 販売用に分離
5. 小規模販売
6. 継続・改善または終了

開発を始める前に「誰の、どの問題を、いくらで解決するか」を一文で定義する。販売検証前の大規模開発は行わない。
