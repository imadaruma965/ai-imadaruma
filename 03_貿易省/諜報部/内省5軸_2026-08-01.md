## 軸1｜朝の意図設定（implementation intention / if-then）× 夜の振り返り

### 要点
- Implementation intention（「もし状況Xなら、行動Yする」）は、目標意図だけの場合より目標達成を中〜大程度押し上げる。
- 朝は具体的な実行プラン認知が夜より出やすく、翌日の進捗報告と結びつきやすい研究がある。
- 「朝のif-then × 夜の振り返り」の**ペア専用RCTは薄い**。夜に障害・学びを1つ残し、朝のif-thenへ渡すループは MCII（Mental Contrasting + Implementation Intentions／WOOP）と整合する読み方が妥当。日次のMCIIは一回きりより効きやすい報告がある。

### 根拠の強弱
| 主張 | 強弱 |
|------|------|
| if-then本体の効果 | **強** |
| 朝の具体プラン認知と翌日進捗 | **中** |
| 朝＋夜ペア専用の効果サイズ | **弱〜中**（周辺証拠＋推論） |

### 内省UIへの示唆
- **やる**: 朝は具体if-thenを1本（状況キュー必須）。夜は「今日の障害1つ」を翌朝のifへ持ち越す。
- **やらぬ**: 朝に抽象的な願望だけ書く／夜に長文の計画を書いて覚醒させる。

### 出典メモ
| 文献 | 要約 |
|------|------|
| Gollwitzer & Sheeran (2006) meta（AES P 系） | 94テスト、平均 d≈0.65。if-thenは開始失敗・脱線防止に効く。 |
| Bieleke, Keller & Gollwitzer (2021) If-then planning — DOI 10.1080/10463283.2020.1808936 | if-thenの実験総説。健康行動など日常目標でも中〜大の効果帯。 |
| Sheeran et al. (2024) 642 tests — DOI 10.1080/10463283.2024.2334563 | 条件付き形式・高動機・リハーサルで効果大。 |
| Oettingen 系 MCII／WOOP；Adriaanse et al. (2010) EJSP 等 | 願望＋障害の対比のあと if-then。障害をif側に載せる前提が揃う。 |
| 日次MCIIと就寝遅延（2025 registered report, Europe PMC） | 毎日のMCIIが一回きりより就寝遅延を減らす。 |
| Ludwiczak et al. (2024) Goal Cognition B/E of Day — DOI 10.1525/collabra.136883 | 朝は具体実装思考が出やすい（特に朝型）。具体思考は翌日進捗と関連。 |

### 統治手帳への翻訳一句
「朝は鍵穴を決め、夜は鍵の欠けを一つ残す。」

## 軸2｜一晩の振り返り（reflection）が自己認識と翌日修正に効く条件

### 要点
- 夜のポジティブな仕事内省は、翌朝の意味づけ・翌日のワークエンゲージメントと連鎖する日記研究がある。
- 就寝前の「やるべきことの外出し」（to-do list）は入眠を早める実験が二次資料で広く引用される（2018）。
- ジャーナリング介入のメタ分析（Sohal 2022）はメンタル指標に小さな改善。異質性は大きい。一般集団ではポジティブ寄り記述が情動面で有利、という整理がある。
- 実務二次は「5〜10分・3〜5問い・締め（win／学び／翌日1手）」を推奨。深掘り長文は反芻・覚醒のリスク。

### 根拠の強弱
| 主張 | 強弱 |
|------|------|
| 短く構造化した夜の閉じ | **中** |
| 最適分数の厳密値（何分が正解か） | **弱** |
| 長時間の自由記述を夜に必須化 | **やらぬ側に中** |

### 内省UIへの示唆
- **やる**: 上限タイマー／問い上限3／「事実1・学び1・明日の最小手1」／反芻時は短縮モード。
- **やらぬ**: 白紙長文必須、評価点の羅列、就寝直前の自己糾弾プロンプト。

### 出典メモ
| 文献 | 要約 |
|------|------|
| Sonnentag 系 positive work reflection（日記・翌日効果） | 夜のポジティブ内省→翌朝の意味づけ等→翌日エンゲージメント。 |
| Scullin et al. 就寝前 to-do（JEP 2018 系・二次で広く引用） | 完了済みの想起より、未完了の外出しが入眠に寄与しやすい、という報告。 |
| Sohal et al. (2022) journaling meta — DOI 10.1136/fmch-2021-001154 / PMC8935176 | RCT20件。介入群で尺度スコア約5%改善帯。異質性大・臨床的意義は慎重。 |
| Guo et al. expressive vs positive writing meta — DOI 10.1002/nop2.1897 | 一般集団ではポジティブ記述が情動に有利な整理。 |

### 統治手帳への翻訳一句
「夜は採点しない。明日の一手だけ閉じる。」

## 軸3｜少数指標の可視化（レーダー等）と監視感・罪悪感

### 要点
- 測定は行動量を増やしつつ、楽しさ・内発動機を削り活動を「仕事化」しうる（Etkin）。
- Quantified Self／押し込み型トラッキングは、恐怖・罪悪感・羞恥を動機に使いがち、という批判的整理がある（Lupton）。
- ウェアラブル等の定性調査では、未達・過剰監視・自己不信・不安が報告される。
- 「指標は何個が最適か」の黄金数RCTは薄い。監視感を減らす条件は、自律・透明・内発・常時スコア抑制に寄せて読む。

### 根拠の強弱
| 主張 | 強弱 |
|------|------|
| 測定の隠れたコスト（内発動機の毀損） | **強〜中** |
| レーダー枚数の最適値 | **弱** |
| 監視感回避の設計原則（自律・非罰） | **中**（理論＋定性） |

### 内省UIへの示唆
- **やる**: 指標は極少（例: 七徳の「今日の1軸」）、傾向は週次、未記入を失敗表示にしない、自己解釈欄をスコアより先に置く。
- **やらぬ**: 毎日フルレーダーの赤緑、連続未達の赤バッジ、他者比較、スコア絶対評価の常時表示。

### 出典メモ
| 文献 | 要約 |
|------|------|
| Etkin (2016) The Hidden Cost of Personal Quantification — DOI 10.1093/jcr/ucv095 | 測定は量を増やしつつ楽しさと継続意欲を削りうる。 |
| Lupton (2016) quantified selves / dataveillance | 押し込み型トラッキングと情動的動機づけ（罪悪感等）の問題。 |
| Overquantified（Aalto thesis） | SDT枠で自律・有能感の毀損、未達時の失敗感・不安。 |

### 統治手帳への翻訳一句
「数字は鏡であって、看守にしない。」

## 軸4｜自己批判ではなく自己Compassion寄りの記録

### 要点
- 自己批判は精神病理の横断的リスク因子。自己compassion（Neff: 自己への優しさ・共通の人間性・マインドフルネス）はレジリエンス因子。
- 「自己慈悲は甘やかしで動機が落ちる」という通説は、実証側では否定されやすい（initiative・失敗不安の低下と両立しやすい）。
- Mindful Self-Compassion（MSC）等の介入エビデンスは厚い。ガイドなしの「自己慈悲ジャーナル」単体は効きにくい可能性に注意（二次）。
- 一般集団ではポジティブ記述が情動に有利（軸2と接続）。

### 根拠の強弱
| 主張 | 強弱 |
|------|------|
| compassion vs criticism の心的帰結 | **強** |
| UI文言テンプレ単体の継続RCT | **弱〜中** |

### 内省UIへの示唆
- **やる**: 未達時プロンプトを「何が悪かったか」から「友人が同じなら何と言うか／明日の小さな再起1手」へ。共通人性の一文を任意表示。
- **やらぬ**: ストリーク断絶の罰、人格否定ラベル、「甘え禁止」トーン。

### 出典メモ
| 文献 | 要約 |
|------|------|
| Neff (2023) Self-Compassion Annual Review — DOI 10.1146/annurev-psych-032420-031047 | 六要素モデル、神話の否定、介入の概観。 |
| Self-criticism and self-compassion（Current Psychiatry／self-compassion.org PDF） | 批判＝リスク、compassion＝レジリエンスの整理。 |
| Neff & Germer MSC RCT | プログラム介入で自己慈悲・ウェルビーイング改善。 |

### 統治手帳への翻訳一句
「叱る前に、同じ人間として隣に座る。」

## 軸5｜習慣の最小単位（2〜5分）と途切れ後の再開

### 要点
- Tiny Habits（Fogg）: 既存ルーチン（Anchor）の直後に超小さい行動＋Celebration。公式は30秒未満も推奨。2〜5分はジャーナルの「最小版」として妥当な帯。
- 小さな行動の方が一貫し、習慣化しやすい、という行動モデル・実装意図研究と整合。Foggの本体は実地プログラム由来で、単一ラボRCT一式ではない点に注意。
- Anchor形式は軸1のif-thenと同一機構。
- 「1日抜けても崩壊しない／連続欠かしたら設計を小さくし直す」は実務ルール。厳密メタは薄いが、欠席1回で習慣が消えるわけではない、は習慣研究の一般含意と整合。

### 根拠の強弱
| 主張 | 強弱 |
|------|------|
| 小さく始める | **中〜強**（行動モデル＋実装意図） |
| 再開UIの最適プロトコル | **弱**（実務） |

### 内省UIへの示唆
- **やる**: デフォルト2分モード、Anchor設定（既存ルーチン後）、欠席後は罰なし再開＋レシピ縮小提案、成功時の短いCelebration。
- **やらぬ**: 復帰時に未消化分のまとめ強制、失った日数の強調、完璧主義の全日埋め。

### 出典メモ
| 文献 | 要約 |
|------|------|
| Fogg Tiny Habits（公式 start-tiny / references） | Anchor → Tiny Behavior → Celebration。動機の波に頼らない設計。 |
| Minute Calisthenics protocol — DOI 10.1186/s12889-020-09355-4 | THMを実装意図の一種として記述したRCTプロトコル。 |
| Steffen (2022) Tiny Habits for Gratitude — DOI 10.3389/fpubh.2022.866992 | 感謝の極小習慣レシピの整理。 |
| Gollwitzer系（軸1と共用） | if-then／キュー結合が習慣の土台。 |

### 統治手帳への翻訳一句
「戻るときは、昨日の負債ではなく、今日の一口から。」
