# 0. 一行でいうと

> **奴らを見ろ、とは言わない。私を見ろ、と言う。**

一般の風刺画は、権力や他者を告発して成立する。**本ブランドの風刺画は、神話と規範と、自分自身を撃つ。**同じ切れ味を、敵を作らずに出す。

---

# 1. 何を風刺するか

## 1.1 撃ってよいもの

| 対象 | 例 |
|---|---|
| **神話**（亀神話・「継続は力なり」） | 石に刻まれた教え、同じ歩幅の足跡、一本しかない道 |
| **万人向けの助言**（one-size-fits-all advice） | 5時起き、毎日コツコツ、意志を鍛えよ |
| **物と制度**（人ではない） | 生産性アプリ、チェックリスト、カレンダー、研修、名刺 |
| **自分自身**（最も強い） | 買ったまま読まない本、三つ目の新しい仕組み、未送信のメール |

## 1.2 撃ってはいけないもの

**人・職業・団体・実在の人物・診断・時事政治・宗教・国民性。**
**そして「亀」——亀は敵ではない。**亀を笑う絵は、この世界では作らない（17 §5）。

**迷ったときの判定**：**その絵を見て傷つく「誰か」が具体的に想像できたら、作らない。**傷ついてよいのは、**神話と、自分だけ**である。

# 2. 五つの型（毎日、どれかを選ぶ）

| # | 型 | 構造 | 例 |
|---|---|---|---|
| **A** | **状態の札** | 読者の状態を一枚で名指す。**最も保存される** | THE EMPTY DESK／THE FORTY-SEVEN TABS／THE SUNDAY NIGHT |
| **B** | **反転** | 常識を裏返す。**うさぎが、逆をやっている** | 皆が登る丘を、一人だけ回り込む |
| **C** | **時間**（連続パネル） | 同じ絵を2〜3コマ、一箇所だけ変える。**最後で予想を外す** | *He made a plan. / He made a better plan. / …* |
| **D** | **神話の物証** | 石・足跡・柵など**物だけ**で神話を示す。人を描かない | 割れた石板が、道に長い影を落としている |
| **E** | **道具の皮肉** | 物が主役。**人は小さく、または不在** | 使われていないアプリが、机の上で積み上がっている |

**一枚に一つの型。混ぜない。**

# 3. 絵の規律（世界観の凝縮）

| # | 規律 |
|---|---|
| 1 | **地はマスタードの黄のベタ。**紙のムラ・擦れ・汚れを残す |
| 2 | **石はすべて墨。**手すり・台座・階段・壺・門柱を一つか二つだけ置く。**風景は描かない**（丘・木立・遠景の町は禁止） |
| 3 | **色を持つのは、うさぎだけ**（五色）。亀は二色。物は墨 |
| 4 | **線は墨のハッチング。**疎密をつける。**なめらかな陰影・グラデーション禁止** |
| 5 | **要素は三つまで。**人物・石・小道具の合計 |
| 6 | **余白は五割以上** |
| 7 | **青白い光はAIだけ。**朝と未来は暖かい黄 |
| 8 | **うさぎは止めない**（傾く・跳ねる・翻る）。**亀は止まってよい** |
| 9 | **どこか一箇所が緩んでいる**（靴紐・付箋・帯） |
| 10 | **右下に朱の落款** |

**基準画を必ず参照に添える。**文章だけで人物を描かせない。

---

# 4. 言葉の規律

| 項目 | 規定 |
|---|---|
| 題字 | **英語の短い語**（THE〜）。札形式なら下帯に。**日本語版は日本語の短い語** |
| 手書きの一行 | **英語8語／日本語20字まで。**絵の説明をしない。**ずらす** |
| 口調 | 断定して、最後だけ開く。**説明しない** |
| 禁止語 | **あなたはADHD／診断／症状／治る／改善する／必ず／誰でも／簡単に／今だけ** |
| 番号 | **原型と状態の札にだけ番号をつける。**日々の風刺画に番号はつけない（増えすぎて管理できなくなる） |

---

# 5. 法と倫理の線（動かさない）

| 守る | 根拠 |
|---|---|
| **読者を診断しない。**「あなたはADHDだ」「ADHD度チェック」を作らない | 医師法17条・L4' |
| **恐怖で締めない。**「このままでは10年後」を作らない | L5' |
| **人を攻撃しない。**攻撃するのは神話と物 | L7' |
| **効果を断定しない。**治る・改善する・成果が出ると書かない | 薬機法66条・景表法／FTC |
| **実在の人物・企業・製品を特定できる形で描かない** | 名誉毀損・商標 |
| **AIで描いていることを隠さない** | ブランドの看板と一致（`Hare Statecraft正本` §5.40） |

# 6. 毎日の手順（15〜30分）

1. **種を選ぶ**（§7 のネタ帳から一つ）
2. **型を決める**（§2 のA〜E）
3. **一行を書く**（先に言葉。絵は後）
4. **プロンプトを組む**（§8 の雛形。基準画を添付）
5. **点検する**（§9）
6. **保存する**——`deck/`（札）または `satire/YYYY-MM-DD_題字.png`
7. **記録する**——`satire/ネタ帳.md` に、日付・型・題字・一行・反応

**三回直して合わなければ、その日は出さない。**種は翌日に回す。**毎日出すことより、世界観を崩さないことを優先する。**

# 8. プロンプトの雛形

```text
Use case: daily satirical illustration for an English-language publication
Asset type: single illustration in an existing series

REFERENCE IMAGES:
Reference Image 1 = the hare. Take his face, proportions, outfit and props exactly from it.
（亀を出す場合）Reference Image 2 = the tortoise.
Match their drawing style; do not redesign them.

FORMAT:
Vertical 2:3.〔札にする場合：thick worn black border, a small Roman numeral at top centre, and a
bottom title band reading 〈TITLE〉 in hand-lettered capitals, with a small red seal in the corner.〕

TECHNIQUE:
Old printed card. Black ink hatching only — uneven density, some areas left bare. NO smooth
shading, NO gradients, NO glow. Flat mustard-yellow ground with paper grain, speckles and worn
edges. Slight off-register colour.

THE IMAGE:
〔型A〜Eのどれか。要素は三つまで。石は墨、うさぎだけが色を持つ〕
Long hatched shadows fall across the ground.
〔抜けを一つ：the boot lace is untied / paper slips stick out of the notebook〕

HANDWRITTEN LINE:
Below the drawing, small hand-lettered pen script, exactly: 〈8語以内の一行〉

AVOID:
landscape, hills, trees, distant towns; painted stone; smooth shading or gradients; a second
light source; crowds; real people, brands or logos; skulls, graves or macabre motifs; cute
mascot proportions; dog or fox features; any text other than the title and the one line.
```

# 9. 出す前の点検（六つ）

1. **その本棚に並ぶか**（クラッセン、タン、ジェファーズの隣に置けるか）
2. **その壁に飾れるか**（標本図版の隣に掛けられるか）
3. **その音楽の中で成立するか**（歌詞のないループの邪魔をしないか）
4. **「これ、私だ」と言えるか**（言えないなら、それは自己紹介であって風刺ではない）
5. **傷つく誰かが想像できないか**（できたら作り直す）
6. **スマホの幅で、何が起きているか読めるか**

# 11. 既刊の三枚が確定させたこと【2026-09-28 追記】

**この三枚が、以後のすべての基準になる。迷ったら、この三枚に合わせる。**

| 札 | 何を確定させたか |
|---|---|
| **Ⅰ THE HARE** | 人物の全仕様（帽子・不敵な笑み・食い違い五箇所・タブレットと黒いノート・ほどけた靴紐）／**色を持つのはうさぎだけ** |
| **Ⅱ THE TORTOISE** | 亀の全仕様（裸・白い鉢巻き・四つん這い・甲羅と肌の二色）／**色数の差が二人の差** |
| **Ⅲ THE DOOR** | **人物のいない札が成立する**／**石の語彙**（門柱・階段・手すりの断片）／**扉の中だけが風景** |

## 11.1 構図——札は中央、場面はずらす

| | 札（原型・状態） | 場面（物語の絵） |
|---|---|---|
| 配置 | **中央。左右対称** | **ずらしてよい** |
| 理由 | 数字と題字帯が中央にある。**一枚だけ呼吸が違うと、デッキに見えない** | 動きと物語は非対称から出る |

**ずらすなら、空いた側に意味を置く**（割れた石板・足跡・影）。**空白が「余り」に見えたら、それは失敗である。**

## 11.2 影は手前へ落とす

**左右のどちらかへ流すと、片側だけが重くなる。**手前（画面下）へ落とせば、左右の余白が等しく残る。**影は必ずハッチングで描く。**

## 11.3 石の語彙——場所を説明せずに場所を出す

**門柱・階段・手すりの断片・台座・壺。一つか二つだけ。**建物全体は描かない。**すべて墨。**

**これで背景の問題は解決した。**黄の地に石の断片を置けば、そこが「どこか」になる。**風景（丘・木立・遠景の町）は、以後も描かない。**

## 11.4 色の配分（三層）

| 層 | 色 |
|---|---|
| 地 | **マスタードの黄のベタ**（紙のムラ・擦れ） |
| 物・石・亀 | **墨のハッチング**（＋亀のみ二色） |
| **扉の中／うさぎの衣装／AIの光** | **色が入るのはここだけ** |

**「色が入っている場所＝意味がある場所」**という読み方が、これで成立する。
