## 1. ペルソナ適合の検証（ダ・ヴィンチ）

### 1.1 まず確認すべきこと：この媒体の読者は誰か

`18`（第5案）は**日本語圏**の人物である。英語のSubstackはその人には届かない。**したがって本ヘッダーの適合は、次のどちらを狙うかで判定が変わる。**

| 想定読者 | 判定 |
|---|---|
| A. 日本語圏の `18`（デザイン20年・健診で引っかかった47歳） | **不適合。**英語である時点で読めない |
| B. 英語圏の "unconventional minds"（neurodivergent 当事者・自認層） | **部分適合。**ただし人物像の一次データが無い（【UNKNOWN】） |

### 1.2 英語圏で語彙が違う

英語圏の当事者コミュニティの自称は **neurodivergent / ADHD brain / late-diagnosed** が主流である。日本語の「ADHD型」に相当する自己像の語が違うため、**`18` の語をそのまま翻訳しても刺さらない**【INFERENCE】。

### 1.3 絵が語っている位置

本ヘッダーが発している信号を分解する。

| 要素 | 読者に伝わること |
|---|---|
| 重い Didone 体＋イタリック＋レタースペースの小文字大文字 | **由緒ある読み物。**Substackの文芸的な慣習と一致（良い） |
| 銅版画＋トスカーナの風景＋古典の門 | **古典教養・哲学の館。**「私のための場所」ではなく「立派な場所」に見えやすい |
| 道化のうさぎ | **私のための場所**の信号（唯一これが担っている） |
| 包帯の亀 | 正本の意味（歴戦の証）は英語圏の読者に説明されていない |
| 石の標語 | 権威づけ。**ただし §0-5 の反転がある** |

**【INFERENCE】** 「立派な場所」の信号が強すぎ、「私のための場所」の信号が一点（うさぎ）に集中している。**ペルソナが求めているのは、許可（あなたのままでよい）である。**荘厳さは許可を与えない。

## 2. 機能の検証（北斎）

### 2.1 Substackの寸法と、この絵の不一致

| 用途 | 公式の推奨 | 本案 |
|---|---|---|
| ロゴ | 256×256 以上（512以上が安全） | **未作成** |
| メールのバナー | **1100×220（≒5:1）** | **未作成**（この絵をそのまま縮めると人物が潰れる） |
| ホームページのヘッダー | **2560×1280（2:1）** | 約3:1。**上下に余白を足すか、左右を切る必要がある** |

**さらに公式が明記している注意が二つある。**
1. **1:1より縦長の画像は自動で1:1に切られる**
2. **画像内の文字はモバイルで切れる・読めなくなることが多い。タイトルは媒体に任せよ**

**本案は、画面の左3分の1に文字を集めている。モバイルでは最初に失われる領域である。**

### 2.2 絵としての点検

| 項目 | 判定 |
|---|---|
| うさぎの同一性 | **合格。**道化帽・黒縁眼鏡・水玉コート・左右非対称のズボン・黒ブーツと白ローファーがキャラ01と一致 |
| 市松模様の道・開いた扉・朝日 | **合格。**正本 §6 の記号を保っている |
| 亀 | **不一致。**写実的な銅版画の亀になり、絵本調の亀（正本 §5）と別人に見える |
| 地の色 | クリームは保持。**ただし「マスタードの黄色の帯」が消えた**（正本 §4） |
| 線の密度 | **要注意。**ハッチングが細かすぎ、モバイル幅では灰色の塊になる |
| 石 | **意味が反転**（§0-5） |

## 3. 代案（北斎の推奨）

### 3.1 世界観は変えない。「格」を一段下げ、「私のため」を一段上げる

**捨てるもの**：トスカーナの遠景・丘の上の町・石の標語・荘厳な門の装飾・画面内のタイトル文字
**残すもの**：銅版画の線、クリームの紙、市松模様の道、開いた扉と朝日、道化のうさぎ、包帯の亀、**マスタードの黄色の帯**
**足すもの**：**余白**（絵を1割小さくする）。**視線**（うさぎが読者を見る）

### 3.2 三点セットで作る（一枚で兼用しない）

| # | 用途 | 仕様 | 中身 |
|---|---|---|---|
| 1 | ロゴ | 512×512・背景透過 | **うさぎの顔だけ**（帽子の鈴まで。線は太らせる） |
| 2 | ホームページのヘッダー | 2560×1280（2:1）・**文字なし** | 扉を中央に、亀を左、うさぎを右。**上下に広い空。タイトルは媒体が描く** |
| 3 | メールのバナー | 1100×220（5:1）・**文字なし** | **市松模様の道と開いた扉だけの帯**。人物は小さく2つ。細部を捨てる |

### 3.3 タッチの指定（プロンプトに入れる語）

```text
Detailed pen-and-ink engraving lines with restrained crosshatching, flat muted color fills,
warm cream paper ground, one wide band of desaturated mustard yellow, black-and-white
checkerboard path, generous empty space, no text, no lettering.
```

**禁止**：写実的な風景、遠景の町並み、荘厳な装飾、細密なハッチングの詰め込み、画面内の文字、石碑への標語

### 3.4 なぜこの方向が正しいのか（理由）

1. **密度は快感だが、密度は読みにくさでもある。**このペルソナは「散らかったものが一枚に収束する」瞬間に快感を覚える（`09` §1.4）。**収束を見せるには、空白が要る。**いまは収束前の散らかりに見える
2. **許可の絵にする。**荘厳な門は「入る資格」を問う。**開いた扉と、こちらを見て笑ううさぎは「入っていい」と言う**
3. **モバイルで生き残る形にする。**文字を捨て、人物を大きく、線を太くする。**媒体がタイトルを描いてくれるのだから、絵は絵の仕事だけをすればよい**
4. **亀を絵本調に戻す。**同じ世界に住んでいる二人に見えないと、「亀神話」の物語が成立しない
