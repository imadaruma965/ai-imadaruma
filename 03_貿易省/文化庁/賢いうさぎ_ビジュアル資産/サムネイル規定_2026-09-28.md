# サムネイル規定（横長・文字あり）

> 用途：X長文記事のカバー、note見出し、YouTube等。**札（縦2:3）とは別物として扱う。**
> 上位：`世界観ブリーフ_2026-09-28.md`／`風刺画ルール_2026-09-28.md`
> 制定 2026-09-28（北斎）

## 1. 札との違い（ここだけ変える）

| 項目 | 札 | **サムネイル** |
|---|---|---|
| 比率 | 縦 2:3 | **横 16:9**（1600×900 で作る） |
| 人物の大きさ | 画面高さの約2/3 | **50〜70%**（縮小表示に耐えるため、札より大きく） |
| 要素の数 | 三つまで | **二つまで**（人物＋石か小道具ひとつ） |
| 文字 | 題字帯（画像内） | **画像に文字を焼かない。**BOSSが後から載せる |
| 余白 | 五割以上 | **左3分の1（または左半分）を黄の無地にして空ける**＝文字の置き場 |
| 枠 | 太い黒枠 | **枠なし**（縮小で潰れるため） |
| 落款 | 下帯の隅 | **右下に小さく** |

## 2. 変えないもの

マスタードの黄のベタ地／墨のハッチング／**色を持つのはうさぎだけ**／なめらかな陰影とグラデーション禁止／紙のムラ／**うさぎは動いている、亀は止まってよい**／**どこか一箇所が緩んでいる**。

## 3. 文字を載せるときの決まり（BOSS作業）

- 置き場は**空けた左側**。中央に重ねない
- 書体は**札の題字と同じ系統**（太めのセリフ体）。揃えることが署名になる
- 色は**黒**。黄の上で最も読める
- **一行か二行。**三行は入れない

# 5. X・Instagram に札を出すとき（2026-09-28 追記）

**札は 2:3（1024×1536）で作る。だが 2:3 は 4:5 より縦に長く、Xのタイムラインでは途中で切られることがある。**切られると、**上のローマ数字と下の題字帯——札に見せている部分——が真っ先に消える。**

## 解決：札を 4:5 の台紙に載せる

**絵を作り直さない。左右に余白を足すだけ。**

```bash
sips --padToHeightWidth 1536 1229 --padColor 000000 deck/I_THE_HARE_v1.png --out deck/x_4x5/I_THE_HARE_v1_4x5.png
```

- 1536 × 1229 ＝ 4:5。**左右に約100pxずつ足すだけ**
- **余白は黒。**札の外枠が黒なので、額縁のように見えて継ぎ目が出ない
- **原本（2:3）は deck/ に、投稿用（4:5）は deck/x_4x5/ に置く**

| 用途 | 使うファイル |
|---|---|
| デッキ・印刷・商品 | `deck/〈札〉_v1.png`（2:3・原本） |
| **X本文・Instagramフィード** | **`deck/x_4x5/〈札〉_v1_4x5.png`（4:5）** |
| 記事サムネ・note見出し | 16:9（本ファイル §1〜§4） |

**【要検証】**Xの切り取り方は仕様変更がある。**最初の一枚を投稿したとき、タイムラインで上下が切れていないかを必ず目視すること。**切れていなければ 2:3 のまま出してよい。
