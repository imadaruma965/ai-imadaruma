## 命名規則（2026-09-17改訂・日本語／ブランド名を先頭に）

```
賢いうさぎYYMMDD日本語タイトル.png
```

例：`賢いうさぎ260917発射台.png`

- **「賢いうさぎ」を必ず先頭に付ける**（BOSS決裁・2026-09-17）。理由：ダウンロードされたファイル単体を見ても、どのブランドの画像か一目で分かるようにするため。区切り記号（アンダースコア・ハイフン）は入れない
- 日付はYYMMDD（西暦下2桁＋月2桁＋日2桁）
- タイトルは絵の中心にあるモノ・状況を一言で（例：発射台／分かれ道／逆立ち）。長い説明文にしない
- 2026-09-17より前のファイル（`x_post_2026-08-28_koitsua_meianda_1200x1200.png`、`x_post_260916_wakaremichi.png`）は旧命名のまま保持し、リネームはしない

## 比率とマルチSNS運用（2026-09-24新設）

**媒体ごとに比率が違う場合、2つの方法がある。優先順位は①ネイティブ再生成→②クロップ。**

1. **ネイティブ再生成（推奨・時間があるとき）**：同一の小道具・構図意図・世界観を保ったまま、対象の比率で構図を組み直して生成し直す。2026-09-24「重さで分ける（横）」で実証済み——月・小道具・キャプションを一切欠けさせずに4:3へ移せた。**ポイントは「クロップではなく再配置」を明示的に指示すること**（小道具のデザインは踏襲し、配置だけ横長に組み替える）
2. **クロップ（簡易・時間がないとき）**：`sips -c`等で中央クロップして書き出す。要素が欠ける場合があるため、書き出し後に必ず目視確認する（耳・小道具が切れていないか）

| 媒体 | 推奨比率 | 備考 |
|---|---|---|
| **X** | 横長（4:3〜16:9） | フィードのサムネイルで小道具が読めるよう、要素を大きめ・コントラスト強めにする |
| **Instagram フィード** | **4:5（縦長）** | 表示面積が最大。今の繊細タッチとの相性が良い |
| **Instagram ストーリーズ** | 9:16 | 4:5より縦に長い。足りない場合は上下（空・地面）を延長するか、同一構図で比率だけ変えて再生成 |
| **note見出し画像** | 4:3〜16:9 | Xと同様、横長向き |

**運用ルール**：
1. 生成時に本命の比率を1つ決める（索引の「本命比率」列に記録）
2. 他媒体は、時間が許せば①ネイティブ再生成、急ぐ場合は②クロップで書き出す
3. クロップで要素が欠ける場合（耳・小道具など）は採用せず、再生成に切り替える

**画風の使い分け（2026-09-20の懸念への対応）**：現行の繊細タッチ（v2.0）は情報量が多く、Xのサムネイルでは要素が小さく読みにくい場合がある。X投稿で「止める力」を優先したい回は、小道具を大きく・コントラスト強めに調整するか、太い輪郭線タッチ（v1.0アーカイブ）の再検討も選択肢として残す。

**マスター比率の固定化（2026-09-27改訂・BOSS決裁）**：上記の媒体別推奨比率(X=横長、Instagram=4:5)は今後は使わず、X・Instagramフィード共通で縦型4:5(1080×1350px)・1枚絵をマスター比率として固定する。理由：同じ画像をXとInstagramフィードの両方にそのまま流用するため、媒体ごとに作り分ける手間をなくす。ネイティブ再生成/クロップの使い分けルール自体は今後も有効だが、「対象の比率」は常に4:5固定とする。Instagramストーリーズ(9:16)のみ従来通り別途クロップ/再生成で対応。

**画像生成ツール（2026-09-27新設）**：実制作はChatGPT(image2.0)で行う。プロンプトには常に「縦型4:5・1080×1350px・1枚絵・文字/ロゴなし」を明記する。

**⚠️上記2点は2026-09-28付で北斎の新方針に置き換え、廃止（BOSS決裁）**：X本文の挿絵は今後「札」形式（縦2:3・太い黒枠・上にローマ数字・下に題字帯・右下に朱の落款、文字を画像内に焼き込む）に統一する。上記の「マスター比率4:5・1枚絵・文字/ロゴなし・ChatGPT image2.0」のルールは廃止し、以後のX本文挿絵には適用しない。キャラクターも紳士うさぎ（色鉛筆調）から野兎+亀の新基準画に切り替わっている。詳細・上位文書は`../風刺画ルール_2026-09-28.md`／`../世界観ブリーフ_2026-09-28.md`／`../サムネイル規定_2026-09-28.md`（記事サムネ・note見出し用は横16:9・枠なし・別ルール）。生成時は基準画（`../キャラマスター/01d_札版_基準画_v1.png`／`02a_亀_札版_基準画_v1.png`）を必ず参照に添付する。`賢いうさぎ260927引く休憩.png`は旧方針（4:5・現キャラ）で作った最後の1枚として、リネームせずこのまま索引に残す。

**補足（2026-09-28・北斎より訂正）**：4:5を求めた理由（X・Instagram両方への流用）自体は正しかった。ただし**札の原本は2:3のまま作り、投稿時だけ左右に黒余白を足して4:5の台紙に載せる**（原本を作り直さない）。手順・書き出し済みファイルは`サムネイル規定_2026-09-28.md` §5、実体は`../deck/x_4x5/〈札〉_v1_4x5.png`。**未検証**：Xタイムラインで上下が実際に切れないかは、最初の投稿で目視確認してから確定する(BOSS確認待ち)。切れなければ2:3のまま出してよい。
