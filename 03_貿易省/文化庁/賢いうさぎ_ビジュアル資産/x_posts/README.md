## 命名規則（2026-09-17改訂・日本語／ブランド名を先頭に）

```
賢いうさぎYYMMDD日本語タイトル.png
```

例：`賢いうさぎ260917発射台.png`

- **「賢いうさぎ」を必ず先頭に付ける**（BOSS決裁・2026-09-17）。理由：ダウンロードされたファイル単体を見ても、どのブランドの画像か一目で分かるようにするため。区切り記号（アンダースコア・ハイフン）は入れない
- 日付はYYMMDD（西暦下2桁＋月2桁＋日2桁）
- タイトルは絵の中心にあるモノ・状況を一言で（例：発射台／分かれ道／逆立ち）。長い説明文にしない
- 2026-09-17より前のファイル（`x_post_2026-08-28_koitsua_meianda_1200x1200.png`、`x_post_260916_wakaremichi.png`）は旧命名のまま保持し、リネームはしない
