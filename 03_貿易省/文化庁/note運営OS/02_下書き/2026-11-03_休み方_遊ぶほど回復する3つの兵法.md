# 休み上手なうさぎは、休日に何をしているのか。──心理学が教える「何もしない」だけではない休息と、遊ぶほど心が回復する3つの兵法【保存版・小さな作戦リスト付き】

休みは、何もしない時間じゃない。

どこに力を使うか、選び直す時間だ。

休日を上手に使える人は、人生もうまくいく。そんな話を聞くと、少し焦る。成功している人は、休日にも運動し、本を読み、新しいことに挑戦しているらしい。たしかに、そういう休日は素敵だと思う。

でも、僕たちの休日はどうだろう。

昼まで寝た。動画を見た。ソファでスマホを眺めていた。何かしようと思っているうちに、もう夕方だ。

やっと好きなことを始めたら、今度は夢中になりすぎて、食事も睡眠も後回しになった。

そして日曜日の夜、こう思う。

「せっかくの休みを、また無駄にした」

体は休めたはずなのに、なぜか疲れが残っている。でも、本当に無駄だったのだろうか。

うさぎには、突然ジャンプして、空中で体をひねる行動がある。「ビンキー」と呼ばれ、喜びや興奮を感じているときに見られることがある。

天敵から逃げるためでも、餌を探すためでもない。ただ、跳ねる。

もちろん、動物の行動をそのまま人間の生き方に当てはめることはできない。でも、この姿を見ると、僕は少し考えてしまう。

人間にも、何かの役に立つためではなく、ただ楽しいから動く時間があっていいのではないか。

今日は、心理学の「回復体験」という考え方を手がかりに、休み上手なうさぎの休日について考えてみたい。

## 1. 休みまで「役に立つか」で測っていないか

僕たちは、時間を効率よく使うよう求められている。料理は時短。移動は最短。動画は倍速。勉強は最速で成果を出す。仕事で効率を求めるのは分かる。

でも、休みの日まで「役に立ったか」で採点する必要があるのだろうか。

散歩するなら、歩数を稼ぎたい。本を読むなら、仕事に役立つ知識を得たい。趣味を始めるなら、上達したい。得意になったら、収益化できないだろうか。

もちろん、どれも悪いことではない。問題は、好きだったことまで、いつの間にか成果を求められる課題に変わってしまうことだ。

特に、先延ばしや過集中に悩む人にとって、休日は意外と難しい。平日にできなかったことが頭から離れない。片づけなきゃ。勉強しなきゃ。遅れを取り戻さなきゃ。自由な時間ができても、何から始めるか決められない。ようやく始めたら、今度は止まれない。

何もしなければ罪悪感。何か始めれば、やりすぎて疲れてしまう。

でも、ここで一つ疑ってみたい。本当に必要なのは、もっと上手な時間管理なのだろうか。

もしかすると、僕たちは休日になっても、仕事と同じものさしを握りしめているのかもしれない。

休み上手とは、休日に多くのことを達成できる人ではない。今の自分に合う休み方を選べる人だと、烏龍は考えている。

休みは、仕事に戻るための充電時間だけではない。

休んでいる時間も、人生の本編だ。

## 2. 心理学が見つけた「回復する休み」の四つの要素

では、心が休まる休日には、どんな特徴があるのだろう。

心理学者のソンネンターグとフリッツは、2007年の研究で、仕事からの回復に関わる経験を四つに整理した。

1. 心理的な切り離し：仕事のことから心を離す
2. リラックス：心身の緊張をゆるめる
3. コントロール：自分で時間の使い方を決める
4. マスタリー体験：仕事以外のことに挑戦し、学ぶ

ここで興味深いのは、四つ目だ。休息と聞けば、横になる、眠る、何もしないといった過ごし方を思い浮かべやすい。でも、仕事以外のことに挑戦する経験も、回復を考えるうえで重要な要素に含まれている。

たとえば、初めての料理を作る。楽器で弾けなかった曲を練習する。知らない土地を歩く。陶芸で不格好な器を作る。

ここで大切なのは、立派な成果ではない。

レシピを見ながら一品作れた。昨日より一小節弾けた。迷いながらも目的地に着いた。土の塊が、自分の手で器になった。

「自分で試したら、少し形にできた」

そんな小さな手応えだ。心理学者バンデューラが提唱した自己効力感の理論でも、自分で行動して得た達成経験は、「この課題なら、自分にもできそうだ」という感覚を育てる重要な情報源の一つとされている。

もちろん、趣味で料理ができたからといって、翌日の仕事が必ずうまくいくわけではない。でも、仕事の評価とは別の場所で、自分の力を使えたと感じることはできる。

その手応えが、仕事の成果に変換される必要はない。

自分に合う休み方を一つ知れば、次の休日にはもう一つ選択肢が増える。試して、合わなければ変える。うまくいけば、また選べる。

そうして増えた選択肢は、次の休日を自分らしく過ごすための財産になっていく。烏龍は、その積み重ねを、休み方の複利と考えている。

ただし、マスタリー体験にも注意が必要だ。上達しなければ。もっと難しいことに挑戦しなければ。せっかく始めたのだから、最後までやり遂げなければ。

そう考え始めたら、趣味まで仕事になってしまう。

回復体験は、休日に四つ全部を達成するためのチェックリストではない。

自分に合う休み方を見つけるための手がかりだ。

疲れ切っている日は、眠る。何もしない。
少し元気が残っている日は、好きなことに自分の力を少し使ってみる。
そのくらいでいい。

では、その日の自分に合う休み方を、どう選べばいいのだろうか。ここからは、回復体験を日常の小さな行動に置き換えてみたい。

## 3. 遊ぶほど心が回復する3つの兵法

烏龍が考える、休日に自分のエネルギーを取り戻すための三つの兵法。大切なのは、全部やることではない。今の自分に必要なものを、一つ選ぶことだ。

### 第一の兵法：離れる──朝の光の中を、寄り道する

仕事のことが頭から離れない。休日なのに、月曜日の予定を考えてしまう。

そんな日は、いつもの道から一本だけ外れてみる。近くの公園を通る。木漏れ日を見る。気になった花を一枚撮る。

目的地に早く着くことだけを考えれば、寄り道は非効率だ。でも、仕事から気持ちを離すという意味では、別の価値がある。

朝の光には、体内時計の調整に関わる働きもある。光と暗さの周期は、眠る時刻や目覚める時刻を整える重要な手がかりだ。一般的な昼間活動・夜間睡眠の生活では、朝の明るい光は体内時計を前に進める方向に働くことがある。

ただし、朝日を浴びればその場でメラトニンが増えるわけではないし、公園を歩けば必ず疲れが取れるという話でもない。

ここで大切にしたいのは、光を浴びることだけではない。

歩く道を、自分で選ぶことだ。

いつもなら通り過ぎる小さな店。季節によって変わる木の色。昨日まで気づかなかった景色。

歩数を数えなくていい。運動の成果を記録しなくてもいい。

「今日はこれを見つけた」

そう思えたら、それで十分だ。

### 第二の兵法：満たす──誰かと、手間を分け合う

平日は、誰かの予定や期待に合わせて動くことが多い。人と関わることは大切だけれど、気づかないうちに疲れてしまうこともある。

そんな休日には、安心できる人と、成果を求めない時間を過ごしてみる。

たとえば、一緒に料理を作る。材料を買いに行く。野菜を切る。生地をこねる。少し失敗して笑う。できあがった料理を、ゆっくり食べる。

一人なら30分で済む食事に、二時間かける。効率だけで見れば、遠回りだ。

でも、その二時間には、会話や協力、一緒に過ごした記憶がある。料理を完成させることだけが、目的ではない。一緒に作る時間を楽しむことにも意味がある。

もちろん、人と会うこと自体が疲れる人もいる。そんな日は、一人で好きな料理を作る。いつもより丁寧にお茶を入れる。お気に入りの器を使って食卓を整える。

回復体験の一つであるリラックスは、何もしないことだけに限られない。自分にとって心地よい活動を選ぶことで、気持ちがゆるむ場合もある。

誰かと過ごしたい日は、誰かと。一人でいたい日は、一人で。

何をするかだけでなく、誰と、どんな気持ちで過ごすかを選んでいい。

### 第三の兵法：遊ぶ──役に立たないことに、夢中になる

趣味にまで、成果を求めていないだろうか。

本を読んだら、何か学ばなきゃ。絵を描いたら、誰かに見せなきゃ。得意になったら、収益化できないかな。

気づけば、好きだったことが、もう一つの仕事になっている。

趣味が仕事になるのは素晴らしい。でも、すべての楽しみを利益に変えなくていい。

仕事に関係のない本を読む。誰にも見せない作品を作る。昔好きだった趣味を30分だけやってみる。

上達してもいい。飽きてもいい。何も形に残らなくてもいい。

特に、好きなことに強く引き込まれやすい人にとって、没頭できる時間は大切な楽しみの一つだと、烏龍は考えている。ただ、夢中になりすぎて食事や睡眠を削ってしまうなら、少し工夫してみたい。

終了時刻を決める。途中で休憩する合図を用意する。続きが気になるなら、次にやりたいことを一行だけ残しておく。

それは、集中を責めるためではない。

楽しみを長く楽しむためだ。

遊びは、何かを達成するためだけのものではない。

好きだから、やる。面白そうだから、試す。気が向いたから、もう少し続けてみる。

仕事から気持ちを離したり、小さな手応えを得たりすることもある。でも、遊びが必ず回復につながるわけではない。だからこそ、何をするかだけでなく、いつ終わるかも、自分で選びたい。

「何に役立つか」は、今日は考えなくていい。

## 4. 休みも、人生の本編だ

さて、次の休日。あなたは、どんなふうに過ごしたいだろう。

仕事が頭から離れないなら、少し寄り道してみる。人に合わせ続けて疲れたなら、安心できる人や、自分自身のために時間を使ってみる。何となく退屈で、少し元気があるなら、役に立たない趣味を楽しんでみる。そして、疲れ切っているなら、何もしなくていい。

三つの兵法を全部やる必要はない。休み方を、新しい宿題にしなくていい。

保存版｜休日の小さな作戦リスト

今の自分に近いものを、一つ選んでみてほしい。

【仕事のことが頭から離れないなら──離れる】
・近所を10分歩く
・いつもの道を一本だけ外れる
・気になった景色を一枚だけ撮る

【人に合わせ続けて疲れたなら──満たす】
・安心できる人と、普段作らない料理を一品作る
・用事を決めずに、お茶を飲む
・一人なら、自分のために食卓を整える

【少し元気があって、何か楽しみたいなら──遊ぶ】
・仕事に関係のないものを読む
・誰にも見せないものを作る
・昔好きだったことを30分だけやる

【疲れ切っているなら──何もしない】
・予定を一つ減らす
・必要な睡眠を優先する
・今日は休む日だと決める

全部やらなくていい。一つもできない日があってもいい。

それでも、休日は失敗ではない。

僕たちは、時間を無駄にしない方法をたくさん知っている。でも、人生の最後に思い出すのは、効率よく終わらせた会議だけだろうか。

遠回りして見つけた景色。
誰かと失敗しながら作った料理。
何の役にも立たない趣味に、夢中になった時間。

仕事では無駄に見える時間が、人生では宝物になることがある。

もちろん、仕事も大切だ。約束を守ることも、責任を果たすことも、信頼を積み重ねることも大切だ。でも、そのために人生のすべてを成果へ変換する必要はない。

使える体力も、時間も、集中力も限られている。だからこそ、どこに力を使うかを選ぶ。

休み上手なうさぎは、誰よりも効率よく休日を過ごすうさぎではない。

走る日もあれば、止まる日もある。跳ねたいときには跳ねる。疲れたときには休む。そして、ときには走らず、ただ景色を眺めていてもいい。

自分に合った休み方を少しずつ知り、選び直せること。それこそが、限られた時間とエネルギーを守る兵法だと思う。

賢いうさぎは、走るためだけに休まない。
休みも、遊びも、人生の本編なのだから。

あなたの「何の役にも立たないけれど、好きな時間」は何ですか。散歩でしょうか。料理でしょうか。それとも、誰にも見せない趣味でしょうか。僕は、目的地を決めない寄り道に、うさぎらしい自由があると思っています。よければ、あなたの答えもコメントで教えてください。

うさぎの兵法では、先延ばしや過集中に悩みながらも、自分をすり減らさずに進む選び方を考えています。こうした視点をまた読みたい方は、フォローして次の記事も受け取ってください。

うさぎの兵法｜資源篇
亀にならなくていい。でも、信頼は失わない。
