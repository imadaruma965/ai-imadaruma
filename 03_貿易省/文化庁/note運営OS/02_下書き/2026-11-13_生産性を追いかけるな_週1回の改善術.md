# 生産性を上げたい人ほど、仕事が進まない。
### ──サム・アルトマンに学ぶ「重要な2割」と週1回の改善術

生産性を上げたい人ほど、仕事が進まない。

昨日は、タスク管理アプリを変えた。今日は、時間管理のルールを変えた。明日は、もっと効率のいい方法を探すつもりだ。……で、いつ仕事をするんだろう。笑

僕にも、心当たりがある。仕組みを改善していると、なんだか前に進んでいる気になるんよね。でも、よく考えたら、その間はエンジンが止まっている。

仕組みをいじっている間は、サボっている感覚がない。むしろ、頑張っている気さえする。でも、本当のことを言うと、これは几帳面さじゃない。自分が決めたやり方を、自分でもまだ信じ切れていないだけなんだと思う。

サム・アルトマンのブログ「Productivity」に、僕が気に入った指摘がある。生産性の仕組みを完璧にしようとすることに時間を使いすぎて、そもそも正しい仕事に取り組めているかを、十分に確かめなくなってしまう。彼は、そんな罠に注意を促している。

これを読んで、僕は気づいた。仕組みを疑い続けるのは、仕事への真剣さじゃない。自分の判断を信じられない不安を、改善という形で埋めているだけなんだ。

これは、何も今に始まった話じゃない。孫子も、作戦篇でこう言っている。「兵は拙速を聞くも、未だ巧の久しきを睹ざるなり」──戦は、多少粗くても速く決着をつける方がいい。巧みに長引かせた戦など、見たことがない、ということだ。二千年以上前から、人は同じ罠にはまっていたんだと思うと、ちょっと安心する。

これは、僕が大切にしている「2割思考」ともつながる。仕事を10％速くするより、成果を大きく左右する重要な2割を選ぶこと。そして、2割を選んだあとに一番試されるのは、その2割を、最後まで信じて走れるかどうかなんだ。多少非効率でも、成果を左右する仕事を選んで信じて走れていれば、前には進んでいる。

もちろん、計画や改善が不要という話じゃない。大事なのは、それをいつやるかと、どこまで自分を信じるかなんだ。

**エンジンを回すのは毎日。メンテナンスは週1回。**

そこで僕が使っているのが、PDCA(計画・実行・評価・改善)とOODA(観察・判断・決定・行動)の使い分けだ。これは生産性のテクニックというより、自分を信じる練習に近い。

週末は、整備士になる。一週間を振り返り、成果につながった仕事を確かめ、翌週の重要な2割を選ぶ。そして、一度決めたら、まず一週間はその仕組みを信じて走ってみる。多少、効率が悪くてもいい。小さな不便が見つかるたびに仕組みを疑って変えていたら、信じる前に壊してしまうことになる。

平日は、運転手になる。ここではOODAを使う。目の前の状況を観察し、何が重要かを判断し、次の行動を決めて、動く。急な依頼、作業の遅れ、相手からの修正。そんなときは状況に合わせて対応するが、そのたびに仕組みをつくり直す必要はない。運転中に、毎回エンジンを分解しなくていいんだ。

ただし、納期や約束に影響する問題は別。それは週末を待たずに、その場で対応する。仕組みを守ることより、相手との信頼を守ることのほうが大切だからね。仕組みへの信頼も、相手への信頼も、根っこは同じだと思う。一度決めたことを、簡単には覆さないという態度のことだ。

**速く仕上げるより、方向を確かめる**

これは、僕のデザインの仕事でも実感している。以前は、色も装飾も仕上げてから関係者に確認することがあった。でも、方向が違えば、大きな手戻りになる。そこで今は、まずモノクロのレイアウトを見せる。「この方向で合っていますか？」大切だったのは、制作スピードを上げることじゃない。最初に、正しい方向を選び、そのあとは自分の選んだ方向を信じて手を動かすことだったんだ。

**今日の兵法｜一週間の回し方**

難しいことを、たくさん覚える必要はない。僕なら、次の4つだけ意識する。

1. 週末に、翌週の成果を左右する重要な2割を決める。
2. 平日は、決めた仕組みを信じて走り、OODAで変化にだけ対応する。
3. 小さな迷いはメモして、週末にまとめて見直す。
4. 納期や約束に関わる問題だけは、すぐに対応する。

PDCAとOODAを具体的にどう使い分けているかは、また別の記事で詳しく書きたいと思っている。

野生のうさぎには、バニーフロップという仕草がある。安全だと判断した瞬間だけ、警戒を手放して、ごろんと横になる。ずっと気を張っていたら、肝心なときに動けなくなる。警戒と、手放しを、はっきり切り替えられること。それ自体が、生き延びるための強さなんだと思う。

うさぎに必要なのは、完璧な仕組みじゃない。一度決めたことを、走りながら疑わない強さだ。疑うのは、週末でいい。

エンジンを回すのは毎日。メンテナンスは週1回。

その信頼は、相手にだけじゃなく、自分にも向けていい。

亀にならなくていい。でも、信頼は失わない。

うさぎの兵法｜行動篇
