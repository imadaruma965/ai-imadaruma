# 信頼される人は、完璧じゃない人だった。──建国の父フランクリンの『まだらの斧』に学ぶ、約束を守る3つの関所

反省しても、また同じ失敗をした。

直したのは、性格じゃない。仕組みだった。

「あれ、まだですか」

1ヶ月前に頼まれた、チームウェアの発注。僕は「わかりました、やっておきます」と即答していた。その場では、本当にやるつもりだった。

でも、発注していなかった。別の仕事に気を取られているうちに、メモすることすら忘れていたのだ。

慌てて発注し、頭を下げた。二度と繰り返さないと誓った。

そして、また同じことをした。

今度は言い訳のしようがなかった。相手との関係には、はっきりと距離ができた。

反省はしていた。申し訳ないと思っていた。次こそ守りたいとも思っていた。

それでも、結果は変わらなかった。

このとき僕が変える必要があったのは、性格ではなかった。

約束を受けた瞬間に、何をするかという仕組みだった。

ただ、ここで一つ問題がある。

仕組みを作っても、僕たちは完璧にはなれない。忘れないためのメモを忘れる。確認するための予定を確認しない。できると思って引き受けた仕事が、思った以上に増えてしまう。

それでも、他人との約束には責任が残る。

では、欠点を抱えたままで、どうすれば信頼を守れるのだろうか。

その問いを考えるうえで、200年以上前の、ある人物の失敗が参考になる。

ベンジャミン・フランクリンだ。

## 1. まだらの斧

アメリカ建国の父の一人、ベンジャミン・フランクリン。政治家、発明家、出版人として知られる彼は、若いころ、自分の人格を改善するために「13の徳」というリストを作った。

節制、沈黙、秩序、決断、節約、勤勉、誠実、正義、中庸、清潔、平静、純潔、謙譲。目指したのは、これらを身につけることだった。

ところが、実際に取り組んでみると、思っていた以上に自分には欠点があると気づいた。

そこで彼は、小さな手帳を作った。横には曜日、縦には13の徳目を並べ、1週間に一つの徳だけに意識を集中する。守れなかった日には、該当の枠に黒い点を一つ記す。13週間で全部を一周し、それを1年に4回繰り返す仕組みだった。

面白いのは、徳の並び順にも意味を持たせていたことだ。たとえば、最初に置いたのは節制。飲食を節度あるものにすれば、頭を冷静に保ちやすくなる。次の沈黙は、人の話を聞くことや知識を得ることにつながる。先に身につけた徳が、次の徳を助けるように、あえて順番を設計していた。

ただ「もっと立派な人間になろう」と決意しただけではない。自分が変わりやすい順番まで、構造として組んでいた。

ところが、ここまで仕組みを作っても、どうしても苦手なものがあった。

「秩序」だ。

物を決まった場所に置く。用事に決まった時間を割り当てる。フランクリンは、この徳を身につけることに、特に苦労したと自伝に書いている。

そのくだりに登場するのが、まだらの斧の話だ。

ある男が、斧を磨こうと鍛冶屋に頼む。鍛冶屋は引き受けるが、男自身が砥石を回さなければならない。男は懸命に回すが、斧の表面すべてを磨き上げるのは、思った以上に大変だった。やがて疲れた男は、磨き残しのある斧を、そのまま持ち帰ろうとする。

「まだらの斧でいい」と。

フランクリンは、この男の姿を、自分の欠点に重ねた。完璧な人格を目指しても、思いどおりにはいかない。

実際、彼は徳目の点検を熱心に行った時期があったものの、やがて回数を減らし、最後には記録をつけなくなった。手帳を持ち歩き続けたことと、点検を続けられたことは、同じではない。

それでも、フランクリンは自伝の中で、この試みを無意味だったとは考えていない。目指した完璧さには到達しなかった。しかし、その努力によって、試みなかった場合よりも、よい人間になれたと振り返っている。

ここに、烏龍は大切な違いがあると思っている。

完璧になれなかったことと、何も変えられなかったことは、同じではない。そして、欠点が残っていることと、他人への責任を果たす方法がないことも、同じではない。

もちろん、フランクリンの徳目の記録は、現代の仕事で約束を守るために作られたものではない。ここから先は、彼の考え方を、僕たちの日常に引き寄せた応用だ。

では、まだらのままの自分が、約束を守るためには何が必要なのだろうか。

## 2. 信頼を守る3つの関所

約束には、三つの分かれ目がある。

- 引き受ける前
- 引き受けた直後
- 守れなくなりそうなとき

烏龍が考える、信頼を守るための三つの関所だ。

### 第一の関所：背負う前に数える

「できます」

僕は、この言葉を何度も軽く使ってきた。頼まれた瞬間は、できると思っている。相手を待たせたくないし、期待にも応えたい。

でも、その場で考えているのは、頼まれた仕事そのものだけだったりする。

- ほかに何を抱えているか
- いつまでに終わらせる必要があるか
- すでに引き受けた約束と、重ならないか

そこまで確認していない。

フランクリンは、13の徳を一度に直そうとしなかった。一つずつ、順番を決めて取り組んだ。もちろん、人格を磨くことと仕事を引き受けることは違う。それでも、自分が扱える量を考えるという点には、通じるものがある。

チームウェアの発注を頼まれたとき、僕は、その週に何を抱えていたかさえ数えていなかった。数えていれば、少なくとも即答する前に、一呼吸置けたかもしれない。

だから、最初の関所はこれだ。

新しい約束をする前に、今ある約束を見る。その場で判断できなければ、こう伝えればいい。

「いま抱えている予定を確認してから、お返事します」

すぐに引き受けないことは、不誠実ではない。守れるか分からない約束を、勢いで増やさない。それが、最初の誠実さだと思う。

### 第二の関所：記憶の外に置く

僕の発注ミスで、決定的に抜けていたのはここだった。「わかりました」と答えたものの、そのあと何も記録しなかった。

了承した瞬間の気持ちは、本物だった。ただ、その気持ちは、一ヶ月後まで発注内容を覚えておく仕組みにはならなかった。

フランクリンは、自分の欠点を、頭の中だけで管理しようとはしなかった。手帳に枠を作り、黒い点という形で残した。彼自身も、記憶力に頼れた若いころは秩序の必要性を十分に感じていなかったことを、自伝で振り返っている。覚えていられると思っている間は、記録する必要を感じにくい。

でも、約束は自分の記憶力を試すためにあるわけではない。相手の期待に応えるためにある。

だから、引き受けたら、その場で記録する。

たとえば、チームウェアの発注なら、こう書く。

「11月5日まで｜チームウェア発注｜サイズと数量を確認して注文する」

これだけでも、あとで何をすべきか分かる。

ただし、書けば終わりではない。記録しても、見なければ思い出せない。だから、書く場所は一つに決める。毎朝確認するカレンダーでも、仕事用のタスク管理アプリでもいい。大切なのは、記録を残すことと、記録を見返すことをセットにすることだ。

覚えておこう、ではない。覚えなくても戻れる場所に置いておく。

あの失敗のあと、僕は約束を受けたその場で手を止め、メモを優先するようにした。性格を一気に変えたわけではない。約束を受けた直後の行動を、一つ変えたのだ。

### 第三の関所：遅れる前に知らせる

どれだけ気をつけても、予定どおりに進まないことはある。仕事が重なる。確認が必要になる。思っていたより時間がかかる。

そんなとき、僕たちは連絡をためらいやすい。もう少し進めてから報告しよう。ちゃんとした見通しが立ってから伝えよう。何とか間に合わせれば、言わなくて済む。

そう考えているうちに、時間が過ぎてしまう。

でも、待っている相手にとって困るのは、遅れだけではない。何が起きているのか分からず、次の予定を決められないことも、大きな負担になる。

だから、約束に影響が出ると分かったら、相手から聞かれる前に伝える。

必要なのは、長い言い訳ではない。事実と、現在の状況と、次にどうするかだ。たとえば、こう伝える。

「予定していた発注が遅れています。申し訳ありません。現在、数量の確認まで終わっています。納期を確認し、今日の15時までに改めてご連絡します」

この伝え方なら、相手は何が起きているかを知り、次の判断ができる。見通しが立っていないなら、立っていないと伝えていい。ただし、次に連絡する時刻は、守れる範囲で具体的に決める。

フランクリンが自分の欠点を後年の自伝に記したことと、仕事で遅れを早めに報告することは、同じ行為ではない。ここで学びたいのは、弱点をなかったことにしない姿勢だ。

失敗しそうなときほど、相手に必要な情報を渡す。約束を守れない可能性が見えたとき、責任まで消えるわけではない。むしろ、そこからの行動に、信頼を守る余地が残っている。

## 3. 保存版｜信頼の関所チェックリスト

次に誰かから何かを頼まれたとき、思い出してほしい。完璧な人間になる必要はない。ただ、約束の前後に、小さな関所を置いておく。

**第一の関所｜背負う前に数える**

- 新しい依頼が来たら、すでに抱えている約束と期限を見る
- 引き受けられるか分からなければ、その場で即答しない
- 「確認してから返事します」と伝える

**第二の関所｜記憶の外に置く**

- 引き受けたら、その場で記録する
- 何を・いつまでに・次に何をするかを書く
- 毎日確認する場所に記録を集める

**第三の関所｜遅れる前に知らせる**

- 約束に影響が出ると分かったら、できるだけ早く連絡する
- 遅れの事実と謝罪、現在の状況を伝える
- 分かっている見通しと、次に連絡する時刻を伝える

三つとも一度に身につけようとしなくていい。自分がいちばん失敗しやすい関所を、一つ選んでみる。

- 約束する前に勢いで引き受けてしまうなら、第一の関所
- 引き受けたあとで忘れてしまうなら、第二の関所
- 問題が起きると連絡をためらってしまうなら、第三の関所

どこで失敗しやすいかが分かれば、対策を置く場所も見えてくる。

ここまでは、やり方の話だった。ここからは、少しだけ、考え方の話をしたい。

## 4. まだらのままでいい

あの発注ミスから距離ができた関係は、今もまだ戻っていない。謝っても、反省しても、信頼はすぐには戻らなかった。

これは、仕組みを作れば過去の失敗が帳消しになるという話ではない。忘れやすい事情があっても、相手が受けた影響は消えない。

だからこそ、次の約束をどう扱うかを考えなければならない。

あの一件のあと、僕が変えたことは一つだった。約束を受けたら、その場で手を止めて記録する。

それだけで、僕が完璧な人間になったわけではない。今後、二度と失敗しないと言い切れるわけでもない。それでも、以前と同じやり方を続けることは、やめられた。

フランクリンの斧は、最後までまだらだった。彼は徳目の記録を続けきることもできなかった。でも、そこで考えた仕組みや、自分の欠点と向き合った経験まで、無意味になったわけではない。

僕たちも、きっと同じだ。

苦手なことが、全部得意になるとは限らない。忘れやすさが、ある日突然なくなるとも限らない。

だからといって、信頼を守ることを諦める必要はない。

信頼される人とは、欠点のない人ではない。自分の弱点を知ったうえで、相手への責任を果たす方法を考え、失敗したときにも、その後始末から逃げない人だと、烏龍は考えている。

まだらのままでいい。

ただし、まだらだから仕方ない、で終わらせない。

約束する前に数える。

約束したら記録する。

危なくなったら、先に知らせる。

たった三つの関所でも、次の約束への向き合い方は変えられる。完璧な人間になることよりも、不完全な自分が責任を果たせる方法を、これからも探していきたい。

あなたなら、三つの関所のうち、どれがいちばん抜けやすいだろうか。引き受ける前、記録するとき、それとも連絡するとき。

僕の場合は、第二の関所だった。よければ、あなたの場合もコメントで教えてください。

うさぎの兵法では、自分の性質を知り、戦い方を選びながら、自由と信頼を両立する方法を考えています。こうした視点をまた読みたい方は、フォローして次の記事も受け取ってください。

うさぎの兵法｜信頼篇

亀にならなくていい。でも、信頼は失わない。
