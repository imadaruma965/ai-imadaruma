# 忘れ物にも、先延ばしにも値段がある。──知らないうちに払っている「ADHD税」と7つの兵法

僕は、サッカーの指導へ行くたびに650円を払っている。

高速道路の料金だ。

週6回。4週間で24回。月に15,600円。これが一年続くと、約20万円になる。

でも、不思議なことに、帰り道はいつも下道なんだよね。

行きは時間ギリギリになって高速道路を使う。でも帰りは、時間に追われていないから下道で帰れる。つまり、僕が毎回払っている650円は、距離の問題というより、時間の使い方の問題なんだ。

そして、こんな出費は高速料金だけじゃない。

僕は以前、英会話のサブスクを二つ契約していた。さらに、ダイエット管理アプリのサブスクまで入っていた。契約したときは、どれも本気だった。最初の1〜2か月は、ちゃんと頑張る。でも、いつの間にか別のことに興味が移って、アプリを開かなくなる。それでも、引き落としだけは律儀に続いている。こちらの興味がなくなっても、契約は勝手に終わってくれないんよね。笑

こうした出費には、実は名前がある。

**ADHD税。**

もちろん、本当の税金じゃない。でも、この言葉を初めて知ったとき、僕はずいぶんうまい名前をつけたものだと思った。だって、僕たちうさぎは、何かを買ったわけでも、特別な贅沢をしたわけでもないのに、気づけば時間やお金を失っていることがあるからだ。

今回は、僕自身の失敗談を交えながら、知らないうちに払っている7つのADHD税と、その負担を減らすための7つの兵法を考えてみたい。

## 1. 僕が毎年払っている、約20万円の見えない税金

サッカーの指導へ向かう日。出発する時間は、ちゃんと分かっている。何時までに準備を終えて、何時に家を出れば間に合うのか。もちろん、計算している。

ところが、出かける直前になると、別のことを始めてしまう。気になる仕事を少しだけ片づけよう。あのメールに返信しておこう。さっき思いついたアイデアを、忘れないうちに調べておこう。そうしているうちに、あっという間に時間が過ぎている。

気づけば、予定していた出発時間を過ぎているんだ。まずい。

そこから慌てて準備して、高速道路へ向かう。650円。一回だけなら、まあ仕方ないと思える金額だ。でも、これが週6回。4週間なら24回で、15,600円。52週間続けば、計算上は202,800円になる。年間約20万円。

もちろん、これは一年間ずっと週6回利用した場合の概算で、実際の年間支払額を集計したものではない。それでも、自分で計算してみて驚いた。

約20万円あれば、何ができただろう。新しい勉強ができたかもしれない。仕事に必要な道具を買えたかもしれない。将来のために貯めておくことだってできた。何より、あんなに毎回焦って移動する必要はなかったのかもしれない。

僕は、高速道路を使うこと自体が悪いとは思っていない。時間を買うために高速料金を払うのは、立派な選択だと思う。でも、僕の場合は少し違う。余裕を持って出発するつもりだったのに、結局ギリギリになってしまう。そして、予定外の650円を払っている。帰り道は下道なのだから、少なくとも毎回の移動に高速道路が必要なわけではない。

僕が買っていたのは、速さというより、自分で失ってしまった時間を取り戻すための余裕だったんだ。

一回650円。でも、積み重なれば年間約20万円。こういうことは、きっと僕だけじゃないと思う。

## 2. ADHD税は、意志の弱さだけでは説明できない

ADHD税という言葉を聞いたことがあるだろうか。これは、ADHDの特性に関連して起こりやすい、余計な出費や時間的な損失を表す通称だ。忘れ物による買い直し。支払い忘れの延滞金。解約し忘れたサブスク。締切に間に合わせるための割増料金。医学的に確立された専門用語ではなく、当事者コミュニティなどで使われている言葉なんだ。

もちろん、こうした失敗はADHDのない人にも起こるし、ADHDのある人が全員同じ困りごとを抱えているわけでもない。何でもADHDのせいにするつもりはない。ただ、忘れやすさ、時間の見積もりの難しさ、衝動性、先延ばしなどが重なると、余計な費用が発生することはある。

ここで、僕は一つ考えたいことがある。そのお金は、本当に自分が欲しくて払ったものなんだろうか。

例えば、英会話のサブスク。契約した瞬間の僕は、本気で英語を話せるようになりたいと思っていた。一つ目のサービスを契約する。しばらく使ってみる。そして、別のサービスも気になり、二つ目を契約する。でも、最初の1〜2か月を過ぎると、だんだん開かなくなる。ダイエット管理アプリも同じだった。

大切なのは、最初からやる気がなかったわけじゃないということだ。始めたときの自分は本気だった。でも、その熱量が、数か月後も続くとは限らない。それなのに、契約は続く前提でできている。僕たちの興味は移り変わる。でも、毎月の引き落としは、そんな事情を気にしてくれない。

烏龍は、こうした出費を考えるとき、金額だけを見ていては足りないと思っている。探し物に使う時間。締切直前の焦り。支払いを忘れたときの落ち込み。約束を守れなかったときに傷つく、相手からの信頼。

**僕が守りたい五つの資産は、時間・お金・行動・信頼・健康だ。ADHD税は、この五つに少しずつ影響してしまうことがある。**

だったら、自分を責め続ける前に、まず負担が発生する仕組みを見つけてみたい。

## 3. 知らないうちに払っている7つのADHD税

僕自身の経験と、身近に起こり得る例を合わせて、七つに整理してみた。読みながら、自分にも心当たりがないか考えてみてほしい。

**① 出発が遅れて払う、余計な交通費**
これは、僕自身の高速料金だ。下道で行く予定だったのに、焦って高速道路を使う。一回なら小さな金額でも、繰り返せば大きな負担になる。

**② 買ったことを忘れて払う、二重購入代**
本屋で気になる本を見つけて買う。本棚に置こうとした瞬間に気づく。「あれ？ あったんや」。まったく同じ本が、もう一冊ある。

**③ やる気が消えても払い続ける、サブスク代**
英会話二つとダイエットアプリ。どれも契約したときは本気だった。でも気づけば別のことに興味が移り、契約していること自体が意識から消えてしまう。怖いのは、使わなくなったことより、使っていないことに気づかず払い続けてしまうことなんだよね。

**④ 置き場所を忘れて払う、買い足し代**
ハサミが見つからない。探しても見つからないから、新しいものを買う。ところが、数日後に別の場所から出てくる。

**⑤ 支払いを忘れて払う、延滞金**
支払いの案内は届いていた。でも、あとで確認しようと思って、そのまま忘れる。気づいたときには期限を過ぎている。

**⑥ 先延ばしで払う、特急料金**
あとでやろうと思っていた発注や申し込み。気づけば締切直前で、特急対応や速達配送を選ぶことになる。

**⑦ 予定を忘れて払う、キャンセル料**
約束を忘れて、キャンセル料が発生したり、相手に迷惑をかけてしまったりする。お金なら、また稼ぐことができる。でも、相手の時間や信頼は、お金を払えば必ず元に戻るわけじゃない。この七つ目は、特に忘れたくない。

こうして並べてみると、ADHD税は単なる無駄遣いの話ではないと分かる。時間の使い方、記憶、興味の移り変わり、仕事の進め方。いろいろな場所に、小さな負担が隠れているんだ。

## 4. ADHD税を減らす7つの兵法

ここからが実践編だ。目指すのは、完璧に失敗しない人になることじゃない。忘れても困りにくい。脱線しても戻りやすい。うっかりしても大きな損失になりにくい。そんな仕組みをつくることだ。

**兵法その一　出発時間ではなく、準備開始を知らせる**
高速料金を減らすには、まず出発を遅らせないことが必要になる。出発する時刻にアラームが鳴っても、まだ準備が終わっていなければ遅い。だから、自分が実際に準備へ必要とする時間から逆算して、通知を設定する。出発する時間だけでなく、仕事を切り上げる時間も決めておく。週6回の高速利用を週3回に減らせたら、年間約10万円の差になる計算だ。対策する価値は、数字で見るとよく分かる。

**兵法その二　買う前に、持ち物を確認できるようにする**
同じ本を二冊買ってしまうなら、買う前に確認できる状態をつくっておく。本棚の写真をスマホに残す、くらいでいい。記憶力で解決しようとするより、覚えていなくても確かめられる状態をつくる。僕は、そういう仕組みのほうが、うさぎには合っていると思う。

**兵法その三　サブスクは、始める日に「見直す日」も決める**
これは、以前の僕に一番教えてやりたい兵法だ。契約するときに必要なのは、始める覚悟だけじゃない。やめるかどうかを判断する予定も、同時につくっておくことだ。契約した日に、一か月後のカレンダーへ通知を入れる。確認するのは「今も使っているか」「来月も払いたいか」の二つだけ。興味がなくなることを防ぐのではなく、興味がなくなってもお金が流れ続けないようにする。

**兵法その四　なくさない努力より、探さずに済む配置をつくる**
よく使うものは、置き場所を決めておく。安価でよく使うものに限っては、使う場所ごとに複数置いてしまうのも一つの方法だ。自分の行動を無理に矯正する前に、環境を調整する兵法だ。

**兵法その五　支払いを自動化し、確認だけを残す**
支払い忘れが多いなら、自動引き落としを使う。期限を覚えておく負担を減らせるからだ。ただし自動化すれば終わりではなく、月初などに残高と引き落とし内容を確認する日を決めておく。

**兵法その六　締切を早めるより、途中で見せる**
自分で決めた仮の締切は、本当の締切じゃないと知っているんだよね。笑　だから、全部を完成させる前に、途中で確認してもらう方法を使う。僕がデザインの仕事で取り入れたのは、まずモノクロで構成だけを組み、ディレクターやお客様へ方向性を確認する方法だ。「まず構成だけ組みました。この方向で合っていますか？」。完成してから方向性が違うと分かれば大きな手戻りになるが、構成の段階ならまだ直しやすい。僕が変えたのは、作業スピードじゃない。問題を見つけるタイミングだった。

**兵法その七　約束をした瞬間に、通知まで設定する**
約束をしたら、その場でカレンダーへ登録し、通知も入れておく。あとで登録しようと思わないことが大切だ。もし守れないと分かったら、できるだけ早く相手へ連絡する。忘れないための仕組みと、問題が起きたときの対応。その両方が、信頼を守ることにつながる。

## 5. 見えない税金を、自分の資産に変えていく

ここまで、七つのADHD税と、それぞれに対応する兵法を紹介してきた。一度、整理しておこう。

| 見えない税金 | 減らすための兵法 |
|---|---|
| ① 余計な交通費 | 準備開始と仕事の切り上げを通知する |
| ② 二重購入代 | 買う前に持ち物を確認する |
| ③ 使わないサブスク代 | 契約時に見直し日を設定する |
| ④ 探し物による買い足し代 | 定位置や配置を工夫する |
| ⑤ 延滞金 | 支払いを自動化し、残高を確認する |
| ⑥ 特急料金 | 完成前に途中確認を入れる |
| ⑦ キャンセル料 | 約束した瞬間に予定と通知を登録する |

どの兵法も、特別に難しいことではない。でも、こういう小さな工夫を実際に使える形にしておくことが大切なんだと思う。

今まで当たり前のように払ってきた650円が、少し違うものに見えてくる。英会話やダイエットへの興味が薄れること自体を、無理に責めなくてもいい。ただ、使わなくなったことに気づける仕組みはつくっておきたい。そうすれば、次に夢中になれるものへ、お金を残しておける。

烏龍は、ADHD税を減らすというのは、単なる節約ではないと思っている。自分が本当に使いたいことへ、時間とお金を取り戻すことなんだ。そして、焦りや自己嫌悪を減らし、大切な約束を守れるようにすることでもある。

もちろん、すべてを仕組みだけで解決できるわけじゃない。それでも、一回減らせたなら、その分だけ前へ進んでいる。

時間・お金・行動・信頼・健康。守るべき五つの資産は、何か大きな成功をしたときだけ増えるものじゃない。日常の小さな負担を一つ減らすことでも、守れるものがある。

だから、七つ全部を一度に直そうとしなくていい。まずは、この一か月で余計に払ったと思うお金を、一つだけ思い出してみてほしい。僕なら、まずは高速料金の650円からだ。

あなたが一番心当たりのあるADHD税は、どれだろう。よかったら、コメントで教えてほしい。僕がまだ気づいていない、八つ目のADHD税もあるかもしれないから。

亀にならなくていい。でも、信頼は失わない。

うさぎの兵法では、先延ばしや脱線、過集中、衝動的な行動に振り回されながらも、自分の特性に合う仕組みで、時間・お金・行動・信頼・健康を守る方法を考えています。自分を責めるだけでは変わらなかったことを、仕組みや選び方から変えていきたい。そんな考え方に共感してもらえたら、ぜひフォローして、また読みに来てもらえるとうれしいです。
