## Canvaでの編集方法

1. Canvaのホーム画面で「デザインを作成」→「ファイルをインポート」を選択
2. `..._v4_Canva編集用.pptx` をアップロード
3. 文字、図形、写真を必要に応じて編集
4. 完成後はPDF（標準）で書き出し

## 運用数値の追記方法

実績ページ（p16〜p23）のROLE行の右側に **RESULT欄** があります。現在は「（数値を記入）」というプレースホルダーです。

1. CanvaでPPTXを開く
2. 対象ページのRESULT欄の「（数値を記入）」をクリック
3. 実数を入力（例：フォロワー +1,200／保存率 3.8％）

枠のサイズと位置は固定されているため、文字を差し替えるだけでレイアウトは崩れません。数値が出ていないページは、枠ごと削除しても構いません。
