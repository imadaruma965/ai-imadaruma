## 1. 必須データ項目（OSレコードとの対応）

| 必須項目 | OSフィールド（既存） | メモ |
|----------|----------------------|------|
| 顧客・企業名 | `companyName` | |
| 担当者名 | `contactName` | |
| 連絡先 | `memo` または `sourceUrl` に記載 | 専用欄が無い場合は memo 先頭に `連絡先:` |
| 営業元 | `channel` | 紹介／地域／クラブ／CW／LI 等 |
| 提供サービス | `service` | sound／SNS／リール／ロゴ／AI改善 |
| 案件名 | `companyName`+`service` または memo | |
| ステータス | `status` | 下表 |
| 見込み金額 | `estimatedAmount` | |
| 受注確度 | `winProbability`（0–100%） | OS営業タブで入力。確度加重＝見込み×確度÷100 |
| 最終接触日 | `lastContactDate` | |
| 次回対応日 | `nextActionDate` | **期限超過抽出のキー** |
| 次の行動 | `nextAction` | |
| 提案内容 | `proposalType` + memo | heavy/light/followup |
| 失注理由 | memo（status=lost時） | |
| 入金状況 | `paymentStatus` / `invoiceStatus` | |
| メモ | `memo` | |

### ステータス対応（日本語運用名 ↔ OS）

| 運用名 | OS `status` |
|--------|-------------|
| 未接触 | `candidate` |
| 接触済み | `contacted` |
| （応募済み） | `applied` |
| 返信あり | `replied` |
| ヒアリング／商談 | `meeting` |
| 提案準備〜提案済み | `proposal` |
| 受注 | `won` |
| 保留 | `paused` |
| 失注 | `lost` |

※「提案準備」と「提案済み」はOS上どちらも `proposal`。memo に `準備` / `送付済` を書いて区別する。
