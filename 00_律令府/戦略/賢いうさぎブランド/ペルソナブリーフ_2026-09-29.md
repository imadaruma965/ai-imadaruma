## 1. 英語圏ペルソナ【確定】——Substack「Hare Statecraft」

### 一文

> **41歳。米国または英国・カナダ・豪州の都市圏。デザイン／エンジニアリング／マーケティング／教育のいずれかで働く（会社員・フリーランス双方）。2〜3年前、40歳前後で初めてADHDと診断された——あるいは自分でそうだと気づいた。それまでの人生は「なぜ自分にはこれができないのか」で説明していた。診断は、その説明を全部書き換えた。安堵と、20年分の怒りが同時に来た。仕事はできる。評価もされている。ただし毎年、同じ場所で壊れる。生産性アプリは一通り試して、全部やめた。短い動画では埋まらないものを埋めたくて、長い文章を読む側に戻ってきた。性別は限定しない（ただし遅い診断は女性に多い）。**

## 2. 日本語圏ペルソナ【提案・BOSS未決裁】——X・note

### 一文（第5案 v2）

> **47歳。デザイン・制作の現場で20年以上食べてきた。腕は認められていて、仕事はいまも途切れない——ただし、そのすべてが「誰かがくれた仕事」である。久しぶりに受けた町の健康診断で引っかかった。血圧。スポーツをしてきて健康だけは自信があったから、初めて「年齢」というものを感じた。この働き方は、この体で、あと何年続くのか。一方で、発信したいことも、発信できることも、たくさんある。副業も考えないといけない。ただし自分で決めた計画は、昔から一度も続いたことがない。乗れば誰より速く、乗らない日は何も出せない。**

### 入口の出来事と、二つの欲求

| | 内容 | 数字 |
|---|---|---|
| **入口** | **健康診断の結果票**（届いてから2週間） | 定期健診の有所見率 **2024年59.4%**／うち血圧 **18.4%**（30年で倍）【B】。ミドルクライシス要因1位＝老化・体力の衰え63.3%【B】 |
| 欲求1 | **発信したい／発信できる** | 会社員の副業経験39.2%・**今後66.7%が「始めたい」**。一方40代の実施は17.8%、50代8.8%【C】＝**意向と実施の差が市場** |
| 欲求2 | **自分の名前で仕事が来る状態** | 「今はこうやって仕事をくれるが」＝**依存の自覚** |

## 3. 両方に共通する機構（コピーの骨）

```
評価される場所を避ける → 締切が近づくと着手する・速い → 「これで出す」と決められない
→ 終わらない → 未完了が、次の着手を重くする → 最初へ戻る
```

【A】Steel 2007（課題の嫌悪性が最強の予測因子）／Sirois et al. 2017（先延ばし×完璧主義的懸念 r=.23, k=43, N=10,000。**効果は性別で変わらない**）／Leroy 2009（未完了タスクの注意残余）／Kaiser 2022（**知識は行動をほとんど動かさない。+0.06〜0.10SD**）

## 4. 動かせない線（法と倫理）

| 守る | 根拠 |
|---|---|
| **読者を診断しない**（「あなたはADHD」「ADHD度チェック」を作らない） | 医師法17条・L4' |
| **恐怖で締めない**（「このままでは10年後」） | L5' |
| **人を攻撃しない。**攻撃するのは**神話**（亀神話・「継続は力なり」）と**自分**。**亀は笑わない** | L7' |
| **効果を断定しない**（治る・改善する・成果が出る） | 薬機法66条・景表法／FTC |
| 健康は「入口」に使ってよいが「出口」にしない（改善を約束しない。医療は医療へ） | 同上 |
