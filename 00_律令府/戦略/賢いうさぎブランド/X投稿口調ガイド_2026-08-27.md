## 背景（なぜ分けるか）

初稿（AI正篤案）は言い切り（常体）で最後まで押し通し、「発表文」のように冷たく読めた。BOSSがChatGPTで添削した版は、結びだけ敬体（です・ます）に切り替え、問いかけの形で読者を招いており、これが温度差の正体だった。以後はこの型を標準とする。

## 口調規定

| 項目 | 規定 |
|---|---|
| **基本文体** | 常体（だ・である／体言止め）で運ぶ。事実と決意は言い切る |
| **結びだけ敬体に開く** | 投稿の最後の1〜2文だけ「です・ます」に切り替え、断定から招待へ温度を変える。**断定→開放**の型を毎回固定する |
| **二人称** | 「あなたへ」等の直接呼びかけはしない。問いかけの形（例:「そう思ったら」）で間接的に届ける |
| **自虐との距離** | 三日坊主・後回しは事実として書くが、卑下や自罰では終わらせない。次の一文で必ず「動いている今」に戻す |
| **絵文字** | 🐇を結びに一つだけ。感情の起伏には使わない |
| **ハッシュタグ** | 原則なし。使う場合も最大1個 |

## 口語化の追加調整（2026-08-28追加）

LINEスタンプ発売告知の投稿で、BOSSより「もう少し柔らかく、口語体で」との指示。常体一本槍ではなく、**「〜してます」「〜なんだなあ」のような話し言葉の語尾を、要所で混ぜてよい**ことを追加する。

- 断定→開放の型（結びで敬体に開く）は維持する
- 常体は基本形のまま。ただし「思いつきで作り始めたキャラクターが」のような硬い言い回しより、「まさか本当に『商品』になるとは」「気づいたら16個、できてました」のような**話し言葉の勢い**を優先してよい
- 参加型投稿（読者への問いかけ）では、質問文もできるだけ口語的にする（例:「気になる一言、ありますか?」）

## 江戸の香りの扱い（2026-08-27追加・方針転換）

初稿時点では「本文（告白）とスタンプの江戸弁は別の層」として切り分ける案を提示したが、BOSSの好みにより方針転換。**江戸の香りを、キャラ設定・ファンブランディングとして本文にも入れる**ことを正式採用する。

- ただし全面的な江戸弁（「〜だぜ」「〜ねぇ」の連発）にはしない。**「ちょいと」「〜すぎた」「やらかす」のような、砕けた自嘲・軽い江戸言葉を一筋だけ**混ぜる程度に留める
- 目的は告白としての生々しさを壊さないこと。**香りが強すぎて「演じているキャラ」に見えたら、その回は薄める**
- 結び（断定→開放の型）は江戸の香りより優先する。敬体への切り替えという温度の要は崩さない
- 適用例：「ちょいと後回しにしすぎた」「数えきれないほどやらかしてきた」（初投稿改訂版で採用）

## 事実の扱い（誤読防止）

- 「AI初心者」という表現は使わない。**「昨年10月からAIを使い始めた」**という時系列の事実で語る
- 月商50万円は、**既存事業ではなく新しく立てる副業軸**であることを明記する。誤読させない

### 江戸の香り反映版（2026-08-27・BOSSがXをPremium化したため確定採用）

```
25年、人のブランドをつくってきた。
自分の人生だけは、ちょいと後回しにしすぎた。

49歳。三日坊主も、数えきれないほどやらかしてきた。

昨年10月に使い始めたAIと、
今度は自分自身を設計し直してみる。

目標は、11月末までに、新しい副業で月商50万円。

うまくいった日だけでなく、
迷った日も、転んだ日も、ここに正直に残します。

葦なる刃は、静かに尖れる。

「自分も、そろそろ変わりたい」
そう思ったら、一緒に始めませんか。🐇
```

改行込みで約220字（X重み付けで約400超）。当初は無料枠（実質280ポイント≒日本語約140字）を超過していたが、**BOSSがX Premiumへアップグレードしたため（長文投稿25,000字が上限）、この版をそのまま初投稿の確定稿とする**。

### （参考・不採用）無料枠向け整理版

```
25年、人のブランドをつくってきた。
自分の人生だけは、ずっと後回し。

49歳。三日坊主も数えきれない。

昨年10月からAIを相棒に、
自分を設計し直す。

11月末までに、新しい副業で月商50万円。

迷った日も、正直に残します。

葦なる刃は、静かに尖れる。
一緒に始めませんか。🐇
```

概算：改行込みで約145字、X重み付けカウントで約265〜270（上限280）。江戸の香りは分量を絞り「ずっと」程度の軽い調子に留め、無料枠内に収めることを優先した。**文字数に余裕がない前提のため、今後の投稿でも江戸の香りは1箇所・数語に限定するのが安全**。
