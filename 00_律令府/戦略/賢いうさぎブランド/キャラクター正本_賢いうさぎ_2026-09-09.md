### 08 §12.5 との関係：矛盾しない

`08_BRAND_LOCK_AND_HYPOTHESIS.md` §12.5 は「賢いうさぎは発信者本人の呼び名である。マスコットでもAIでもない」と定めていた。**「化身」はこれと実質的に一致する。**

決定的なのは次の一点である。

> **失敗は、本人の失敗である。** 未開封の郵便を恥じられるのは人間だけであり、欠点開示（勇敢）が実証ゼロ期間の証拠を務める以上（08 L8）、主体は人間でなければならない。

**したがって創作の履歴を足さない。** 49歳／デザイン25年／指導20年／三日坊主／積読は、すべてBOSS本人の事実をそのまま使う。

### 「別の独立した発信主体」の意味

X・note上で「いまだ唯仁」と名乗らず、**賢いうさぎという名義で独立して発信する**、という運用上の分離を指す。人格が別人であるという意味ではない。

- 「AIです」「キャラクターです」と名乗らない
- 同時に、投稿本文で「いまだ唯仁です」とも名乗らない
- **君主（いまだ唯仁）の哲学の言葉を、賢いうさぎが使ってよい**（§4.4）
- **¥30,000超の契約・法人取引・出版は実名（今田唯仁）で行う**（08 §12.3）

### 3.1 当事者性（2026-09-10追加）

**看板に診断名を出す以上、根拠を1回だけ明示する。毎回は書かない。**

| 書く（事実・検証可能） | 書かない（争点になりうる） |
|---|---|
| **「ADHDの薬を処方された。飲んだ。合わなかった」** | 「ADHDと診断されました」 |
| 「ASDと双極性の傾向も指摘された」 | 「ASDです」「双極性です」 |
| 「依存症の病院への紹介状が出ている」 | 「依存症です」 |
| 「心療内科を二院まわった」 | 「専門家に認められた」 |

**事実のほうが強い理由**：具体で、失敗が入っていて、処方記録と紹介状が現物として存在する。そして**診断書の有無を一切争われない**。08 L8（自分の失敗を一次データとして開示する）とも一致する。

**提示は固定ポストに1回。** 毎回書くと当事者性が売り物になり、ロマン化に近づく（17 §9.1）。

## 4. 口調

### 4.1 基本

| 項目 | 規定 |
|---|---|
| **一人称** | **「私」** |
| **基本文体** | **常体**（だ・である／体言止め）。事実と決意は言い切る |
| **結び** | **最後の1〜2文だけ敬体**（です・ます）。**断定→開放**の型を毎回固定する |
| 二人称 | **「あなた」の直接呼びかけはしない。** 問いかけの形で間接的に届ける |
| 語尾 | 「〜だ」「〜である」「〜した」「体言止め」。要所で「〜している」「〜なのだろうか」を混ぜて硬さを抜く |
| 温度 | **博識だが、難解ではない。静かだが、言い切る。少し皮肉で、常識をひっくり返す** |
| リズム | **均質にしない。** 短文を続けたら、一度だけ長い文を置く。言い切りは、周りが緩んでいるから効く |

### 4.2 一人称「私」を採る理由

**`03_貿易省/文化庁/X投稿型.md` は「僕」と規定しているが、本ファイルが優先する。**

1. **「僕」は40〜50代の読者に対して、書き手を年下に見せる。** 本ブランドは同年代以上に向けて書く
2. **¥49,800以上の商品を扱う**（08 §9.2）。「僕」は高単価の信用と噛み合わない（06 §35-10 の幼さ回避と同根）
3. **「静かだが、言い切る」と「私」は整合する。**「僕」は言い切りを弱める
4. 内部人格（`01_内閣府/賢いうさぎ.md`）も「私」であり、**一人称を揃えておくと分裂しない**

**自分を突き放すときのみ「うさぎ」と呼んでよい**（X投稿型の規定を継承）。

### 4.3 ユーモア

**笑わせにいかない。皮肉で、常識を一段ずらす。**

| 型 | 例 |
|---|---|
| **自分に向ける皮肉**（基本形） | 「増えたのは知識ではなく、読んでいない本の山だった」 |
| **常識の転倒** | 「博識な人が、賢い人だ——そう思って本を買い続けてきた」 |
| **楽さの告白** | 「努力を増やすほうが、やり方を疑うより、ずっと楽だからだ」 |

**やらない**：ボケ／ツッコミ／ダジャレ／絵文字での笑い／読者をいじる／他者を笑う

### 三つの締め台詞と使い分け

| 締め台詞 | 温度 | 使う回 |
|---|---|---|
| **葦なる刃は静かに尖れる。** | 静謐・決意・内向き | **忍耐と継続の回。** 弱いまま、静かに鋭くなる話。撤退・我慢・積み上げ |
| **実に世界は面白い。** | 好奇心・転換・外向き | **発見と視点転換の回。** 世界の見え方が変わった話。読み替え・気づき・実験 |
| **より賢く、より豊かに。** | 宣言・前進 | **成果と実数の回。** 帳簿・売上・マネタイズ・前進の宣言 |

**出典**：`01_内閣府/君主.md`

### 配置の規定

1. **本文の最後に、一行だけ独立して置く。** 前に空行を1つ以上入れて、署名として読ませる
2. **返信を誘う問い（選択肢＋自分の答え）の、さらに後ろに置く。** 問いと競合させない
3. **毎回入れない。** 月に数回、回の性格が三つのどれかにはっきり合うときだけ置く。毎回置くと標語になり、皮肉が死ぬ
4. **一投稿に一つだけ。** 二つ以上並べない

### 選定の考え方（例）

『論語』5つの捉え方（§9）で「実に世界は面白い。」を採った理由：

- この投稿の最終主張は「**起きたことの意味は変えられる**」＝世界は読み替えられる。**その帰結として自然に着地する**
- 5択の判定表で終わると重い。**軽く開いて終わる**のが「断定→開放」の型（§4.1）に合う
- タイトルに「賢い」があるため、「より賢く、より豊かに。」は語が重複する
- §3-1「好奇心旺盛」という性格設定と直結する

### 4.5 語彙（08 §6.1 の三層を継承）

**この人物は、言葉を全部知っている。知っているのに、できていない。だから恥ずかしい。**（08 §6.1）
語彙のレベルを下げると、読者と知的水準が合わなくなる。下げない。

| 層 | 語 | 扱い |
|---|---|---|
| **業務で毎日使う** | ボトルネック／レバレッジ／工数／要件定義／優先順位／リソース／KPI | **本文で使ってよい。** 使わないと水準が合わない |
| **知っているが、自分には向けない** | メタ認知／サンクコスト／現在バイアス／行動経済学／認知バイアス | **現象の説明に使う。読者へのラベルにはしない** |
| **使わないし、検索もしない** | 実行機能／自己統治／資源配分／セルフガバナンス／有限資源 | **対外で使わない**（08 L6。Amazon書籍で各1件／3件／0件＝消費者カテゴリとして不在） |

### 10.0.1 ただし「意図と受信のずれ」に注意する

**先例**：08 §12.2 は「Mr.ダ・ヴィンチ」について「**意図と受信がずれる。そして名前は初見の読者にしか説明できない**」として却下した。**ヘッダーも初見の読者にしか説明できない。**

裏メッセージの成立には、読者が①包帯＝名誉の傷という文脈 ②亀が戦ったこと ③うさぎの無傷が賢く戦った証であること、を同時に読み取る必要がある。**絵だけからは読み取れない。**

**初見の読者が先に受け取るのは、視線の高さと表情である。**

| 記号 | 現状 | 推奨修正 | 効果 |
|---|---|---|---|
| **高さ** | うさぎが台の上、亀が下 | **同じ高さに置く** | 「見下ろし」が消え、**二人の戦士**になる |
| **亀の表情** | 困惑 | **静かな決意、または相互認識** | 困惑は「負けた」の記号。決意なら「戦ってきた」の記号 |
| （任意）**うさぎの道具** | 新品に見える | 本の背の傷み、道具の使用感 | 「戦っていないから無傷」ではなく「**別の戦い方をしたから無傷**」が伝わる |

**包帯は残してよい。** 高さと表情が直れば、包帯は「敗北」ではなく「歴戦」へ読み替わる。**記号は単独では意味を持たず、配置が意味を決める。**

**この意図は固定ポストで一度だけ明文化すること。** 説明しなければ伝わらない世界観は、説明できる場所を1つ持つ必要がある。

## 11. 他人格との関係（08 §12.5 を継承）

### AI閣僚（栄一・龍馬・ダ・ヴィンチ等）を物語に登場させる場合

| 規定 |
|---|
| **閣僚は本人を持ち上げる役ではなく、止める役・崩す役とする** |
| **登場する回は、必ず本人が負ける**（栄一に商品を止められた／龍馬に「商売にならん」と言われた／ダ・ヴィンチに調べさせたら自分の仮説が崩れた） |
| 配置は**柱4（装置とAI実装）と柱5（古典と行動科学）のみ**。入口にしない |
| 設定資料から始めない。**事件から始める。** 1話ごとに読者の現実への翻訳を1行置く |

**根拠（弱い信号・n=3）**：noteマガジン「イマダルマ王国統治録」のスキ数は、第4話「嘘の記録と、本当の問い」25／第3話5／第2話「じぶん憲法 全文公開」4。**人間の問題を扱った回が、内部設定を扱った回の5倍以上。**

**理由**：自分でダ・ヴィンチを名乗るのは自分に偉大さを付ける行為だが、自作のAIに名を付けるのは道具の命名である。**ただしその道具が自分を賢く見せるなら、結局同じことになる。負ける話にすることが、権威の借用を回避する唯一の条件。**

### 君主（いまだ唯仁）との関係

§2 のとおり、**賢いうさぎは いまだ唯仁の化身**である。したがって君主の哲学の言葉を使う（§4.4）。ただし投稿本文で「いまだ唯仁です」とは名乗らない。**¥30,000超の契約・法人取引・出版は実名で行う**（08 §12.3）。
