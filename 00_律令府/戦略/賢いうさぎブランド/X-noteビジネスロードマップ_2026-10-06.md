## 1. ブランドの核(全体を束ねる一文)

**欠点を直すより、尖る場所を設計する。**(＝偏りを勝ち筋に変える)

ブランドコピー案:「丸くならずに、勝ちにいく。」

この一文がすべてのコンテンツ・商品の上位に立つ。どのテーマを扱うときも「これは、うさぎ型が成果を出すためにどう役立つのか」を通過させる。通過しないテーマは出さない。

## 2. テーマの3本柱

| # | 柱 | 扱う範囲 |
|---|---|---|
| 1 | 自分を扱う兵法 | ADHD型・内向型・飽き性・過集中・衝動性・先延ばし・完璧主義・休み方・お金・人間関係。偉人伝もここに属する |
| 2 | 成果を出す兵法 | 仕事の進め方・タスク設計・集中・時間管理・発信・文章・X・note・商品設計・収益化 |
| 3 | 伝わる兵法 | デザイン・AI・世界観・ブランディング・マーケティング。**ただし「ChatGPTの使い方10選」のような一般的なAI/デザイン講座にはしない。「うさぎ型が、自分の考えや強みを伝わる形にするためにAI・デザインをどう使うか」に必ず限定する** |

3本柱を束ねる統合コンセプト:**「尖らせる研究」**。自分の尖りを見つける→偉人から尖り方を学ぶ→尖りを仕事に変える→尖りを発信・ブランド・デザインに変える→AIで尖りを増幅する→尖りが伝わるマーケティングを作る、という一本の流れですべてのテーマがつながる。

## 3. 収益導線(ファネル)

```
X(短い気づき・偉人エピソード・バズ投稿、認知獲得)
  ↓
note無料記事 3本(世界観・偉人伝・実用、信頼構築)
  ↓
note有料記事 1本1,000円(偉人伝軸、深い価値)
  ↓
メンバーシップ 月1,000円「うさぎの兵法研究室」(継続関係)
  ↓
(偉人10人たまったら)総集編 3,000〜5,000円
```

### X→noteの役割分担(重要)

- **X＝仮説・フック・要点・反応テストの場**。この人は何が尖っていたか/どんな行動特性があったか/欠点をどう成果に変えたか、を短く出す
- **note有料＝背景・失敗・研究・具体例・設計・実践まで深掘る場**。行動特性が具体的にどこで出たか/何が失敗・成果につながったか/時代背景/現代のうさぎ型への置き換え/真似してはいけない部分/自分ならどう設計するか
- Xで反応が良かったテーマを、3〜5倍深くしてnote化する。**Xの再録(コピペ有料化)は絶対にしない**。Xは入口、noteは完成版

## 4. note無料記事(3本固定)

| # | テーマ | 内容 |
|---|---|---|
| 1 | うさぎ型とは何か | 思想の入口。飽きる・ハマる・脱線する・締切前に火がつく・こだわる・衝動で動くという特性を、欠点でなく「使い方次第で武器になる性質」として整理する。プロフィール固定記事と兼用可 |
| 2 | 無料の偉人伝(推奨:レオナルド・ダ・ヴィンチ) | テーマ:「完成できない人が、なぜ歴史に残るほどの成果を出せたのか」。構成:どんな偏りがあったか→何に困ったか→その偏りが何を生んだか→現代のうさぎ型は何を持ち帰れるか。「この人の偉人伝なら1,000円払っても読みたい」と思わせる役割 |
| 3 | 実用記事 | すぐ使えるもの。例:「その休憩、休憩じゃない。空憩という休み方」「優先順位をつけても動けない人へ。タスクには重さがある」 |

## 5. note有料記事(1本1,000円・偉人伝軸)

|---|---|

| ダ・ヴィンチ | 好奇心、脱線、未完成 |
| エジソン | 試行回数と失敗耐性 |
| フランクリン | 多才と自己設計 |
| ダーウィン | 一つの問いを長く抱える力 |
| ニュートン | 極端な没入 |
| アインシュタイン | 常識から離れて考える力 |

### 毎回の型(固定)

この人の尖り → 失敗した場所 → 成果につながった場所 → 真似してはいけない部分 → 現代のうさぎ型ならどう使うか → 具体的な設計

歴史を売るのではなく、**偉人の人生から、自分の勝ち筋を持ち帰ること**が商品。

## 6. メンバーシップ「うさぎの兵法研究室」(月1,000円)

**名称確定:うさぎの兵法研究室**(「うさぎの兵法Z」等は何をする場所か分かりにくいため不採用。「研究室」は研究途中・仮説・実験・失敗・考察・資料・音声・議論のすべてが自然に収まる器になる)

### 6本柱

| # | 柱 | 内容 |
|---|---|---|
| 1 | 新作有料記事の期間限定閲覧 | その月の新作有料記事(単品1,000円)を、メンバーは公開から30日間、追加料金なしで読める。期間終了後は単品1,000円に戻る(永久保存したい人は単品購入するため、単品販売も共存できる) |
| 2 | 研究メモ | 記事になる前の思考。300〜800字程度。「今日◯◯を調べていて、一番気になったのはここだった」等、考えている途中そのものを見せる |
| 3 | 記事では削った話 | 本編に入らなかった逸話、結論が出なかったこと、反対の解釈、偉人の失敗談、執筆中に迷った部分 |
| 4 | うさぎ型への実践ワーク | 偉人の話を、読者自身の人生に戻す問い。例(モーツァルト回):今、自分が衝動で始めたものを3つ書く→今の主戦場につながるのはどれか→捨てるのはどれか→今週どこに勢いを使うか |
| 5 | うさぎの兵法ラジオ(音声・メンバー限定) | 2種類。①**有料記事の音読+補足**:通勤・家事・就寝前など「読む時間がない人」向け。単なる朗読でなく「ここは記事では書かなかったが」「実はここが一番伝えたかった」という音声限定の補足を必ず足す ②**完全音声限定の研究室ラジオ**(10〜20分):今週調べた偉人で一番面白かった話/最近のX投稿の反応が良かった理由/うさぎ型として今困っていること/記事になる前の仮説/没になったテーマ/今考えている勝ち筋/読者からの質問への回答。記事が「完成した答え」なら、ラジオは「考えている途中」 |
| 6 | 研究参加 | 次に扱ってほしい偉人・テーマ、今困っていることを読者に聞き、実際に記事へ反映する。読者を「読者」から「研究室の参加者」にする仕掛け |

**記事とメンバーシップの違い(要点)**:単品1,000円は「完成した答えを買う」。メンバーシップ月1,000円は「新作を先に読み、考える過程を見て、自分に応用し、研究にも参加する」。

## 6-2. noteマガジン構成（2026-11-10新設・BOSS決裁）

note記事を束ねるマガジンを、読者の悩み（資産）で分ける。**時間・お金・行動・信頼・健康・キャリア**の6つ、全マガジン。

| マガジン | 想定する読者の悩み（[発信コンセプトメモ](発信コンセプトメモ_2026-10-18.md)§②④⑤より） |
|---|---|
| 時間 | 締切直前にならないと動けない、時間感覚が人と違い遅刻や見積もりの甘さを繰り返す |
| お金 | 現時点ではペルソナ調査上の直接的な裏付けは薄いが、BOSS決裁で確定維持。将来、投資・資産運用を扱う |
| 行動 | やる気はあるのに大事なことほど続かない、衝動的に動いて後悔する、考えすぎて動けなくなる（ADHDの核） |
| 信頼 | 約束や期限を守れず信頼を失う、将来孤立するのが怖い、信頼を裏切るのが怖くて挑戦を避ける（最も根拠が厚い） |
| 健康 | ADHD診断・服薬・心療内科への相談しづらさ、感情の起伏、「診断がつかなかったら怠けているだけが確定する」という最深層の恐怖 |
| キャリア | 頑張っても評価されず不真面目だと誤解される、自分に合わない仕事のやり方を正解だと思い込んできた、自分の特性でも勝てる場所を探している。将来、サラリーマン・起業家・フリーランサーを問わない人生謳歌のキャリアデザインを扱う |

**「守るべき5つ」と「選び直す1つ」（2026-11-10追記・BOSS決裁）**：時間・お金・行動・信頼・健康の5つは、何を選ぶときも手放さない土台（＝守るべき資産）。一方キャリア（今どの仕事をするか、どの肩書きで戦うか）は、この5つとは性質が違う。状況によっては思い切って手放す対象にもなる（＝時として選び直す資産）。守るものと、時として選び直すものを混同すると、辞めるべき場所にしがみついたり、逆に守るべきものまで差し出してしまったりする。6マガジンの構成自体は変えないが、記事内で「資産」に言及するときはこの5対1の区別を踏まえる。

**決定の経緯**：
- 当初「六つの兵法（思考篇・選択篇・行動篇・資源篇・対人篇・信頼篇）」をそのままマガジン名にする案があったが、読者は「手法」でなく「自分のどの悩みが解決するか」でフォローを決めるため不採用（内向哲学の「唯一無二性＝プロフィールで読まれる」という知見とも整合）
- 思考篇・選択篇は専用マガジンを持たない。記事の中身が結局どの資産を守る/得る話かで、6マガジンのどれかに入る（例：「手放し思考」は時間、「2割思考」は行動）
- 対人篇は信頼マガジンに内包。対人系の記事（少数と深く付き合う戦略など）も信頼マガジンに入れる
- 全記事アーカイブ用の「兵法マガジン」は新設しない。noteのプロフィールは標準機能で全記事を時系列表示するため、同じ役割のマガジンを重ねる必要がない
- マガジン名は「時間を守る」のような動詞固定でなく、資産の名詞のみ（時間・お金・行動・信頼・健康・キャリア）にする。将来「得るべき資産」（増やす・築く等）の記事が増えても名前を変えずに済む
- 「キャリア」は2文字統一（候補：生業）より検索ワード優先を採用。「キャリアデザイン」は実際に検索される言葉だが「生業」はほぼ検索されないため
- ベンチマーク実例（内向哲学メンバーシップのマガジン一覧、2026-11-10BOSS提示のスクリーンショット）でも6マガジン程度の構成が実際に運用されており、数として妥当

**記事の署名欄（「うさぎの兵法｜○○篇」）は変更しない**。マガジン（資産＝読者の悩み軸）と篇（手法＝兵法の軸）は別レイヤーとして併存する。

**留意点**：お金（投資・資産運用）・キャリア（雇用形態を問わないキャリアデザイン）は、現行のコアターゲット（[発信コンセプトメモ](発信コンセプトメモ_2026-10-18.md)タイプ2b・ADHD当事者傾向の上昇層）の痛みとしての裏付けが他の4資産より薄く、より広い読者層にスコープが広がる含みがある。入口（ADHD当事者の自己統治）とこの2マガジンの関係は、別途整理が必要。

**将来候補（2026-11-10メモ）**：内向哲学（月150万円実績）のマガジンは「実践の書」「内哲視点」のようにフォーマット軸（実践ワーク系／思想エッセイ系）でも分けており、同じ資産の中でこの軸を重ねる発想は、有料化・記事数が増えた段階で再検討する価値がある。今はまだ記事数が少なく細かすぎるため採用しない。

## 7. 当面の実行順序(無理なく収益化を遅らせない順番)

1. note無料記事3本を完成させる
2. 直後に、有料偉人伝を1,000円で出す
3. 有料記事が3〜5本たまり、複数購入する読者が現れたら、メンバーシップ「うさぎの兵法研究室」を開始する
