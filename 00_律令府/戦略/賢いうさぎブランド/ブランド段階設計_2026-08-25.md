# 賢いうさぎ ブランド段階設計（Holiday型の順序を国家版に翻訳）

> **日付**: 2026-08-25
> **提出**: 情報省 AIダ・ヴィンチ → 執行官／律令府
> **状態**: 設計案。ゲートA〜C（`davinci_note_research_gate_2026-08-19.md`）は未通過であり、本書は「特定できた後に、どの順で名乗るか」の設計である。段1の着手可否は執行官決裁。
> **前提**: G4四掛け（ADHD気質×AI×システム設計×東洋哲学）は2026-08-24にBOSS決裁で第一候補。

## 0. なぜ順序の設計が要るのか

Daily Statecraft（2026年4月〜、8ヶ月9記事フォロワー10人）は、名前が悪かったのではない。**Ryan Holidayの第5段階を第1段階として実行した**ことが失敗の構造である。

| Holiday | 年 | 売っていたもの |
|---------|-----|----------------|
| Robert Greene弟子入り／American Apparelマーケ責任者 | 〜2011 | 実務の実績 |
| 『Trust Me, I'm Lying』 | 2012（25歳） | **自分の専門領域の実録** |
| 『Growth Hacker Marketing』 | 2013 | 実務者向けマニュアル |
| 『The Obstacle Is the Way』 | 2014 | ストア派を高パフォーマー向けに翻訳 |
| **『The Daily Stoic』** | **2016** | **哲学を日々の判断に** |

さらに最初の読者1万人は Daily Stoic ではなく **Reading List Email（本の推薦）** で獲得している。世界観ではなく、読者に即座に有用なサービスで名簿を作り、その上に哲学を乗せた。現在32万人（2024年9月時点・前年比約50%成長）。

**含意**: 哲学は5冊目に置く。ただし**哲学的信頼は1日目から積む**——ただし「名乗る」のではなく「読んでいる量で漏らす」形で。

## 1. 名乗りの原則（全段階に適用）

> **証明できた順にだけ名乗る。名乗りは証明の後に来る。**

BOSSが取りたい4つのポジションを、証明可能な順に配置する。

| ポジション | 証明の方法 | 名乗ってよい段階 |
|-----------|-----------|-----------------|
| ADHD気質（飽き性） | 実録そのもの。証明は不要（開示するだけ） | **段1から**（診断名は使わない） |
| AI設計の専門家 | 実験で毎回、動くものを作って見せる | **段1から**（名乗らず実演で示す）→ 段2で名乗る |
| 東洋思想の研究者 | 引用の精度と量。原典に当たっている痕跡 | **段1から漏らす**（名乗らない）→ 段3で名乗る |
| 自己統治論を体系化した人 | 体系が他人に再現された事実 | **段3のみ** |

**禁則**: 段1で「東洋思想の専門家」「自己統治論の体系」を名乗ること。これはDaily Statecraft失敗の再現である。

## 2. 「研究者のニュアンス」を段1から作る機構

Holidayの Reading List Email に対応する国家の資産＝**蔵書システム**（`03_国家叡智/`）とアショーカの研究。これを使い、権威を主張せずに研究者性を漏らす。

### 機構A：締めの一行に原典を当てる（主たる手段）

実験の結果を、原典の一節で言い直して終わる。**解説はしない。出典だけ書く。**

例（形式の見本。実際の文言は正篤が起稿）:

- 「三日で飽きた。『大学』に *物に本末あり、事に終始あり* とある。順序を間違えたのは、私ではなく設計の方だった。」
- 「ChatGPTに計画を出させて、何も実行しなかった。王陽明の *知行合一* ——知って行わないのは、まだ知っていない。」
- 「今月の実験は3つ全部小さい。二宮尊徳の *積小為大*。大きいのを一発当てる設計を、私は最初から持っていない。」
- 「撤退基準を先に書いた。尊徳の *分度*。身の丈を先に決めておかないと、飽きた時に引き際が判断できない。」

**なぜこれが効くか**: 読者は「この人は原典に当たっている」と理解するが、講義されていない。主語は最後まで実験である。Holidayが『The Obstacle Is the Way』でやったのと同じ操作。

### 機構B：読書ログを独立させる（Reading List Email 相当）

実験ログとは別に、**読んだものを短く出す枠**を持つ。これが段3で「専門家」を名乗る資格の実体になる。

- 対象: 東洋古典＋脳機能／行動経済学の両方（`03_国家叡智/脳機能/` 6冊は既にある）
- 形式: 一冊につき「採用した一点／棄却した一点」。国家の蔵書フォーマットをそのまま公開形に落とす
- 効果: 「ADHD本を読み漁っている当事者」と「原典を読む人」が同一人物であることが、自然に示される

### 使ってよい原典（国家に既にある正典）

| 出典 | 概念 | 当てる先 |
|------|------|---------|
| 『大学』 | 修身斉家治国平天下／物有本末 | 自己統治そのものの正典。順序の設計 |
| 王陽明 | 知行合一 | **計画だけ立てて実行しない問題への直撃** |
| 二宮尊徳 | 積小為大／分度／推譲 | 小さな成功の連打／撤退基準／還元 |
| 老荘 | 無為自然 | 摩擦最小化の設計。力まずに回る構造 |
| 孫子 | 先勝／不戦 | 勝てる設計を先に作る。戦わない選択 |
| 韓非子 | 法・術・勢 | 意志ではなく仕組みで律する |
| 渋沢栄一 | 道徳経済合一 | 稼ぎと徳を分離しない |

**注意**: `davinci_note_research_gate` §8の語彙最適化表は引き続き有効。原典語は**締めの一行とシリーズ名**で使い、本文の説明部分は行動経済学の語彙を優位にする。

## 3. 段階設計（期間ではなく、条件で進む）

> ADHD気質の設計として、**期間で進まない。条件で進む。** 期日を切ると、飽きた時点で「失敗」になる。条件にすれば、飽きても条件は消えない。

### 段1：実験ログ期（＝ Trust Me, I'm Lying / Reading List Email 期）

**一文**: 飽き性の設計者が、AIで小さく稼ごうとして、勝ったり負けたりする記録。

| 項目 | 内容 |
|------|------|
| 名乗り | 「賢いうさぎ」。**専門家を名乗らない**。肩書は「飽き性の設計者」程度 |
| 主コンテンツ | **賢いうさぎの〇〇やってみた**（実験ログ） |
| 副コンテンツ | 読書ログ（機構B） |
| 東洋思想の出し方 | 締めの一行のみ（機構A）。解説記事は書かない |
| 開示するもの | 売上・費用・所要時間・**撤退理由**。数字を丸めない |
| 読者への便益 | 「この道具は自分にも使えるか」が分かる。即座に有用 |
| KPI | 実験本数、実数開示の一貫性、スキ・コメント（ビューではない）、**引用・言及の発生** |
| 商品 | **作らない**。ゲートB（ペルソナ）未通過のため |
| 禁止 | 四柱・七徳・仁子思想の体系解説／じぶん憲法の全文公開型／診断名の肩書使用／稼ぎ煽り語彙 |

**段1で最も重要な規律**: 失敗した実験を**必ず同じ精度で書く**。多産多死型は、負けを同じ解像度で開示し続けないと「また新しいことに手を出しただけ」に見える（栄一点検事項）。

**段1→段2 の移行条件**（期間ではない）
1. 実験ログが一定数たまり、**複数の実験に共通する型**が自分で言語化できる
2. 読者側から「どうやって決めているのか」「その判断基準は何か」を問う反応が出る
3. 実数（売上・撤退）の開示が途切れずに続いている

条件2が最重要。**読者が判断基準を求め始めた時が、思想を出してよい合図**である。こちらから先に出さない。

---

### 段2：型の抽出期（＝ The Obstacle Is the Way 期）

**一文**: 飽きる前に立ち上がる設計——その方法を、読者が自分で使える形にする。

| 項目 | 内容 |
|------|------|
| 名乗り | **AI設計の専門家**として名乗ってよい（段1の実演が証明になっている） |
| 主コンテンツ | 実験から抽出したメソッド。「飽き性のための設計」の型 |
| 東洋思想の出し方 | **型の背骨として明示され始める**。ただし体系ではなく、各原則の根拠として一つずつ |
| 読者への便益 | 自分の飽き性に、自分で設計を当てられる |
| 商品 | **ここで初めて有料**。型そのもの。価格・形式は栄一点検後 |
| 禁止 | 自己統治論の体系名（仁子思想・四柱）を商品名にすること |

**段2→段3 の移行条件**
1. メソッドに購入者がつき、**他人が再現した事実**が確認できる
2. 「賢いうさぎ」という名前が、本人の発信外で言及される（引用・切り抜き）
3. 東洋思想の引用が、読者から「もっと聞きたい」と求められている

条件1が核心。**体系を名乗る資格は、他人が再現した時に発生する。**

---

### 段3：Daily Statecraft 期（＝ The Daily Stoic 期）

**一文**: 自己統治を、日々の判断に落とす。

| 項目 | 内容 |
|------|------|
| 名乗り | **東洋思想の研究者／自己統治論を体系化した人**。ここで初めて正面から |
| 主コンテンツ | **Daily Statecraft**。原典の一節 → 現代の状況 → 今日どうするか |
| 形式の要点 | **主人公は読者**。著者の王国の説明ではない（4月の失敗はここ） |
| 東洋思想の出し方 | 主題として正面から。ただし**毎回、読者の今日の判断に着地する** |
| 商品 | 書籍化、ニュースレター、体系そのもの |
| 海外 | Substack。詳細は §5 |

**Daily Statecraft は捨てない。取っておく。** 段1〜2は、その名を名乗る資格を稼ぐ期間である。

## 4. 名前について（結論：改名しない）

「Daily Eastern」は勧めない。

- **Stoic は学派の名。Eastern は地理の名。** ストア派＝一学派・正典あり・約400年。東洋思想＝儒道仏法家・複数国・2500年。Daily Stoic に対して Daily Eastern は、Daily Western と名乗るのと同じ粒度である
- 英語圏で "Eastern philosophy" はオリエンタリズム的括りとして避けられる傾向
- "stoic" は英語の日常語（不平を言わず耐える）で暗黙の便益を持つが、"Eastern" は何も約束しない

**Daily Statecraft の方が良い名前である。** Holidayが名づけたのは**実践の名**であって出自ではない。Stoic＝実践、Statecraft＝実践（統治する行為）、Eastern＝地図の領域。実践の名が勝つ。

さらに、この名には正典がある——『大学』の **修身斉家治国平天下**。「自分を修めることは、国を治めることと地続き」は比喩ではなく、東洋政治哲学の中心命題である。Holidayにとっての『自省録』に相当する原典を、既に持っている。

**運用**: 段1〜2の表看板は「賢いうさぎ」（キャラクター）。Daily Statecraft は段3で立ち上がる思想レイヤーの名。両方すでに存在しており、必要なのは改名ではなく**順序**である。

## 5. 海外（Substack）の判断

**着手は段2以降。段1では日本語に集中する。**

理由: 英語圏の「ADHD×AI×システム」はレッドオーシャン（ADHD Jesse 約7万、ADHD Weasel 約3.6万、Unconventional Organization の ADHD Entrepreneur's Guide to Systems 等）。差分を持たずに入ると埋もれる。

**白地の正確な位置**: ストア派は既に「ビジネスの意思決定OS」として市場化された（Holiday、Tim Ferriss）。東洋思想側は瞑想書（365 Tao, 1992 等）どまりで、**自分の事業実験を通して検証し続ける実践者がいない**。その席は空いている。

ただしその席に座るのは**思想レイヤー＝段3**である。段1の実験ログを英訳しても、レッドオーシャンに一人増えるだけ。**日本語で賢いうさぎを立て、実績ごと輸出する順序が有利。**

## 6. ベンチマーク（物語の型のベンチ。棚のベンチとは別）

`davinci_note_research_gate` §8のベンチは「棚への着地」と「読者規模」を測るものだった。本書のベンチは**物語の型**を測る。

| 名前 | 同型性 | 借りる | 捨てる |
|------|--------|--------|--------|
| **Ryan Holiday** | **最重要**。哲学を解説せず日々の判断に落とした構造。段階の順序そのもの | 実務実績→翻訳→日課、の順序。読書リストによる信頼形成。主人公を読者にする形式 | 古典の権威に寄りかかる部分。国家は当事者の実験が主語 |
| **Ryder Carroll**（バレットジャーナル） | ADD当事者が自分の脳のために設計した方法が世界的メソッド・書籍になった。**ADHD気質×設計の完全な同型** | 「自分のために作った仕組みが、結果的に他人に売れた」順序 | 単一メソッドへの収束（うさぎは多産多死が形式） |
| **Oliver Burkeman**（Four Thousand Weeks） | 直線的生産性への哲学的批判が世界的ベストセラー。**「亀を倒す」の需要が既に証明されている** | 有限性からの逆算。批判が言い訳に落ちない論理 | 学者的トーン。うさぎは実験の当事者 |
| **Derek Sivers** | 起業実録＋東洋的ミニマル哲学＋短文 | 文体。短さ。判断の理由を書く癖 | 隠居的トーン |
| ジマタロ（中島遼太郎） | 設計者が行動経済学をビジネス棚で語り書籍化 | **棚の乗り方**（§8で継続）、図解 | 教科書型 |

- **執行官**: 段1着手の可否決裁。ただしゲートA〜C未通過のため、着手する場合も「計測のための試験投稿」（§8段C）の範囲を超えないこと。
- **正篤**: 機構A（締めの一行）の形式設計。原典語と行動経済学語の配分規律を保持。**稿の起草は段1着手決裁後**。
- **アショーカ**: 機構B（読書ログ）と§2の正典表。特に**王陽明「知行合一」**は「計画だけ立てて実行しない」への直撃であり、G4の中核概念になりうる。思想的裏づけの研究を推奨。成果は内部メモ、公開形への翻訳は正篤。
- **韓非子**: §2の原典引用が効能訴求・診断商品化に接近しないかの点検。段3で「自己統治論の体系」を商品化する際の規約点検は別途。
- **栄一**: 段1の禁則「失敗した実験を同じ精度で書く」が守られているかの継続監査。段1→2、段2→3の移行条件は**自己申告ではなく実数**で判定されるべき。
- **北斎**: 段1でキャラクター表現が必要になる見込み（うさぎ／亀の対比）。発注は執行官決裁後。
- **ルカ**: 段1の実験ごとの売上・費用・撤退を国家会計に記録。**公開する数字と会計の一致**が誠実性の担保。
