# 06 脳科学 — 脳は中央集権か分散か

中心的問い: **人間の脳という統治システムは中央集権的か、分散的か。** その答えを個人国家OSの設計に転用する。

---

## 1. 結論を先に

[FACT / Evidence: HIGH]
> **脳は分散処理システムであり、中央司令部を持たない。**
> しかし**「今どのネットワークに資源を割くか」を切り替える機構**は存在し、その切り替え能力こそが希少資源である。

これが本章の最重要知見であり、国家OS設計の根幹を変える。

---

## 2. 実行機能（Executive Function）

[FACT / Evidence: HIGH]
Miyake らの因子分析研究（2000, Tier A）以降、実行機能は主として3つの分離可能な要素として整理される。

| 要素 | 内容 | 個人国家での対応 |
|---|---|---|
| **Inhibition（抑制）** | 優勢な反応を止める | 衝動的な新規事業・SNS・買い物を止める |
| **Working Memory Updating（更新）** | 情報を保持しながら書き換える | 複数の案件を同時に把握する |
| **Shifting（切り替え）** | 課題間を移動する | 制作から営業へ、事業から体調へ |

[FACT / Evidence: HIGH]
実行機能は**前頭前皮質を中心とするが、そこに局在するのではなく、ネットワークとして実現される**。単一の「司令部」は解剖学的に存在しない。

[FACT / Evidence: HIGH]
**Shifting（切り替え）には必ずコストがかかる（task-switching cost）。** 課題を切り替えると反応時間が延び、エラー率が上がる。これは訓練で減るが消えない。

[INTERPRETATION → 決定的な設計示唆]
> **統治OSにおける最大のコストは「作業」ではなく「切り替え」である。**
> エージェントを13体持つということは、13通りの切り替え先を持つということ。切り替え候補が増えるほど、切り替え判断そのものにコストがかかる。

これは `01` の「日常的中核は3」という結論を、認知科学の側から裏づける。

---

## 3. ワーキングメモリ

[FACT / Evidence: HIGH]
- Miller (1956) の「7±2」は**短期記憶のスパン**であり、実行を伴うワーキングメモリの容量ではない
- Cowan (2001, Tier A) は、チャンキングを統制した場合の実効容量を **4±1** と推定
- Baddeley のモデル: 中央実行系＋音韻ループ＋視空間スケッチパッド＋エピソディックバッファ

[INTERPRETATION]
君主が「同時に頭に置ける国家の関心事」は**4つ前後**。組織を10並べても、意識に載るのは常に4つ以下。
残り6つは「思い出せば使える」レベルにしかならない。したがって**残り6つは、思い出すコストを下げる仕組み（索引・入口の一本化）が必須**である。

[DESIGN]
→ 中核3〜4体は常時想起可能に。それ以外は**「執行代理に頼めば呼び出される」という単一入口**を作る。君主が専門エージェントの名前を覚えている必要をなくす。

---

## 4. 三大ネットワークと Salience Network【本章の核心】

[FACT / Evidence: HIGH]
機能的MRI研究により、次の3つの大規模ネットワークが繰り返し同定されている（Menon の triple network model 等、Tier A）。

| ネットワーク | 主な領域 | 機能 |
|---|---|---|
| **DMN（Default Mode Network）** | 内側前頭前野、後帯状皮質、楔前部 | 内省、自伝的記憶、将来の想像、心の彷徨 |
| **ECN / CEN（Central Executive Network）** | 背外側前頭前野、後頭頂皮質 | 目標指向の課題遂行、外界への注意 |
| **SN（Salience Network）** | 前部島皮質、前帯状皮質（dACC） | **顕著性の検出と、DMN⇄ECN の切り替え** |

[FACT / Evidence: HIGH]
- DMNとECNは**拮抗的**に働く（一方が活性化するともう一方が抑制される）
- **SNが、どちらを起動するかのスイッチを担う**（Sridharan et al., 2008, Tier A）
- SNの機能不全は、精神疾患（うつ、不安、依存）で広く報告されている

[INTERPRETATION → 国家OSへの直接転用]

> **脳の統治構造は「3つの省庁＋1つのスイッチ」である。**
> そしてボトルネックは省庁ではなく**スイッチ（SN）**にある。

これを国家OSに写すと:

| 脳 | 国家OS |
|---|---|
| **DMN** | 内省・長期展望・図書館・意味づけ（＝知） |
| **ECN** | 今日の実行・目標追求（＝執行） |
| **SN** | **何が重要かを検出し、内省モードと実行モードを切り替える機構（＝執行代理の朝夕儀式）** |

> **[DESIGN] 執行代理（オーケストレーター）の本質的機能は「作業の管理」ではなく「注意の切り替え」である。**
> これは Salience Network の役割そのもの。だから執行代理は**毎日必ず接触する唯一のエージェント**でなければならない。スイッチは常時稼働していなければ意味がないから。

さらに:
- **DMNとECNが拮抗する** → 「考える時間」と「やる時間」を同時に持てない → **内省と実行を時間帯で分離せよ**（朝の閣議＝ECN起動、夜の振り返り＝DMN起動）
- **DMNを潰してはいけない** → 常に実行モードでいると、長期展望と意味づけが失われる。「何もしない時間」は怠慢ではなく、DMNの稼働時間である（老子の無為の神経科学的裏づけ）

## 5. 習慣形成と基底核

[FACT / Evidence: HIGH]
- 行動が習慣化すると、制御が前頭前皮質（目標指向系）から**基底核（線条体、特に背外側線条体）を含む習慣系**へ移行する
- 習慣化された行動は、**実行機能をほとんど消費せずに実行される**
- 習慣形成には文脈手がかり（cue）と反復が必要。Lally et al. (2010, Tier A) の観察研究では自動性が漸近するまで中央値66日、個人差が非常に大きい（18〜254日）

[INTERPRETATION → 統治設計の最重要含意]
> **統治OSの目標は「毎日良い判断をすること」ではなく、「判断を必要としない状態を増やすこと」である。**

判断を要する行動は実行機能を消費し、実行機能は有限。したがって、
- 良い行動を習慣化 → 実行機能を消費せずに実行される
- 実行機能は、習慣化できない**本当に新しい判断**にだけ使う

[DESIGN]
→ 運用ルールは「毎日決める」ではなく「毎日決めなくて済むようにする」ために設計する。
→ 朝の閣議は「今日何をするか考える場」ではなく、**「昨日決めておいた今日の一手を確認する場」**にすべき。考える場にすると実行機能を朝一番に消費してしまう。

## 6. 報酬系とドーパミン

[FACT / Evidence: HIGH]
- ドーパミンは「快楽」そのものより、**報酬予測誤差（reward prediction error）**の信号として働く（Schultz et al., Tier A）
- 予測より良い結果 → ドーパミン上昇 → その行動が強化される
- 予測通り → 信号は小さい
- **「探索（新奇性）」自体が報酬予測誤差を生む**

[INTERPRETATION → 新規事業中毒の神経科学的説明]
> **新しいプロジェクトを始めることは、それ自体が報酬になる。** 結果が出ていなくても、新奇性が報酬予測誤差を生むから。
> 一方、既存事業の地道な継続は予測通りの結果しか生まないので、報酬信号が小さい。

これが「プロジェクト乱立」「新規事業中毒」「新しいAIツールを試し続ける」の生物学的基盤である。**意志の弱さではなく、報酬系の正常な動作**である。

[DESIGN → 対抗策は3つ]
1. **参入審査**（`18`）で新規開始のコストを上げる。始めるのを難しくする
2. **既存事業に報酬予測誤差を作る**。数字を可視化し、小さな更新を毎日見えるようにする（進捗の可視化は報酬信号を生む）
3. **新奇性の欲求を、無害な場所に逃がす**。図書館での学習・実験ノートなど、国家資源を消費しない探索路を公式に用意する

3が重要。欲求を禁止するのではなく、**低コストな出口を作る**。

## 7. 決断疲れ（Decision Fatigue）

[FACT / Evidence: LOW–MEDIUM]
- 「意思決定を重ねると判断の質が落ちる」という主張。Baumeister らの自我消耗（ego depletion）理論に由来
- **ただし再現性に重大な疑義がある。** 大規模な多施設事前登録replication（Hagger et al., 2016, Tier A）で効果は極めて小さいか無かった
- 有名なイスラエル仮釈放判事研究（Danziger et al., 2011）も、事件の並び順による交絡の指摘がある

[INTERPRETATION]
**「意志力は消耗する電池である」というモデルは採用しない。** 証拠が弱い。

しかし、より確実な代替説明がある。
- 課題切り替えコスト（Evidence: HIGH）は実在する
- ワーキングメモリの容量制約（Evidence: HIGH）は実在する
- 睡眠不足による前頭前野機能低下（Evidence: HIGH）は実在する

[DESIGN]
→ 「意志力を節約する」ではなく、**「切り替え回数を減らす」「同時保持数を減らす」「睡眠を守る」**という、証拠の強い経路で設計する。
→ 現行運用に「意志力の消耗」を前提としたルールがあるなら、根拠を張り替えるべき。

## 8. 脳から抽出する国家OS設計原理

| # | 脳の事実 | 国家OS設計原理 |
|---|---|---|
| 1 | 中央司令部は存在しない。分散ネットワーク | 完全中央集権の組織図は脳の実装と合わない。ただし… |
| 2 | SNが切り替えを担う。それがボトルネック | **切り替え機構（＝執行代理）を1つ置く。これは常時稼働** |
| 3 | DMNとECNは拮抗する | **内省と実行を時間帯で分離する**（朝＝実行、夜＝内省） |
| 4 | DMNは必要。潰してはいけない | **「何もしない時間」を制度として守る** |
| 5 | 実効ワーキングメモリは4±1 | **常時想起する組織は3〜4まで** |
| 6 | 切り替えにコストがかかる | **選択肢の数そのものがコスト。組織を増やすと切り替えコストが増える** |
| 7 | 習慣は実行機能を消費しない | **統治の目標は判断の削減。定型化・自動化が最優先** |
| 8 | ドーパミンは予測誤差信号。新奇性が報酬 | **新規開始に摩擦を、既存継続に可視化された進捗を** |
| 9 | 意志力消耗説は証拠が弱い | **意志力節約ではなく、切り替え削減・睡眠保護で設計する** |

---

## 9. 本章の結論

1. **脳は分散システムだが、切り替え機構（Salience Network）は単一である。** → 国家OSも、専門機能は分散させてよいが、**切り替えの入口は1つ**にする。
2. **執行代理AIの本質は「作業管理」ではなく「注意の切り替え」。** だから毎日接触する唯一のエージェントであるべき。
3. **内省（DMN）と実行（ECN）は同時に起動できない。** 朝と夜で役割を変える運用が神経科学的に正しい。
4. **統治の目標は「良い判断を毎日する」ではなく「判断を減らす」。** 習慣化と自動化が最優先の投資先。
5. **新規事業中毒は意志の問題ではなく報酬系の正常動作。** 禁止ではなく、参入摩擦＋既存の可視化＋無害な探索路の3点で対処する。
6. **意志力消耗（ego depletion）は根拠が弱いので、設計の前提にしない。**
