## 2. 中核採用：Implementation Intention（実行意図）

[FACT / Evidence: HIGH]
Gollwitzer らの研究（メタ分析 Gollwitzer & Sheeran, 2006, Tier A; 効果量 d ≈ 0.65）。
「目標意図（Xを達成したい）」に加えて **「実行意図（もしSという状況になったら、私はRという行動をとる）」** を事前に具体化すると、目標達成率が有意に上がる。

**なぜ効くか**: 状況Sが認知的にプライムされ、行動Rが自動的に想起される。つまり**その場での意思決定を不要にする**。`06`の「判断を減らす」と完全に一致。

[DESIGN → if-thenプロトコル]
統治OSのルールは、原則として**すべて if-then 形式で書く**。

悪い例（現行に多い形）:
> 「衝動を感じたら冷静に対処する」

良い例:
> 「新しい事業アイデアが浮かんだら → 駐車帯に1行書いて、72時間触らない」
> 「note投稿を思いついたら → 下書きフォルダに入れて、朝の閣議まで公開しない」
> 「監査の指摘を読んで反発を感じたら → 反論を書かず、24時間置いてから対応/保留/却下を選ぶ」
> 「22時になったら → PCを閉じ、翌日の一手を1行書いて終わる」

**現行の運用ボード22枚を、if-then 形式で書き直せるかどうかが、それが生きたルールかどうかの判定基準になる。** 書き直せないものは、ルールではなく願望である。

## 3. 中核採用：Habit Formation

[FACT / Evidence: HIGH]
- 自動性の獲得には文脈手がかり（時刻・場所・直前の行動）と反復が必要
- Lally et al. (2010): 自動性が漸近するまで中央値66日、範囲18〜254日
- **既存の習慣に新しい行動を接続する（habit stacking）**のが最も確実

[INTERPRETATION]
**66日という数字より、個人差の大きさ（18〜254日）のほうが設計上重要。**
「21日で習慣になる」は根拠がない。したがって、**習慣化の成否を短期で判定してはならない**。

[DESIGN]
→ 新しい習慣は**一度に1つだけ**。定着判定は最短でも60日後。
→ 定着していない習慣を「意志が弱い」と評価しない。手がかりの設計を疑う。

## 4. 採用：Self-Determination Theory（自己決定理論）

[FACT / Evidence: HIGH]
Deci & Ryan。内発的動機は3つの基本欲求の充足に依存する。

| 欲求 | 内容 | 個人国家での脅かされ方 |
|---|---|---|
| **Autonomy（自律性）** | 自分で選んでいる感覚 | AIやルールに命令されている感覚になると崩れる |
| **Competence（有能感）** | できるようになっている感覚 | 進捗が見えないと崩れる |
| **Relatedness（関係性）** | 他者とのつながり | 一人で作業し続けると崩れる |

[INTERPRETATION → 統治OSへの警告]
> **統治OSは、構造上、自律性を損ないやすい。** ルール・監査・KPIは全て外的統制であり、外的統制は内発的動機を弱める（過剰正当化効果）。

これは統治OSの根本的なジレンマである。制度で自分を縛るほど、やる気を失う。

[DESIGN → 3つの防御]
1. **自律性**: 全ルールは君主自身が作り、君主が改廃できることを明示する。AIは提案のみ。**「AIに管理されている」ではなく「自分が作った制度に従っている」という自己認識を守る**。憲法に「AIは決定しない」と書く意味はここにある
2. **有能感**: 進捗の可視化。**達成できたことの記録**（`06`の報酬予測誤差とも一致）。監査が指摘だけを出すと有能感を削るので、監査の出力に「守れた約束」を必ず含める
3. **関係性**: 一人国家の最大の弱点。AIとの対話は関係性欲求を部分的にしか満たさない。**対外活動（顧客・仲間との実接触）を国家機能として明示的に位置づける**必要がある

> **[DESIGN] 監査エージェントの出力フォーマットに「守れた約束」を必ず含める。** 指摘だけの監査は、有能感を削り、やがて監査自体が回避される（＝`02`の門下省の空洞化と同じ経路）。

## 5. 採用：Metacognition（メタ認知）

[FACT / Evidence: HIGH]
自分の理解・進捗・判断の質を監視し制御する能力。学習成果との相関は頑健。
重要な発見として、**人は自分の理解度を過大評価する**（流暢性の錯覚、Dunning-Kruger 的現象）。

[INTERPRETATION]
「自分がどう判断したか」を後から見返せる形で外部化することが、メタ認知の実装である。頭の中では実行できない。

[DESIGN]
→ **決裁記録（Decision Record）**が、メタ認知の外部化装置である。
```
【日付】【決めたこと】【選ばなかった選択肢】【前提】【予測】【この判断を見直す条件】
```
「予測」と「見直す条件」が、後の照合を可能にする（`05` AAR、`04` 形名参同と同一構造）。

## 6. 採用：Cognitive Load Theory

[FACT / Evidence: HIGH]
Sweller。認知負荷は3種類。
- **Intrinsic（内在的）**: 課題そのものの難しさ。減らせない
- **Extraneous（外在的）**: 情報の提示の仕方に由来する無駄な負荷。**減らせる**
- **Germane（学習関連）**: スキーマ構築に使われる負荷。有用

[INTERPRETATION → 統治OSの外在的負荷]
統治OSが生む外在的負荷:
- どのフォルダに書くかを毎回考える
- どのエージェントを呼ぶかを毎回考える
- 同じ情報が2箇所にあり、どちらが正しいか判断する
- 使われていないボードが視界に入る

これらは**全て国家目標に一切寄与しない純粋な損失**である。

[DESIGN]
→ **入口を1つにする。** 迷う瞬間を消す。
→ **正本を1つにする。** 現行の「対話ログ2箇所・申し送り2箇所」は外在的負荷の直接的な原因。
→ **使わないものは視界から消す**（削除でなくアーカイブでよい）。

## 7. 採用（回避設計）：Learned Helplessness

[FACT / Evidence: MEDIUM–HIGH]
Seligman ら。制御不能な嫌悪刺激を反復して受けると、後に制御可能な状況でも回避行動を取らなくなる。
（近年の神経科学的再解釈では、無力感がデフォルトで、制御可能性の学習が獲得されるとする Maier & Seligman, 2016）

[INTERPRETATION → 統治OSの最大の心理的リスク]
> **達成不可能なノルマを毎日課すと、統治OSそのものが学習性無力感の生成装置になる。**

具体的には:
- 毎朝10個のタスクを立て、毎晩3個しか終わらない → 「どうせできない」の学習
- 監査が毎週未達を指摘し続ける → 監査を見なくなる
- 22枚の運用ボードのうち大半が更新されていない → 「このシステムは守れないもの」という学習

**これは現行 ai-imadaruma における現実的なリスクである。** ボードの半数が1ヶ月更新されていない状態は、「守らなくても何も起きない制度」を毎日学習している状態にほかならない。

[DESIGN → 3つの防御]
1. **日次の必達は1つだけ**にする。それ以外は「やれたら加点」。必達が1つなら達成率は高く保てる
2. **守れないルールは即座に廃止する。** ルールを守れないことより、守れないルールが存在し続けることのほうが有害
3. **縮退運転モード**（`03`）を制度化する。「今日は低調モード」を宣言できれば、未達ではなく正規の運用になる

## 8. 採用：Prospective Memory / Attention Residue

**Prospective Memory** [Evidence: MEDIUM–HIGH]
未来にやることを覚えておく記憶。負荷が高いと著しく劣化する。
[DESIGN] → 「覚えておく」を人間に要求しない。全て外部化（駐車帯・受信箱・リマインダ）。

**Attention Residue** [Evidence: MEDIUM]
Leroy (2009)。前の課題が未完了のまま次に移ると、残留した注意が次の課題の成績を下げる。効果は再現されているが効果量は文脈依存。
[DESIGN] → 課題の切り替え時に **「終了の儀式」**（1行の完了メモ、次のアクションの明示）を入れる。未完了のまま切り替えない。これは `06` の切り替えコストとも整合する。

## 9. Identity-based Behavior

[FACT / Evidence: MEDIUM–HIGH]
「〜する人である」という自己概念と一致する行動は持続しやすい。行動変容の文献で広く支持されるが、実験的因果証拠は中程度。

[INTERPRETATION → 国家メタファーの正当化と危険]
> **「国家として自分を統治する」というメタファー自体が、identity-based な装置である。**
> 「自分は国家を統治する君主である」という自己概念は、行動を強く方向づける。

これは ai-imadaruma の最大の資産である。同時に危険もある。
- **良い方向**: 判断が「気分」でなく「国家の意思」になる。長期視点が持てる
- **危険な方向**: **統治ごっこ**。組織図を作ること自体が「君主らしい行動」として報酬になり、実務が空洞化する

[DESIGN]
→ アイデンティティを守りつつ空洞化を防ぐには、**「良い君主とは何か」の定義を、組織の壮麗さではなく成果と規律に置く**。
→ 判定基準（ユーザーの第66項と同じ結論）: **「その組織図が美しいか」ではなく「毎日実際に使われるか」**。

## 10. 本章の結論

1. **if-then（実行意図）が最も証拠の強い介入。全ての運用ルールを if-then 形式で書き直せ。** 書き直せないものは願望であり、廃止候補。
2. **習慣化の個人差は極めて大きい（18〜254日）。短期で成否を判定するな。新習慣は同時に1つ。**
3. **統治OSは構造的に自律性を損なう。** 「AIは決定しない」「ルールは君主が作り改廃できる」を明示することが、動機の防衛策である。
4. **監査の出力には必ず「守れた約束」を含める。** 指摘だけの監査は有能感を削り、やがて回避される。
5. **外在的認知負荷（どこに書くか・誰に聞くか・どちらが正本か）は純粋な損失。** 入口と正本を1つにする。
6. **達成不能なノルマの反復は、統治OSを学習性無力感の生成装置に変える。** 日次必達は1つだけ。守れないルールは即廃止。縮退運転モードを制度化する。
7. **Ego Depletion は採用しない。** 証拠が弱い。切り替え削減・睡眠保護という強い経路で代替する。
8. **国家メタファーは強力な identity 装置だが、「統治ごっこ」に転化する危険を内包する。** 評価軸を組織の美しさから使用実績へ。
