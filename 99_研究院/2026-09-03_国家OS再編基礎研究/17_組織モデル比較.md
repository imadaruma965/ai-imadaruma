# 17 組織モデル比較 — 6案の100点評価

第53〜54項の要求に従い、**6つの組織モデル**を構築し、**11の評価軸**で採点する。

---

## 評価軸の定義（各100点）

| 軸 | 何を測るか | 高得点の条件 |
|---|---|---|
| 1 **認知負荷** | 君主が構造を維持するのに要する認知資源 | 常時想起する単位が少ない。どこに書くか迷わない |
| 2 **意思決定速度** | 着想から実行までの時間 | 経由する層が少ない。承認が軽い |
| 3 **役割明確性** | 「誰に聞くか」が自明か | 分割軸が単一。責任に重複と空白がない |
| 4 **AI間重複** | 役割の重なりの少なさ（高得点＝重複が少ない） | 3条件テストを全員が通過している |
| 5 **監査能力** | 自己欺瞞と誤りを検出できるか | 監査が実行から独立。君主へ直報 |
| 6 **長期戦略** | 未来と外部を見る力（VSM S4） | S4が独立し、かつS3に潰されない |
| 7 **日次実行** | 今日が動くか | 日次の接点が明確。摩擦が小さい |
| 8 **知識共有** | 文脈の分断を防げるか | 共通コンテキストが設計されている |
| 9 **拡張性** | 事業や領域が増えたときに耐えるか | 領域追加でエージェントが増えない |
| 10 **保守性** | 制度の更新・廃止が回るか | 廃止がデフォルト。定員制がある |
| 11 **君主との相性** | 実際に毎日使われるか | 実測された使用パターンと整合する |

## 各モデルの決定的な欠点

| モデル | 決定的欠点 |
|---|---|
| **A 現行** | **分割軸の混在**により、役割明確性30点・拡張性25点・保守性25点。エージェントを増やす方向にしか進化できない構造 |
| **B 三省六部** | **S4（外部情報・未来）が存在しない。** また全案件を三段階に通すため日次が重い |
| **C VSM** | **理論的に最も正しいが、名前に愛着が持てない**（君主との相性45点）。`07` の identity 効果を失う。実際に使われない危険 |
| **D Cabinet** | **監査がCabinetの一員になると独立性が崩れる**（監査能力60点）。かつ第0項が禁じるCEO組織の焼き直しに見える |
| **E Network** | 一人国家には自律主体が複数存在しないため、ネットワーク型の利点が原理的に発現しない |
| **F Hybrid** | **弱点は「移行コスト」と「初期の名前の二重化による混乱」。** どちらも一時的なもので、構造的欠陥ではない |

## MODEL F が高得点になる理由の分解

MODEL F は、他モデルの長所を、それぞれの短所を持ち込まずに統合している。

| 取り込んだもの | 出典モデル | 短所を回避した方法 |
|---|---|---|
| 監査の独立（S3\*） | C（VSM） | — |
| S4の独立と S3/S4 裁定 | C（VSM） | Bの欠点（S4なし）を補完 |
| 起草→審査→執行 | B（三省制） | **L3以上に限定適用**。Bの日次の重さを回避 |
| 2層運用（中核＋呼び出し） | D（Cabinet） | 監査を中核に置きつつ**内府の下には置かない**。Dの独立性欠陥を回避 |
| 日次接点1体 | D（Cabinet）＋`06`（SN） | — |
| 定員制・戸籍調査 | ローマCensor | Aの保守性欠陥を解消 |
| 低コスト日常監査 | 江戸・目付 | Bの審査の重さを回避 |
| 国家メタファーと人物通称 | A（現行） | **Cの相性欠陥を解消**。identity装置を維持 |
| 領域＝台帳 | 原則1 | Aの拡張性欠陥を根本解決 |

> **MODEL F は「CEO組織の焼き直し」でも「歴史の模倣」でもない。**
> 唐の権限分離／VSMの機能定義／ローマの定員審査／江戸の日常監査／現代の認知科学とAI実証研究を、**個人という制約条件のもとで再結合したもの**である。

## 本章の結論

1. **MODEL F（三省一台・工房制）を推奨する。平均88.2点。**
2. **現行 MODEL A は41.4点。** 特に役割明確性・AI間重複・拡張性・保守性が30点未満で、構造的欠陥がある。
3. **MODEL A の唯一の強みは監査能力70点**（栄一の独立性と一時停止勧告権）。**この設計判断は正しかったので、MODEL F でも継承する。**
4. **MODEL C（VSM）が理論的には最強だが、君主との相性45点で失格。** 使われない制度は存在しないのと同じ（原則12）。
5. **MODEL F は5つのモデルのHybrid**: VSM（機能定義）× 唐三省制＋御史台（権限分離）× Cabinet（2層運用）× ローマCensor（定員審査）× 江戸目付（低コスト日常監査）。
