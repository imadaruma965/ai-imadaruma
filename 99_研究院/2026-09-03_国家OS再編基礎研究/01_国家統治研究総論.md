# 01 国家統治研究総論

国家が長期にわたって存続・繁栄するために必要な普遍構造は何か。逆に、何が国家を殺すのか。
本章は歴史・組織論・サイバネティクスの横断から、統治の一般理論を抽出する。

---

## 1. Q1: 国家が長期存続・繁栄するために必要な普遍機能

[FACT / Evidence: HIGH]
政治学・行政学の複数系統（Fukuyama の政治秩序論、North の制度経済学、Beer の VSM、Ostrom の制度設計原理）が、名称は違えど収斂して指摘する機能は次の6つである。

### 統治の6大普遍機能

| # | 機能 | 問い | これが欠けると |
|---|---|---|---|
| 1 | **同一性 Identity** | 我々は何者で、何を良しとするか | 目的が漂流し、判断の基準が状況ごとに変わる |
| 2 | **方向 Direction** | 有限の資源をどこに集中するか | 全方位に薄く展開し、どこでも勝てない |
| 3 | **執行 Execution** | 決めたことを実際に動かす | 計画だけが積み上がる（計画倒れ国家） |
| 4 | **検証 Verification** | 決めたことは正しかったか、実際にやったか | 自己欺瞞が累積し、腐敗が可視化されない |
| 5 | **情報 Intelligence** | 外と内で何が起きているか | 現実とモデルが乖離し、ある日突然破綻する |
| 6 | **記憶 Memory** | 過去の判断と学習をどう保持するか | 同じ失敗を繰り返し、学習が個人の記憶に依存する |

[INTERPRETATION]
この6機能は**削れない**。削ったのではなく「誰かが兼務している」だけであり、兼務した瞬間にその機能は劣化する。特に4（検証）は、3（執行）と同じ主体が持つと必ず形骸化する。

[DESIGN]
→ 個人国家においても、この6機能は必ず「誰かの責任」として名前がついていなければならない。逆に、**この6つに還元できない組織は存在理由がない**。

### 普遍機能の階層性

6機能は対等ではない。**上位が下位を規定する一方向の階層**を持つ。

```
同一性（憲法・価値観）      ← 最も変わりにくい。年単位
   ↓ 規定する
方向（国家戦略）            ← 四半期単位
   ↓ 規定する
政策（何をやるか）          ← 月単位
   ↓ 規定する
計画（いつ誰がどうやるか）   ← 週単位
   ↓ 規定する
任務（今日の一手）          ← 日単位
```

[FACT / Evidence: HIGH]
この階層の逆流（下位が上位を書き換える）は、歴史上ほぼ例外なく機能不全の兆候である。日本の統帥権独立（軍という執行組織が国家意思の上位に立った）、明代の宦官政治（執行補助職が政策決定を握った）、宋代の冗官（下位組織が自己増殖して国家財政を規定した）はいずれもこの型である。

[INTERPRETATION]
個人国家における逆流とは、**「今日やること」が「国家目標」を事後的に書き換える現象**である。「今日はこれをやったから、これも戦略ということにしよう」。これは最も検知しにくく、最も致命的な腐敗である。

## 2. Q2: 国家が機能不全になる最大要因

[FACT / Evidence: HIGH]
歴史事例（詳細は `03_成功国家失敗国家比較.md`）から抽出すると、崩壊要因は単一ではないが、**発生頻度と致死性の積**で並べると次の順になる。

### 死因ランキング

| 順位 | 死因 | メカニズム | 歴史例 |
|---|---|---|---|
| **1** | **情報の質の劣化** | 統治者に届く情報が、忖度・遅延・断片化で歪む。現実とモデルが乖離したまま意思決定が続く | ソ連の生産統計、明末の辺境報告、9/11前の米インテリジェンス断片化 |
| **2** | **組織の自己増殖** | 組織が国家目標ではなく自らの存続を目的化する。人員と手続が増え、実行速度が落ちる | 宋の冗官冗費、後期律令制の令外官膨張 |
| **3** | **検証機能の骨抜き** | 監査・審査が政治的に無力化される。形式は残り、実質が消える | 唐・門下省の封駁権の空洞化、明の都察院の党派化 |
| **4** | **財政と現実の乖離** | 収入を超える約束を続ける。危機時に選択肢がゼロになる | ローマ帝国後期の通貨改悪、明末の財政破綻 |
| **5** | **制度更新能力の喪失** | 環境は変わったのに制度が変わらない。過去に成功した制度ほど更新されない | 科挙の八股文化、江戸後期の身分制と経済実態の乖離 |
| **6** | **後継・継続性の断絶** | 統治能力が特定個人に依存し、その個人が失われると崩壊 | ローマ帝政の継承危機、多くの一代英雄型国家 |

[INTERPRETATION → 個人国家への翻訳]

| 国家の死因 | 個人国家での現れ方 |
|---|---|
| 情報の質の劣化 | 自分の数字（売上・時間・体調）を正確に見ていない。「なんとなく忙しい」で判断する |
| 組織の自己増殖 | AIエージェント・フォルダ・運用ボードが増え、維持だけで時間が溶ける |
| 検証機能の骨抜き | 監査AIを置いたが、耳の痛い指摘を無視するようになる／監査の場を開かなくなる |
| 財政と現実の乖離 | 収入見込みを楽観し、支出と時間の約束を先に配ってしまう |
| 制度更新能力の喪失 | 一度作った日次運用を、効かなくなっても回し続ける |
| 継続性の断絶 | 全ての判断が「その時の気分」に依存し、記録が残らない |

[DESIGN]
→ **最大の死因は1（情報の質）である。したがって統治OSの設計は「良い組織図を描く」ことではなく「君主に正しい数字と正しい異論が届く経路を作る」ことから始めるべきである。**

## 3. Q3: 権力集中と権力分散の設計

[FACT / Evidence: HIGH]
政治制度論の中心的トレードオフは次の通り。

- **集中の利得**: 意思決定速度、方向の一貫性、責任の所在の明確さ
- **集中の損失**: 誤りの増幅、腐敗の非検知、単一障害点
- **分散の利得**: 誤りの相互訂正、腐敗の抑制、冗長性
- **分散の損失**: 速度低下、責任の拡散、調整コストの二次関数的増大

歴史的に、**大国は分散に、小国は集中に寄せる**のが安定解である。理由は、調整コストが構成員数の二乗で増えるのに対し、誤りの増幅リスクは規模に対しておおむね線形だから。小国では調整コストが相対的に高すぎる。

[FACT / Evidence: HIGH]
北宋がこの失敗の教科書である。宰相権を分割し（中書・枢密院・三司）、相互牽制を徹底した結果、腐敗は抑えられたが、意思決定が誰にも完結できなくなり、官僚数と財政支出が膨張し、外圧に対して機動できなくなった。

[INTERPRETATION]
個人国家は**構成員1名の極小国家**である。したがって分散設計は原理的に不利である。しかし完全集中も不可である。なぜなら集中の損失（誤りの増幅・自己欺瞞の非検知）が、まさに個人が最も弱い領域だから。

[DESIGN → 権力設計の結論]

> **決定権は完全集中（君主のみ）。検証権のみ分散（監査は独立）。**

これは三権分立ではなく**二権分立**である。

```
決める権限   → 君主に100%集中（AIは提案のみ）
執行の管理権 → 執行代理に委任（君主の意図の範囲内で）
検証する権限 → 執行から独立。執行代理に報告せず、君主に直報
立法（憲法） → 君主が直接保持。AIは改正提案のみ可能
```

分散するのは**権力**ではなく**視点**である。これが小国における正しい分権の形。

## 4. Q4: 意思決定・実行・監査・知識は同一組織に置くべきか

[FACT / Evidence: HIGH]
唐の三省制（中書=起草／門下=審査／尚書=執行）と、それとは別系統の御史台（監察）が、この問いに対する最も洗練された歴史的解答である。さらに翰林院（知識・詔勅の学術的基盤）が第4の系統として存在した。

分離の根拠は明確である。**同一主体は自らの起草を正しく審査できない**。これは道徳の問題ではなく認知の問題である。

[FACT / Evidence: HIGH — AI領域でも同一結論]
LLMマルチエージェント研究においても、自己検証（self-verification）はバイアスがかかり、独立した検証者（verifier / critic）を置いた場合にのみ有意な改善が出るという報告が複数ある。MASTタクソノミー（arXiv:2503.13657）が挙げる3大失敗カテゴリの1つが "task verification" である。詳細は `11_AIマルチエージェント.md`。

[DESIGN → 分離の結論]

| 機能 | 分離すべきか | 理由 |
|---|---|---|
| 意思決定 ⇄ 実行 | **分離する（弱く）** | ただし小国では同一人物が両方行う。分離するのは「決める時間」と「やる時間」であって組織ではない |
| 実行 ⇄ 監査 | **絶対に分離する** | 最重要。自己採点は必ず甘くなる。監査者は被監査者に報告してはならない（米GAOの独立性原則） |
| 意思決定 ⇄ 知識 | **分離する** | 知識は「今の判断に都合の良い形」に歪められてはならない。図書館は戦略の下僕ではない |
| 監査 ⇄ 知識 | **分離しない** | 監査は基準を必要とし、基準は知識から来る。ただし監査の結論は独立 |
| 起草 ⇄ 審査 | **分離する** | 唐の中書＝門下。AIのハルシネーション対策としても有効（`11`参照） |

**特筆すべき歴史的事実 [FACT / Evidence: HIGH]**
唐の三省制は、後に政事堂（三省長官の合同会議）に統合されていった。理由は速度である。分離は正しかったが、**分離のコストが高すぎたため、実務が統合方向に押し戻した**。

[INTERPRETATION]
これは極めて重要な教訓である。**審査層は「安い」場合にのみ生き残る**。高コストな審査は、時間的圧力の下で必ずスキップされる。したがって個人国家における監査は、儀式ではなく「5分で終わる定型」でなければならない。

## 5. Q5: 一人国家において行政組織はいくつまで管理可能か

[FACT / Evidence: MEDIUM]
- Miller の 7±2 は短期記憶の容量であり、組織管理の限界に直接適用するのは誤用に近い。近年の推定ではワーキングメモリの実効容量は**4±1チャンク**とされる（Cowan, 2001, Tier A）。
- 経営学の span of control 研究は、密な関与が必要な部下は5〜7名、定型業務なら10〜30名が上限とする（Evidence: MEDIUM、文脈依存が大きい）。
- 認知負荷理論（Sweller）は、外在的負荷（extraneous load）が学習と実行の質を直接下げると示す（Evidence: HIGH）。組織図を覚えること自体が外在的負荷である。

[INTERPRETATION]
一人国家では、組織の維持コストが**丸ごと君主の認知負荷**になる。企業なら中間管理職が吸収する負荷を、誰も吸収してくれない。

さらに個人国家に特有の制約がある。**「どこに書いたか」「誰に聞くか」を思い出すコスト**である。組織が10あれば、情報を書くたびに10通りの選択肢を検討する。この選択コストは、組織数に比例して毎回発生する。

[DESIGN]

> **日常的に想起する必要のある組織単位は「3」が上限。呼び出せば思い出せる専門単位を含めても「7〜9」が実用上限。合計10を超えた時点で、組織図は使われなくなり装飾になる。**

根拠の三点セット:
1. ワーキングメモリ実効容量 4±1（Cowan）
2. 唐の三省・ローマの主要マギストラトゥス・英国のコア閣僚など、歴史上の「日常的中核」はいずれも3〜5
3. 実測（`19`参照）: 現行13エージェントのうち、対話ログのサイズで見て実質稼働は3体に集中している

**実測データが理論と一致している。** これは偶然ではなく、君主の認知容量が実際の使用パターンを決めているという証拠である。

## 6. 統治の失敗を検知する早期警戒指標

[DESIGN]
上記の死因が発現する前に検知するための、個人国家用の先行指標。

| # | 指標 | 危険水準 | 対応する死因 |
|---|---|---|---|
| 1 | 統治オーバーヘッド率 = 統治作業時間 ÷ 総稼働時間 | **10%超** | 組織の自己増殖 |
| 2 | 30日間無使用のエージェント数 | **1体でも** | 組織の自己増殖 |
| 3 | 監査所見のうち未対応で30日超のもの | **3件超** | 検証機能の骨抜き |
| 4 | 受信箱（未処理情報）の滞留件数 | **20件超** | 情報の質の劣化 |
| 5 | 「正本」が2箇所以上に存在する項目数 | **1件でも** | 情報の質の劣化 |
| 6 | 直近30日で数字を確認していない領域の数 | **2領域超** | 財政と現実の乖離 |
| 7 | 3ヶ月更新されていない運用ルールの数 | **総数の30%超** | 制度更新能力の喪失 |

[INTERPRETATION]
指標5は特に重要で、かつ現行 ai-imadaruma で**実際に違反が検出されている**（対話ログ2箇所、申し送り2箇所、国家OS内容がVaultにも複製）。詳細は `19`。

## 7. 本章の結論

1. 統治の普遍機能は6つ（同一性・方向・執行・検証・情報・記憶）であり、削れない。
2. 最大の死因は「情報の質の劣化」。組織図より情報経路を先に設計せよ。
3. 極小国家では**決定権は集中、検証権のみ分散**。三権分立は不要、二権分立で足りる。
4. 実行と監査は絶対に分離する。ただし**監査は安くなければ形骸化する**（唐・政事堂の教訓）。
5. 日常的中核組織は3、総組織数は10が上限。これは理論値であり、かつ現行リポジトリの実測値と一致する。
