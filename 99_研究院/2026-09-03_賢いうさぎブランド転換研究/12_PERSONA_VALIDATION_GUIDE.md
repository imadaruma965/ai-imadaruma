# 2. 顧客インタビュー（30〜45分）

## 2.1 設計原則

| 原則 | 理由 |
|---|---|
| **抽象を聞かない。直近の具体的行動を聞く** | 「先延ばししますか」は誘導であり、かつ自己申告が当てにならない |
| **仮説を先に言わない** | 「終わらないですよね」と言えば「はい」が返る |
| **「なぜ」を2回まで** | 3回目からは本人が理由を創作し始める |
| **沈黙を待つ** | 3秒待つ。埋めない |
| **診断しない・助言しない** | 08 §14-1。面談中に解決策を提案しない |
| **逐語で記録する** | コピーの原材料は本人の語順にある。要約すると死ぬ |

**録音は許諾を取る。個人を特定できる情報は文字起こしから削除する。**

## 2.2 質問リスト

### パート0：導入（3分）

> 「今日は商品の売り込みではありません。あなたの仕事の進め方を教えていただくのが目的です。正解はありません。答えたくない質問は飛ばしてください。録音してよろしいですか」

### パート1：仕事の実態（8分）

| # | 質問 | 測るもの |
|---|---|---|
| Q1 | **いま、同時に何本の案件を持っていますか** | 稼働の実像 |
| Q2 | **そのうち、当初の予定より遅れているものは何本ありますか** | **遅延の実在率** |
| Q3 | **一番遅れているものについて。最後に手をつけたのはいつですか** | **着手のパターン** |
| Q4 | **その案件、先方には何と伝えていますか** | **「先方確認待ち」の実在（09の中核設定）** |
| Q5 | **直近1年で、仕事はどこから来ましたか。多い順に3つ** | **紹介7割・既存6割の検証** |
| Q6 | **昨日、誰にも中断されずに座っていられた時間は、一番長くて何分でしたか** | **商品の所要時間設計を決める** |

### パート2：お金と数字（7分）

| # | 質問 | 測るもの |
|---|---|---|

| Q8 | **単価はどうですか** | 同上 |
| Q9 | **直近で、月の売上と手元に残った額を数字で確認したのはいつですか。何を見て確認しましたか** | **「確定申告直前まで見ていない」の検証。「見ていますか」と聞かない** |
| Q10 | **いま、開封していない郵便物や、返信していないメールはありますか。何通くらいですか** | **事務の停滞（郵便7通設定）の検証** |

### パート3：購入と完了（10分）★中核

| # | 質問 | 測るもの |

| Q13 | **直近3ヶ月で、完了した重要な仕事を挙げてください** | **08 H5・H6 の核心** |

**Q11とQ13は必ず並べて聞く。** 08 §13 実験3 の PASS基準：**購入3以上かつ完了0〜1 の割合が40%以上。** 20%未満で FAIL（柱2を縮小する）。

# 4. 直近行動を確認する質問の設計思想

**なぜ「直近3ヶ月」なのか。**

| 期間 | 問題 |
|---|---|
| 「普段」「よく」 | 自己像からの再構成になる。実際の行動と乖離する |
| 「今まで」 | 想起バイアスが最大。印象的な出来事だけが出る |
| **「直近3ヶ月」** | **想起可能で、かつ自己像で塗り替えにくい長さ** |
| 「今日」「昨日」 | 例外的な日を拾う可能性がある。Q6のみ使用 |

**Q11（買ったもの）とQ13（完了した仕事）を並べる理由**：

**この2つを別々に聞いて、面談者が並べて記録する。** 被面談者に「買ったものは多いのに完了は少ないですね」と言わない。**言った瞬間に、この人は防御に入り、以後の回答が歪む。**

**差は、面談後の分析で計算する。**

# 5. 商品コンセプトテスト

## 5.1 やってはいけない方法

**「こういう商品があったら買いますか」と聞かない。** 購買意思の測定として無効である（全員が甘く答える）。

## 5.2 有効な方法：3つ並べて順位をつけさせる

面談の最後（Q23の後）に、**3つの説明文を紙またはPDFで見せる。** 説明文には価格を書かない。

| # | 説明文（案） |
|---|---|
| **A** | いま抱えている案件のうち、どれが止まっていて、なぜ止まっているのかを、17分で1枚の図にする。 |
| **B** | 先月あなたが使った時間とお金が、何に変わったかを1枚にする。残っていないものが見える。 |
| **C** | 事業を今のまま続けるか、別のことを始めるか。決めるための材料を、あなたの数字から作る。 |

**質問**：
1. **この3つに、興味がある順に1・2・3をつけてください**
2. **1位にしたものについて。これは何のための道具だと思いますか**（＝**理解のテスト**。説明が伝わっていなければ、コピーが失敗している）
3. **1位のものが、いくらなら「高いけど納得できる」ですか。いくらなら「安すぎて怪しい」ですか**（**Van Westendorp 型の2問**。「いくらなら買いますか」と聞かない）

**A＝入口仮説A／B＝入口仮説B／C＝A'（事業判断）に対応する。** 20名の順位分布が、`10` §20 の判定を検証する。

## 5.3 価格受容性の確認

**Van Westendorp 価格感度測定の簡易版（4問）を、コンセプトテストの1位商品について行う。**

| # | 質問 |
|---|---|
| P1 | いくらから「高すぎて買わない」ですか |
| P2 | いくらから「高いが、価値があるなら検討する」ですか |
| P3 | いくらなら「お買い得だ」と感じますか |
| P4 | いくらから「安すぎて品質を疑う」ですか |

**注意（この手法の限界を明記する）**：
- Van Westendorp は**支払意思ではなく価格の心理的な帯**を測る。**実売の予測力は限定的である。**
- 20名では統計的な最適価格は出ない。**帯の位置だけを見る。**
- **最終判定は §7 のβ版販売で行う。** 面談の価格回答を根拠に価格を決めない。

# 6. X投稿による反応テスト

## 6.1 実験1：時間帯（`10` §14.4 の【UNKNOWN】を埋める）

| 設計 | 内容 |
|---|---|
| 期間 | 8週間 |
| 枠 | **07時／12時／17時／21時** の4枠 |
| 投稿 | **同型の投稿**（柱1の観測記録）を、各枠に週1本ずつ。計32本 |
| KPI | **保存数、プロフィールクリック数、note遷移数** |
| 見ないKPI | いいね数、フォロワー増（**X利用者の投稿率は10.7%＝母集団の3/4が能動的行動をしない**） |
| 判定 | 最も保存数の多い枠を主枠にする。**差が20%未満なら「時間帯は効かない」と結論する** |

## 6.2 実験2：入口仮説A/B/C（08 §13 実験1 の実装）

| 設計 | 内容 |
|---|---|
| 期間 | 6週間（2週×3パターン） |
| パターンA | 出来事型：「納期を1回延ばした。理由は先方確認待ちだと伝えた」 |
| パターンB | 資源型：「先月、何時間働いたかは言える。何が残ったかは言えない」 |
| パターンC | 判断型：「今の事業を直すか、新しく始めるか。半年、決めていない」 |
| KPI | **保存率、プロフィールクリック→note遷移率** |
| 判定 | **対照より1.5倍以上で PASS。差なしで FAIL** |
| FAILの措置 | **語を差し替える。Problem Definition（08 L1）は変えない** |

## 6.3 実験3：性別中立コピーの検証

| 設計 | 内容 |
|---|---|
| 期間 | 常時 |
| 方法 | **全投稿から性別を示す語を排除した状態で運用する** |
| KPI | **noteダッシュボードの読者男女比、面談応募者の男女比、購入者の男女比** |
| 判定 | **購入者の女性比率が20%未満で3ヶ月推移した場合、`10` §8.2 の判定を再検討する** |

## 6.4 実験4：プロフィールA/B（08 §13 実験1 継承）

09 §6.2 の確定版と、08 §12.6 の対照案（損失フレーム先行）を**2週ずつ入れ替える。**

**判定基準：フォロワー増ではなく、プロフィールクリック→note遷移率。**

# 7. note記事とβ版販売による検証

## 7.1 note記事のテスト

| # | 記事テーマ | 検証する仮説 |
|---|---|---|
| 1 | 「生産性が上がったと答えた人は8割。単価が上がった人は4割」 | **LEVEL 2（速くなった分の置き場所）が通じるか** |
| 2 | 「仕事が減ったのは、腕が落ちたからではないかもしれない」 | **構造要因の提示が信頼を生むか** |
| 3 | 「学び直しは必要だ80.6%、した33.6%。差の47ポイントが、机の上にある」 | **積読の言語化が刺さるか** |
| 4 | 「今の事業を直すか、新しく始めるか。半年、決めていない」 | **A' が通じるか** |

**KPI**：スキ数ではなく、**読了率とメンバーシップ登録数。**

## 7.2 β版販売（08 §9.4 緩和策1 の実装）

| 段階 | 内容 | 判定 |
|---|---|---|
| **β0** | フロント相当を**無料**で5名に提供。事前指定の指標を測る | **完了率60%以上** |
| **β1** | フロントを **¥2,980**（β価格）で10名に提示 | **購入3名以上** |
| **β2** | フロントを **¥4,980** で提示 | **月20本以上でPASS／月3本以下でFAIL**（08 §13 実験4） |
| **β3** | ハイエンドを **¥49,800** で、既存関係者中心に20名へ提示 | **90日で5件以上でPASS／20名提示で1件以下でKill**（08 §13 実験5） |

**β0の設計が最も重要である。**

- **完了を購入直後の1画面で測る**（後日アンケートにしない。生存バイアス）
- 測る指標を**購入前に固定する**（事後に都合のよい指標を選ばない）
- **測る指標**：①最後まで到達したか ②所要時間 ③記入できた項目数 ④7日後に1回でも開き直したか

**④が「戻る設計」の唯一の直接検証である。**

# 8. 仮説の採用・保留・棄却基準

## 8.1 面談（n=15〜20）

| # | 仮説 | 採用 | 保留 | 棄却 |
|---|---|---|---|---|
