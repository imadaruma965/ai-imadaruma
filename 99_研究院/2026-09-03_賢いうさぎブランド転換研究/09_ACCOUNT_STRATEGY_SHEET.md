## 1.1 基本

**三浦圭介、42歳。フリーランスのWebデザイナー兼ディレクター。独立9年目。福岡在住。既婚、子ども1人。**

生活に困窮はしていない。**ただし、下がり出している。** そしてその事実を、確定申告の直前まで正確には見ていない。手残りは本人も把握していない。

案件は同時に4本、うち2本は納期を1回延ばした。理由を先方には「先方確認待ち」と伝えたが、実際は着手が遅れた。

**能力は高い。** 制作の腕は同業の中でも上位で、**やり出すとバシッといいものを作る。** だから食えている。**食えているから、余計に問題が見えにくい。**

**ただしリピートは取れていない。** 仕事は主に紹介経由で、その紹介数が減ってきた。**質は落ちていないのに、次が来ない。**

## 1.7 ペルソナ修正記録（2026-09-04・第2次・BOSS指摘）

初版の設定を4点で修正する。**うち1点は、これまでの前提と逆である。**

### 修正1：自己認識【最重要・従来と逆】

| 初版 | 修正後 |
|---|---|
| 始めるのは得意で、終わらせるのが苦手 | **始めるのも不得意。嫌なものは避けがち。ただし乗ると速い。そして止めるのが大の苦手** |

正確な機構はこうである。

```
着手が遅い（回避）→ 乗ると過集中で速い → 完璧にしたくて止められない → 終わらない
```

**責任感が強く、細かいところにこだわりすぎるあまり、終わらない。** これは飽きているのではない。

### 修正2：なぜ避け、なぜ止められないのか【心理の根】

**過程ではなく成果を評価されて育った。** 家庭教育がそうだった。結果を褒められ、過程は褒められなかった。

その帰結が3つある。

1. **負ける恥が怖い。** だからチャレンジの量が減った。着手できないのは怠惰ではなく、**失敗が確定する場所に自分を置きたくない**からである。
2. **完璧でなければ出せない。** 結果でしか評価されない世界観では、未完成の提出は敗北である。だから止められない。
3. **「努力しろ」と説くビジネス書にうんざりしている。** 過程を褒められた経験がないため、過程を称える言葉が身体に入らない。

**この3点目は、ブランドの語り方を直接拘束する。** 努力・継続・習慣を称える文体は、この人に届かない。**08 L7（亀を敵にしない）と両立させる必要がある。否定はしないが、称賛もしない。**

### 修正3：健康と身体

- 疲れが抜けない。集中力が落ちてきている自覚がある
- PC作業が長く、**首が痛い。腰痛もひどくなってきた。下腹が出てきた**
- 子どもは「デザインの仕事をする父」をかっこいいと思ってくれている
- **だからこそ、先行き不安と、オッサン化する身体に、いつ愛想を尽かされるかが怖い**

**この項目は、ブランドが直接扱わない領域である**（身体資本は修身省の管轄）。ただし**「集中力が落ちた」の原因を本人が能力の衰えだと誤認している**点は、コンテンツで扱える。

### 修正4：単価下落への本人の理解

「AIの進化のせいか？」とは思っている。**AIをうまく使っているデザイン系が伸びているらしいとも聞いている。**

**しかし、よくわからない。** だから今までの経験値のまま、アナログな発想でPCを使ったデザインワークを続けている。**労力だけがかかっている。**

**ここが商品の接続点である。** この人はAIを学びたいのではない。**「よくわからないまま労力だけかかっている」状態を終わらせたい。**

### 修正5：本棚

ビジネス書に加えて、**デザイン関係のハウツー本も多い。** つまり積読は2系統ある。仕事のやり方の本と、技術の本。**どちらも「足す」方向である。**

### 修正6：この人が今いる分岐点【最重要・購買トリガーの本体】

三浦圭介は、いま**2つの選択肢の間で止まっている。**

```
A. 今のデザイン事業を軌道修正する（AIを取り込む・上流へ移る・単価を上げる）
B. 新しく事業を始める（副業・別領域・コンテンツ販売）
```

**そして、決められない。** 半年以上この状態が続いている。

**決められない理由は、優柔不断ではない。判断基準を持っていないからである。**

- Aを選ぶべき根拠は何か。何がどうなったらAが正解だと言えるのか
- Bへ動くべき合図は何か。今の事業の何を見たら「もう伸びない」と判断できるのか
- **どちらも分からないので、どちらも選べず、代わりに情報を集め続けている**

### なぜBに傾くのか【仮説・断定しない】

**新しいことを始めたくなる衝動の一部は、今の事業の中に見たくない場所があることの裏返しである可能性がある。** Sirois 2013（先延ばし＝短期的な気分修復）とMandel 2017（自己不一致の補償的消費）が示す機構は、書籍の購入だけでなく、事業判断のレベルでも同じ形で起こりうる。

**ただし断定してはならない。** 本物のピボットは存在する。市場が本当に縮小していれば、Bが正解である。**問題は、本人にAとBを見分ける基準がないことであって、Bが常に逃避だということではない。**

### 商品への含意

**基準を渡すのが商品の仕事である。**

これは08で扱った「やめどき」の問題そのものである。**続けるか、やめるか、変えるか。この判断は、事前に基準を決めていなければ、感情と直近の出来事で決まる。**

そしてこれは、商品の位置づけを1段引き上げる。

| | 従来の位置づけ | 修正後 |
|---|---|---|
| 何の商品か | 自己管理・生産性 | **事業判断の材料づくり** |
| 何を解決するか | 終わらない、散らかる | **半年止まっている意思決定を、動かす** |
| ¥49,800の根拠 | 自己投資 | **年商700〜900万円の事業の進路判断** |

**08 §2でH4（非対面・実証ゼロ・煽りなしで¥49,800が売れるか）を最も薄い仮説としたが、この分岐点はH4の根拠を2つ目として補強する。** 三浦にとってこれは自己啓発の買い物ではなく、**半年止まっている経営判断に決着をつける支出**になる。

### 面談での確認事項

**「今の事業を続けるか、新しいことを始めるか、迷っていますか」と直接聞く。** そして「迷い始めてどれくらいですか」「何が分かれば決められますか」を続けて聞く。

**この2問の答えが、H4の実在を判定する最短の材料になる。**

### 年収帯の設定根拠【EVIDENCE】

| 指標 | 数字 | 出典 |
|---|---|---|
| 専業フリーランスの年収中央値 | **400万円前後**（400万円以上が49.5%） | ランサーズ実態調査 2024 |
| 副業含む全体の中央値 | 200万円前後 | 同上 |
| 2025年の年収分布 | **52%が400万円以下、5%が1,000万円超** | LiKG調査 2026年2月 |
| フリーランスWebデザイナーの年代別ピーク | **40代で約657万円**（50代も600万円台） | 業界メディア（グレードC） |
| Webディレクター平均年収 | 約433〜499万円（出典により変動） | 求人メディア（グレードC） |
| Web案件の月額単価ボリュームゾーン | 50〜60万円台 | 業界メディア（グレードC） |

**設定：年商700〜900万円、所得500〜650万円。ピークは2〜3年前。**

この帯を選ぶ理由は3つある。**第一に、52%が400万円以下という分布の中で、¥49,800を払える上位半分に入る。第二に、40代Webデザイナーのピーク657万円と整合する。第三に、月額50〜60万円台のボリュームゾーンで稼働率が落ちた状態を表現できる。**

### 下がっている理由は、記録されている【EVIDENCE】

この人の減収は、気のせいでも景気でもない。業界データが原因を特定している。

| 指標 | 数字 |
|---|---|
| AIで生産性が向上したと回答したエンジニア | **81.9%**。ただし実際に月単価が上がったのは**約40%** |
| AI Engineer の月単価 | 87.5万円（**前年比 +7.1万円**） |
| Engineering Manager | 95.6万円（**+9.2万円**） |
| SRE | **前年比 −5.1万円** |
| Web制作 | 「作る速さ」は差別化にならなくなり、制作だけの案件は減少。**単価を分けるのは「決める力」と「言語化する力」** |

（出典：Findy 2026年調査、フリーランスボード2026年6月、業界メディア。いずれもグレードC）

**ここに決定的な一致がある。** この人の年収が下がっている理由として業界が挙げている軸は「決める力」と「言語化する力」であり、**それは本ブランドの商品が出力するものそのものである。**

したがって¥49,800は、自己啓発への支出ではない。**下がり続ける側から、上がる側へ移るための事業投資として提示できる。** 08 §2でH4（非対面・実証ゼロ・煽りなしで¥49,800が売れるか）を最も薄い仮説としたが、**この接続はH4の根拠を1つ増やす。**

### 修正記録（2026-09-04・BOSS指摘）

当初この人物を「全部読んで、それでも変わらなかった人」と設定した。**これは誤りである。正しくは「読みたいと思って買い、まだ読んでいない人」。** 理由は2つある。

**第一に、恥の質が違う。** 「読んだのに変わらなかった」は失望であり、本のせいにもできる。**「買ったのに読んでいない」は純粋な自責で、逃げ場がない。** 後者の方が強く、後者の方が動く。

**第二に、こちらが購買実績のある層である。** 積読の山は、希望に金を払った記録そのものである。読了して失望した層より、この層の方が既に金を動かしている。07で確認した「支出が全額、足す方向に流れている」という構造の、最も純粋な現れがこの本棚である。

**なお「言葉は全部知っている」（08 §6.1）は、この修正後も成立する。** この人は本を読まずに語彙を持っている。Xのスレッド、YouTubeの要約、書籍要約サービスから摂取しているためである。**読んでいないのに知っている。これが2026年の実態であり、恥をさらに強くしている。**

### 積読が発生する機構【科学的裏づけあり】

補償的消費行動モデル（Mandel, Rucker, Levav & Galinsky 2017, *Journal of Consumer Psychology* 27(1):133–146）は、人が「現在の自己」と「なりたい自己」のずれを消費で埋めることを示している。

**この人にとって、本を買う行為は「その本を読んだ自分」を一時的に手に入れる行為である。買った時点で目的は達成されている。だから読む必要がない。**

積読は失敗ではない。**買った瞬間に、機能を果たし終えている。** ただしその機能は「なりたい自分を一時的に手に入れること」であって、「なること」ではない。

**そしてこれは、この人の机の上に物理的に存在する。** 診断も煽りも不要で、本人が目を上げれば確認できる唯一の証拠である。**入口はここにある。**

### 引き受けるリスクと、その解決

この層は、06 §30 S3が「最も熱心に反応し、最も実行しない」と警告したノウハウコレクターと同一である。**この層を狙うということは、その警告を正面から引き受けるということである。**

解決は、ターゲティングではなく商品設計に置く。

1. **フロント商品の仕事は、この人が最後までやれる最初のものになることである。** 所要時間を明示し、17分から30分で完了する設計にする。14日の拘束にしない。
2. **完了を購入直後に測る。** 後日のアンケートでは取れない。
3. **積読の山に載る商品を作らない。山を見る商品を作る。** これがLEVEL 2（足す前に見る）の商品側の実装である。

### なぜこれが最重要の競合なのか

**三浦圭介がいま迷っている選択肢Bの受け皿が、まさにこの層だからである**（§1.7 修正6）。

```
三浦の分岐点
├ A. 今の事業を軌道修正する ←── 本ブランドが提案する道
└ B. 新しく事業を始める     ←── note型「AI × 稼ぐ」発信者が受け止める道
```

**同じ人の、同じ財布を、逆方向に引っ張っている。** そしてBの方が、見た目には魅力的である。金額が具体的で、手順があり、デザインスキルがあれば書けそうに見えるからである。

### 扱い方（08 L7：敵にしない）

**攻撃しない。彼らが売っているものは正しい商品である。** 新しい収益源を作ること自体に問題はない。

言えるのは**順序についてだけ**である。そして言い方は、事実の指摘に限定する。

> 三浦は今、4本の案件を抱えて2本が遅延している。**そこに5本目を足すことになる。**

これは道徳的な批判ではなく、稼働の算数である。**「新規事業は悪い」とは言わない。「今動いていない2本を見ないまま5本目を足すと、遅延は3本になる」と言う。**

### この層から得られる追い風

**この層の存在は、需要の証明でもある。** 東中の月30万円も、ゆとりの1,200部も、**三浦のような人が実際に金を払っている証拠**である。関心も支払意思も実在する。

**取るべき位置は、Bの否定ではなく、Bの前段である。** 「新しく始める前に、今どこで止まっているかを見る」。これなら、Bを選んだ人にも価値が残る。

### 価格への含意

note実用ノウハウ系の平均が**1,842円**である。**フロント¥4,980は、この平均の約2.7倍にあたる。** 単発記事ではなく、ワークシートと動画とAI設定を含む商品として、価格差の説明が必要になる。

一方で**メンバーシップ売上が前年比+80%超**という成長は、09 §8のnoteメンバーシップ¥980の判断を支持する。
