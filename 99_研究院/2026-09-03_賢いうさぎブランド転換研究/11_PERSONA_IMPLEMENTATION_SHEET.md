# 0. 最初に読む3行

1. **性別を書かない。** 男性を示す語（大黒柱・奥さん・オッサン・父）を1語も使わない。
2. **「苦しんでいる人」として書かない。** この人は全般に満足している（78.5%）。**止まっているだけである。**
3. **一般語で書かない。出来事で書く。**「仕事が終わらない」ではなく「納期を1回延ばした」。

# 1. 第一ペルソナ 1ページ要約

## 一文の定義

> **独立5〜15年、個人年収500〜900万円台の、納品物のある無形サービスの一人事業者。仕事の質でリピートは取れているが、新規の紹介が細り、単価が2年上がっていない。同時進行の案件のうち1本は、着手の遅れが原因で納期を1回延ばしている。性別は問わない。年齢は40代を中心とする。**

## 固定項目（動かさない）

| 項目 | 値 |
|---|---|
| 雇用形態 | **個人事業主・法人代表。給与所得者は含めない** |
| 年齢 | 中心40代／許容35〜54歳 |
| 性別 | **限定しない** |
| 独立年数 | 5〜15年 |
| 個人年収 | 500〜900万円（経費控除前売上） |
| 業態 | **納品物があり、締切がある無形サービス**（Web制作・デザイン・映像・執筆・技術・コンサル等） |
| 集客 | 紹介と既存取引先が7割・6割 |
| 売上 | **上がっていない。下がってもいない** |
| 生成AI | 使っていない、または使っているが単価に反映できていない |
| 支出 | 足す方向に年12〜20万円。測る方向に0円 |
| 一人になれる時間 | **1回30〜60分**（商品の所要時間はここから逆算する） |

## 設定しないもの

居住地／子どもの人数・年齢／映画・音楽／起床就寝時刻／身体の不調／学歴／配偶者の職業／**性別を示す一切の表現**

## 中核機構（コピーの骨）

```
評価される場所を避ける
  ↓ （締切が近づく）
着手する。速い
  ↓
「これで出す」と決められない
  ↓
終わらない
  ↓
未完了が、次の着手を重くする   ← ここが独自Problem
  ↓
最初へ戻る
```

**科学的裏づけ**：Steel 2007（課題の嫌悪性が最強の予測因子）／Sirois et al. 2017（先延ばし × 完璧主義的懸念 r=.23, k=43, N=10,000）／Leroy 2009（未完了タスクの注意残余）

# 5. 本人の代表的な言葉

## 確認済み（08 §6.2 継承・【EVIDENCE-C】）

「気づいたら1日終わってる」／「始めるのは好きなんだけどね」／「また買っちゃった」／「今度こそちゃんとやる」／「机の上、見せられない」／「稼いでるはずなんだけど、残ってない」／「三日坊主なんですよ、昔から」

## 本調査で追加（【EVIDENCE-C】）

「指示しにくい、修正をお願いしにくい」（年下の発注者から見た自分）／「仕事が減るのは、センスが落ちるからだけではない」／「会社のありがたみがよくわかる」（帳簿について）／「一日声を発さない」

## 未取得（面談でのみ得られる・【UNKNOWN】）

朝に考えること／着手前の独り言／先延ばし中の言い訳／深夜の自己嫌悪／購入直前の迷い

**→ 面談で取得するまで、この4つを想像で埋めた文をコピーに使わない。**

# 13. 刺さる言葉 / 避ける言葉

## 刺さる（原則：出来事＋数字＋問い1つ）

- 「納期を1回延ばした。理由は先方確認待ちだと伝えた」
- 「先月、何時間働いたかは言える。何が残ったかは言えない」
- 「足すのはタダで、やめるのは高い」
- 「続けられるようにはならない。それでも成果が残るようになる」
- 「習慣化を4回目も勧める人を、あなたはもう信用していない」
- 「17分で、自分がどこで止まっているかが1枚に出ます」
- **「生産性が上がったと答えた人は8割。単価が上がった人は4割。差の4割は、速くなった分をそのまま渡している」**
- **「仕事が減ったのは、腕が落ちたからではないかもしれない。あなたに発注していた人が、発注する立場でなくなっただけかもしれない」**
- **「あなたのせいではない部分がある。そのうえで、あなたが決められる部分だけを扱う」**

## 避ける

「賢いあなたなら」／「大黒柱」「奥さん」「オッサン」「父として」／「科学的に証明された」／「亀」「うさぎ型」（単独で）／「自己統治」「資源配分」「実行機能」「メタ認知」（対外）／「脳内デバッグ」／「解説」／絵文字

## 使ってよい業務語（08 §6.1）

ボトルネック、レバレッジ、工数、要件定義、優先順位、リソース、KPI
**——使わないと知的水準が合わない。ただし読者へのラベルには使わない。**

# 16. Xでの接触時間帯

## 【UNKNOWN】—— 決め打ちしない

一次データが4研究連続でゼロである。**確認できたのは1点だけ。**

【EVIDENCE-A】インターネット利用の時間帯別行為者率は、**全年代で平日・休日とも21時台が最も高い**。平日は7時台〜23時台まで（14時台を除き）20%超で推移し、12時台は33.5%。

【EVIDENCE-A】40代のSNS接触は**平日35.7分/日・休日40.9分/日**。**長文を読む場所ではない。**

## 90日の実測手順

**07時／12時／17時／21時の4枠で、同型の投稿を回す。** 判定は**保存数とプロフィールクリック率**で行い、いいね数では行わない。
