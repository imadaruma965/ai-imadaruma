# 2. WHERE 06 OVERREACHED

06の推論の飛躍を5点、一つずつ監査する。

| # | 06の飛躍 | 監査 |
|---|---|---|
| O-1 | **「時間管理市場に需要がある」→「時間管理を看板にすべき」** | 需要の存在（EVIDENCE）から看板（STRATEGIC INTERPRETATION）への飛躍。Udemyの8,158評価は¥1,300で買われた講座であり、「時間管理」を看板にした個人は既に数千人いる。需要の存在は**入口**を正当化するが、**看板（Problemの定義）**までは正当化しない。06自身が §16で「差別化は技術で行う」と書いたが、技術（置き場所）はProblem語ではないため、プロフィールに独自のProblemが不在になった |
| O-2 | **「自己統治・資源配分は検索されない」→「独自思想としても使えない」** | 検索カテゴリー不在（EVIDENCE）と思想の有効性（別問題）の混同。ハウセルの「Psychology of Money」も2018年時点では検索カテゴリーではなく、ブログ記事1本が需要を作った（V-1）。**検索されない語を看板にしない**は正しいが、**顧客の言葉で語られる独自Problem**は別に持てる。06はその席を空けたままにした |
| O-3 | **「『能力はあるのに』系の商品市場証拠が弱い」→「Problem framingとしても弱い」** | Amazon 17件全滅（EVIDENCE）は「能力はあるのに報われない」を**商品名**にした本が売れないことを示す。X上のProblem framingとして機能するかは**UNKNOWN**（3研究ともX一次データゼロ）。ただし06の「主語が自己正当化に見える」（A・B一致）は独立に妥当。本審の結論：**「能力はあるのに」は使わない。しかし「全部やっているのに残らない」という行動記述は別物で、未検証** |
| O-4 | **「個人のお金心理商品の実績が弱い」→「お金の心理需要そのものが弱い」** | 06は §8で「世界的著者の思想書には払う。個人の心理解説には払わない」と書き、区別自体はしている。しかし決裁ではお金を「第二資源」へ一括降格した。本審は §6〜§9で、**お金思想書が売った中身は「心理解説」ではなく「人生の見方の更新」**であり、需要は強いが**「心理」の棚で売った本だけが死んだ**ことを示す。降格の理由は「需要が弱い」ではなく「無名の個人がその需要を取る回路が未実証」に置き直す |
| O-5 | **「既存商品がない」→「市場がない」** | 06 §31-11で「ワークブック型の実売統計なし」を理由に第一商品から外した。§18で区別するが、NO PRODUCT≠NO MARKET。日本ではFP資格者（横山、V-8）と最上位発信者（両学長→リベシティ）が「書籍→実装」を有料化しており、**実装需要はあるが供給者が資格・知名度で閉じている**が正しい記述 |

**総括**：06は証拠の読みは正確だが、**Problem層の設計を放棄して市場カテゴリーをそのままProblemにした**。これがO-1〜O-5の共通根である。

【STRONG INFERENCE】
1. **緊急性と支払が最も重なるのは「仕事が終わらない・時間が消える」**（06の入口判断は正しい）。
2. **金額として最大の支出が動いているのは「将来のお金が不安」**だが、その支払先は「増やす」（NISA・お金の大学）であり、既に両学長と証券会社が占有している。無名の個人がここに入る余地はない（06と一致）。
3. **見落とされていたのは「残らない」**。横山光昭の3万件相談・414万部（V-8）は、「家計再生」＝残らない人が**個別相談に払う**ことを示す最大の日本国内証拠であり、06はこれを見ていなかった。ただし供給者はFP資格者である。
4. 「学んでも変わらない」「努力の割に残らない」は強く自覚されているが、**それ自体を商品名にしても売れない**。この二つは**入口ではなく、LEVEL 2のProblemとして使う**（§14）。

# 5. WRONG-SOLUTION ANALYSIS

仮説：「本人が考えている原因と本当のボトルネックが違うため、表面的Solutionへ繰り返し払っている」。**反証優先**で検証する。

## 5.1 反証の試み

| 反証候補 | 結果 |
|---|---|
| 「稼ぐ・増やす・学ぶ」への支出は合理的な問題解決ではないか | **部分的に反証成立**。NISAは平均的には合理的（Dynan 2004：所得が高いほど貯蓄率も高い＝多くの人は「増やす」で解決している）。自己投資も月7千〜3万円なら合理的な範囲。**「全員が誤ったSolutionを買っている」は否定される** |
| 副業・情報商材の高額契約は詐欺の問題であり心理の問題ではない | **部分的に反証成立**。V-3のトラブルは違法勧誘を含む。ただし「簡単に稼げる」訴求に平均106万円を払う行動そのものは、**「稼ぐ」への希望に高額を払う意思**の証拠として使える（詐欺の存在は需要の強さの裏面） |

# 10. MONEY AS A BOTTLENECK

【FOUNDER N=1】「自分の場合、お金への捉え方・使い方・心理が人生の大きなボトルネックだった」。一般化しない。無視もしない。

| 論点 | 科学的判定（01・06の範囲） | 本審の扱い |
|---|---|---|
| 稼ぐ／守る／使う／待つ／増やす能力は別か | **別（B）**。IQ→所得あり、IQ→純資産なし（Zagorsky）。所得と資産は別関数 | 「稼ぐ能力があるのに残らない」は科学的に**あり得る**構図。ただし逸脱ケース（Dynan） |
| 金融知識と行動のギャップ | **大（A）**。知識+0.15〜0.20SD、行動+0.06〜0.10SD（Kaiser） | 知識を売らない |
| Money Beliefs／マネースクリプト | **D**。KMSI-R因子妥当性不支持 | 使わない |
| Present Bias／Delay Discounting | **B**。カード債務と頑健に関連（Meier & Sprenger） | 「今と後の交換」が漏れの一段階として扱える |
| Reward Sensitivity／Impulse Buying | C（Bangma：統制後非有意） | 診断名と結びつけない |
| Scarcity | C（Mani 2013追試不良） | 使わない |
| Status／Identity Consumption | **B**（Mandel 2017、V-11） | 「補償として買う」構図は理論的に妥当 |
| Anxiety | C（財務不安→回避2.75倍） | 「不安→増やす商品を買う」は妥当な仮説 |
| Social Comparison | AoSMレビュー「上を見たらキリがない」 | 顧客語として実在 |
| 家庭・文化のMoney Scripts | D（交絡未分離） | 使わない |

**裁定**：お金は「Root Cause」ではなく、**漏れが最も測りやすく、介入効果が最も実証されている資源**（Ashraf +81%）である。「すべてはお金の心理」は禁止（06と同じ）。ただし06の「お金＝第二資源」は、**「お金＝漏れが最初に数字になる場所」**に置き直す。フリーランスにとってお金の漏れ（請求漏れ・税金の未準備・手残りの不明）は、時間の漏れと同じ構造で同じ人に起きる（**【FOUNDER N=1】＋ルカの設計思想。市場証拠はUNKNOWN、§28 実験2で検証**）。

# 11. PRODUCTIVITY-ALONE FALSIFICATION

「正しい仕事術と仕組みがあれば成功できる」を疑う。

| 仕事術は何か | 判定 | 根拠 |
|---|---|---|
| ROOT CAUSE | **否定** | 構造要因（Card 2013：企業効果18〜21%、Chetty：ランク傾き0.34）が同等以上。仕事術で企業も親も変わらない |
| TOOL | **部分的に妥当** | 実装意図 d=0.65、習慣媒介（Galla）。仕組みは「作動すれば」効く |
| SYMPTOM MANAGEMENT | **部分的に妥当** | 先延ばしが気分修復（Sirois）なら、仕事術は症状の管理であり、気分修復の需要そのものは消えない。TaskChute・Notionを試しては止まる（06 ICP）のはこのため |

他資源との関係：
- **お金**：終わらない仕事は請求・売上として即座に金の漏れになる（06 Trigger）。
- **注意**：科学C〜E。時間の内側に置く（06）。
- **欲望・感情**：先延ばし＝感情調整（B）。仕事術単独では扱えない。
- **健康**：睡眠+27分は効果なし（Bessone）。仕事術の外。
- **運・人間関係・機会**：構造要因。ブランドは扱わない。

**裁定**：仕事術はTOOLであり、**「仕組みがあれば終わる」は、感情調整（回避）と資源の漏れを設計に含めない限り成立しない**。06の「置き場所と仕組み」は仕組み側だけを設計し、**なぜ仕組みが壊れるか（漏れ）**を商品に含めていなかった。

## 12.2 漏れの段階モデル（改善版）

指示のモデル（ABILITY→CHOICE→ALLOCATION→ACTION→COMPLETION→CAPTURE→RETENTION→COMPOUNDING）を、科学の支持と市場の理解可能性で点検した。

| 段階 | 漏れの内容 | 科学の支持 | 顧客語 |
|---|---|---|---|
| ABILITY→CHOICE | 何をやるか決めていない（使い道未決定） | B（04「使い道を決めていない」、機会費用の無視 Frederick 2009） | 「散らかる」 |
| CHOICE→ALLOCATION | 決めたが時間・金を割り当てていない | B（実装意図 d=0.65） | 「予定に入っていない」 |
| ALLOCATION→ACTION | 割り当てたが着手しない | **B**（先延ばし＝気分修復、Sirois 2013） | 「先延ばし」 |
| ACTION→COMPLETION | 着手したが終わらない | B（習慣・環境、Galla） | 「終わらない」 |
| COMPLETION→CAPTURE | 終わったが回収していない（請求漏れ・値付け・納品後の放置） | 【FOUNDER N=1】ルカの設計対象。市場証拠UNKNOWN | 「請求漏れ」「安請け合い」 |
| CAPTURE→RETENTION | 回収したが残らない（税金未準備・生活膨張・衝動） | B（現在バイアス→債務、Meier & Sprenger） | 「残らない」 |
| RETENTION→COMPOUNDING | 残ったが積み上がらない（学び・資産・信用の複利が働かない） | C | 「前進している感覚がない」 |

# 19. ANTI-GENERICITY TEST

**06のプロフィール案A**「能力もAIもあるのに、大事な仕事が終わらない。時間もお金も残らない。そういう人の『置き場所』と『仕組み』を本人専用に設計しています」——**同じ文を他の100人の時間管理コーチ・AIコンサル・仕組み化発信者が使えるか？ → YES**。「置き場所」「仕組み」「本人専用」は全員が使える。**不合格。**

**本審の戦略**「入力を増やす前に、時間と金と成果がどの段階で漏れているかを一枚にする」——同じ文を100人が使えるか？ → 文としては真似できるが、**7段階の漏れモデル、自作の漏れ検知OSの実録、25年の可視化技術による「一枚」**は真似に時間がかかる。**条件付き合格**（コピーの模倣は防げない。モデルと実録で防ぐ）。

**なぜ時間管理専門家でも、金融専門家でも、AI専門家でも、自己啓発発信者でもなく、このアカウントをフォローするのか**：
> **時間・金・成果を別々に扱う専門家の誰も見ていない「途中で漏れている段階」を、自分自身の漏れ検知OSと実録で図にして見せる、唯一の設計者だから。**

# 23. X HOOK STRESS TEST

条件：説教しない・診断しない・煽らない・ライフハックにしない。目的は「思考を止めるProblem framingか」の確認であり、投稿作成ではない。

# 30. FINAL VERDICT

**STRATEGIC PIVOT。**

06が正しく特定した市場入口（仕事術・時間管理の棚、「終わらない・残らない」フリーランス・一人社長）と商品設計原理（知識でなく装置）は維持する。転換するのは、06が空欄のままにした**所有すべきProblem**と、それに伴う**第一商品の形**である。

- 06の暗黙の推論「市場が存在するカテゴリー＝ブランドが名乗るべきカテゴリー」は、O-1〜O-5の監査で棄却した。カテゴリーは入口、Problemは別に所有する。
- 「お金」は第一語にしない（06と同じ）。しかし「お金心理の需要が弱い」のではなく、**「心理の解説」が売れず「自分の行動を説明する言葉」が売れる**ことを、著者力を分解して確認した（§6〜§8）。この需要は無名でも取れる可能性がある（ハウセル・パーキンスは日本で無名だった）。
- 実装需要は米国（FPU）と日本（横山・リベシティ）で実在するが、供給は資格者と最上位発信者に閉じている。本ICPの「漏れ」Painでの転換は**UNKNOWN**であり、90日で¥9,800の「見える」商品として検証する。
- 「能力があるのに」も「すべてはお金の心理」も採用しない。採用するのは行動記述としての**「入力は足りている。途中で漏れている」**である。

## 医療ガードレール（§30 指示への回答）
ADHD・ASD・双極症・依存症・問題のあるポルノ利用を、「漏れ」を含むいかなる一つの原因でも説明しない。薬と自己統治を比較しない。「漏れの7段階」は日常行動・意思決定・支出・時間・注意・環境・自己観察・仕組みの記述であり、診断・治療・障害の示唆ではない。先延ばしを「気分修復」と説明する際も、Sirois & Pychylを人間一般の傾向として引用し、個人の病理へ接続しない。金の漏れは可視化と配置までで、投資・保険・税務の個別判断には入らない。
