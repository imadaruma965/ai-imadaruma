# finance_board — 最小財政統治ボード

> **目的**: 会計ではなく、**今月の資金不足と必要売上**を判断する  
> **日次の入力補助**: キングダムOS 月次（`invoices` / `liabilities` / `personalFinance` / `fiscalMeta.defenseLine`）  
> **本ファイル**: 週次〜随時の統治スナップショット（税務・複式簿記は対象外）  
> **接続**: `roadmap_500k.md` v2／営業タブ（確度加重）／`governance_board.md` §B  
> **作成**: 2026-07-28

---

## 運用

| 項目 | 内容 |
|------|------|
| **更新** | 最低週1。支払期限が近い週は毎日30秒スキャン |
| **朝** | Smart Rabbit / morning_cabinet が「不足・期限・未入金」を見る |
| **正本数字** | 可能ならOSから転記。矛盾したら**銀行残高とOSを優先**し、本表を直す |

## 2. 計算（必ず埋める）

```text
月末予測残高
= 現在残高
+ 確定入金
+ 入金予定
− 固定費
− 変動費
− 支払予定
```

| 計算結果 | 円 |
|----------|-----|
| **月末予測残高** | |
| **資金不足額** = 最低必要残高 − 月末予測残高（負なら0と書き「余裕」） | |
| **今月必要売上**（不足を埋める／防衛ライン到達に要する入金） | |
| **月50万との差額** = 500,000 − 今月確定+予定の売上計上 | |

```text
確度加重売上 = Σ(見込み金額 × 受注確度)
```

## 5. キングダムOSとの対応

| 本ボード | OS |
|----------|-----|
