# ai-imadaruma

ai-imadarumaは、いまだ唯仁という個人国家を統治するAI内閣である。日本語名は**イマダルマAI統治内閣**。

これはAI秘書ではない。BOSSであるいまだ唯仁の理念・目標・判断を、現実の実行計画へ落とし込むAI統治システムである。

- 作業のルールと振り分けは [`CLAUDE.md`](CLAUDE.md)（開発憲法）
- AI主管の正本は [`01_内閣府/AI主管定義.md`](01_内閣府/AI主管定義.md)

---

## 第一国家目標

**2026年11月30日まで**に、サッカー以外の事業で**月間総合売上50万円以上**を、継続案件として樹立する。

- **含める**：imadaruma.sound ／ Daily Statecraft ／ Kindle・Publishing ／ SNS経由の商品・サービス ／ その他サッカー以外の事業
- **含めない**：サッカー事業 ／ 投資運用益（imadaruma.capital は財政の柱に残すが売上には数えない）

正本は `00_律令府/憲法/第一国家目標.md`（11/30＝達成判定日、12/9＝宣言の象徴日）。

### じぶん憲法（最高法規）

- **標語**：葦なる刃は、静かに尖れる。
- **中核文**：人生は選択である。選択が国家を定める。

すべてのAI・戦略・日次運用は、この憲法の下位に位置する。

```
いまだライフ理念（Purpose / Vision / Mission / Values）
  ↓
じぶん憲法 v3
  ↓
四柱統治フレームワーク（人格・内政・外交・財政）／明君七徳
  ↓
執行：BOSS ＋ AI内閣6体 ／ 点検：00_律令府/点検リスト.md
  ↓
日次運用・戦略・記録
```
