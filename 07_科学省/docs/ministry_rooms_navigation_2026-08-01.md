# 統治手帳ナビゲーション再編 — 10省庁の部屋（2026-08-01）

## 目的

タブ列（全体・今日・内閣・内省・週・月・営業・一覧・新規）を、国家OSの10省庁体制（`01_首相官邸/ai_jurisdiction.md`）に合わせた「部屋」へ再編。各部屋を開くとその省庁のAIがいて直接相談でき、既存の機能画面（タスク・営業・KPI・財務など）はそのまま対応する省庁の部屋に格納する。

既定の着地点は首相官邸（スマートラビット）。

## 部屋割り当て

| タブ | 中身 | AI |
|------|------|-----|
| 首相官邸 | **相談を先頭・起動時の既定画面**。サブタブ: 相談／一覧／新規／ダッシュボード（旧・全体） | スマートラビット |
| 経産省 | 月の目標・KPIボード（財務の実数は除く） | 栄一（新規埋め込み） |
| 内務省 | 今日／週／**アイデアメモ** をサブタブで束ねる（今日にAI尊徳は元々内蔵） | 尊徳 |
| 教育省 | 内省（七徳日次チェック） | ヤマト（新規埋め込み） |
| 外務省 | 営業・案件パイプライン | 坂本龍馬（新規埋め込み） |
| 法務省 | 相談のみ | 韓非子（新規埋め込み） |
| 科学省 | 相談のみ | テスラ（新規埋め込み） |
| 情報省 | 相談＋3人サブピッカー | ダ・ヴィンチ／ルパン／アショーカ |
| 文化省 | 相談＋2人サブピッカー | 北斎／正篤 |
| 財務省 | 財政スナップ・負債台帳・請求書・個人財務（月タブから移設） | ルカ（新規埋め込み） |

割り当ての根拠（今さん確認済み）:
- 月タブの財務系ブロックだけ財務省へ。KPIボード（売上進捗・外交/発信・内政・七徳）はまとめて経産省に残す
- 内省（七徳）→ 教育省（ai_jurisdiction.md上は尊徳の日次実行にも七徳項目があるが、教育省を選択）
- 営業（案件パイプライン）→ 外務省（ai_jurisdiction.mdで坂本龍馬の起動時参照ファイルに`sales_pipeline.md`が明記されているため）

## 実装

- バックエンド（`server.cjs`の`/api/cabinet/*`、`lib/cabinet-registry.cjs`）は無変更。メンバー非依存の汎用実装だったため。
- `app.js`: 単一パネルを全メンバーで使い回していた実装を`mountCabinetChatWidget(mountEl, memberId)`という部品化された関数に置き換え。各省庁の部屋は自分専用のマウント先(`#chat-mount-<member>`)を持ち、会話データ(`state.cabinetChat[memberId]`)とAPI呼び出しは既存のまま再利用。
- `index.html`: 主タブを10ボタン化。首相官邸・内務省のみサブタブ(`.room-subtabs`)で複数の既存viewを束ねる。他は単一view。
- 月タブから財務ブロック(財政スナップ・負債台帳・請求書・個人財務)を財務省タブへ移設(要素idは無変更のためJS側の改修は不要)。
- 内部のview id(day/week/month/sales/all/new/home/reflect/smartrabbit)は維持し、churnを避けた。新設したのは`zaimu`/`houmu`/`kagaku`/`jouhou`/`bunka`のみ。

## 動作確認

- `node --test`: 変更前と同じ結果（バックエンド無変更のため regression なし）。
- Playwright(headless Chromium)で別ポート起動し、10部屋すべてのタブ切替・内務省/首相官邸のサブタブ・情報省/文化省のサブピッカー・財務省への機能移設を確認。実Cursor APIコストを避けるため、この検証では偽のAPIキーを使い、認証エラー経路(401/500)で配線のみを確認した。
- 検証中、新設4部屋(外務省/法務省/科学省/文化省)への初回訪問で本番`state.json`に開幕挨拶失敗のエラーメッセージが4件生成されたため、確認後に削除して本番データを元へ戻した。
