## 2. 目的（技術側の翻訳）

1. ランサーズ等の**仕事通知メールを人手で全件開かない**  
2. 自動で Sheet「仕事リスト」に集約し、優先度を付ける  
3. **毎日 Top20** だけが**外務**（および統治手帳の外交／仕事閲覧）から見える  
4. 発注・受注管理にはまだ繋げない（閲覧＋応募判断まで）
---

## 3. アーキテクチャ（Phase 1）

```text
imadaruma965@gmail.com
  └ Gmail ラベル: Lancers/Jobs（手動 or フィルタ）
        ↓ 定期ジョブ（15〜60分）
  Gmail API (readonly) で未処理取得
        ↓ パース（件名・本文・URL・予算・締切）
  重複判定（案件URL）
        ↓
  Google Sheet「仕事リスト」追記
        ↓ スコア列
  ビュー「本日Top20」
        ↓
  統治手帳「外交／仕事」パネルから Sheet / Top20 を閲覧（読み取り）。主利用者は外務
```

既存資産の再利用:

- Sheets 追記: `07_科学省/taskboard/gsheets.cjs`（サービスアカウント or OAuth）  
- OAuth 基盤: `07_科学省/taskboard/google-oauth.cjs`（現状 Calendar + Sheets）  
  → **Gmail readonly スコープ追加が必要**（再認可）

## 4. Sheet スキーマ（仕事リスト）

| 列 | 内容 |
|----|------|
| A 受信日時 | ISO / 表示用 |
| B タイトル | |
| C カテゴリ | 推定 or 件名から |
| D 予算帯 | あれば |
| E 締切 | あれば |
| F 案件URL | **重複キー** |
| G 優先度 | 0–100 |

| I ステータス | 新規／Top20／応募済／見送り／期限切れ |

## 6. 統治手帳への見せ方（外務が閲覧）

- **場所**: 「外交／仕事」ビュー近傍に「仕事リスト／本日Top20」リンク＋簡易一覧（読み取り）。主利用者は**外務**  
- **しない**: `won` 以降・請求・発注ステータスとの自動結合（財務フェーズ）  
- **応募したら**: 手で営業パイプラインに1件登録、または Sheet のステータスを「応募済」に更新（Phase 1はSheet更新で足りる）

## 8. 法務・安全（技術メモ → 最終は韓非子）

- ランサーズ**画面スクレイピングはしない**（メール通知のみ）  
- Gmail は **readonly** から開始（削除・送信はしない）  
- 秘密・トークンは `secrets/` と `.env.local`（Git外）  
- 応募行為の自動化（ボット応募）は本設計に含めない（人がTop20を押す）
