# 学習ループ —— 会話から学び、正本を更新する仕組み

> **制定日**: 2026-09-13（BOSS指示「ここでやりとりした全てのchatは、学習してアップデートするように」）
> **主管**: 情報省ダ・ヴィンチ（知識編集）／執行官スマラビ（反映の取りまとめ）
> **上位設計**: `05_情報省/エージェント成長OS.md` §7
> **実行**: デスクトップアプリの定期タスク「【毎日】学習ループ」（毎晩 23:30。アプリが閉じていれば次の起動時に実行）

---

## 1. 全体の流れ

```text
① 取り込む（既存・自動）
   Claude Code のセッション終了 → SessionEnd フック → 図書館 05_AI対話/Claude/
   ChatGPT 等 → 手動取り込み（02_修身省/日次運用/ChatGPT取り込み.md）→ 図書館 05_AI対話/ChatGPT/ など
        ↓
② 抜き出す（新設・自動・毎晩）
   extract_new_turns.py が、前回から増えた会話だけを抜き出す
   （Claude Code は ~/.claude/projects の生記録から。終了していない長い会話も拾える）
        ↓
③ 学ぶ（新設・自動・毎晩）
   定期タスクが 抽出手順.md に従って、決定・訂正・原則・事実・持ち越しを抽出し、
   正本に反映済みかを確かめる
        ↓
④ 振り分ける
   ・反映済み        → ダイジェストに1行
   ・正本の更新が要る → 反映待ち.md に変更案（BOSSの一言で適用）
   ・人格の学び      → 02_修身省/日次運用/成長ボード.md
        ↓
⑤ 使う
   次の会話の冒頭で、反映待ち.md の「未承認」節だけ読む（ダイジェストは求められたとき。CLAUDE.md §0）
   BOSSが「反映して」と言えば、どの人格でも反映待ちを正本へ適用する
```

## 2. 自動でやること／BOSSの承認が要ること

| 自動でやる | 承認が要る |
|---|---|
| 会話の抽出、ダイジェストの作成 | **正本の本文を書き換えること** |
| 反映待ち.md への変更案の追加 | 戦略・価格・LOCKの変更 |
| 成長ボードへの候補の追加 | Skill・人格ファイルの変更（1パッチ原則） |
| 対話ログの記録漏れの補記 | 図書館への知識の確定保存 |

**正本の書き換えを承認制にした理由**：会話からの抽出は読み違えることがある（例：2026-09-13、北斎が「絵本タッチという語は使っていない」と誤って断定した）。誤った抽出が正本に直接入ると、次の会話がその誤りを前提に動く。**変更案として一度BOSSの目を通す**ことで、自動化の速さと正本の正しさを両立する。BOSSが全自動を望む場合は、`抽出手順.md` §6 の一行を変えれば切り替えられる。

## 3. ファイル

| ファイル | 役割 |
|---|---|
| `extract_new_turns.py` | 新しい会話の抜き出し（モデルを使わない決定的処理） |
| `抽出手順.md` | 定期タスクが従う手順（ここを直せば挙動が変わる） |
| `反映待ち.md` | 正本への変更案の一覧。BOSSの承認待ち |
| `ダイジェスト/YYYY-MM-DD.md` | その日に学んだことの記録 |
| `state.json` | どこまで読んだか（git管理外） |
| `_work/` | 抽出の作業場（git管理外・終了時に消える） |

## 4. BOSSの使い方

- **朝**：「反映待ちを見せて」→ 一覧が出る。「全部反映して」「1と3だけ」などと答える
- **すぐ学ばせたいとき**：デスクトップアプリの定期タスク一覧から「今すぐ実行」
- **過去の会話を一気に学ばせたいとき**：「今すぐ実行」を何度か押す（1回あたり約18万字ずつ、古い順に読み進む）

## 5. 学べないもの

- **チャットに貼った画像そのもの**：記録に残らない。参照画像・完成画像は `03_貿易省/文化庁/賢いうさぎ_ビジュアル資産/` などに**ファイルとして保存**すること
- **ChatGPT等の会話**：図書館へ取り込まれるまでは読めない
- 思考の過程（thinking）とツールの出力は抽出しない
