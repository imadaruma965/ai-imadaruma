# agent_growth_os — エージェント知識成長OS

> **目的**: 壁打ち・リサーチの精度を、知識の蓄積とSkill更新で継続的に上げる  
> **主管**: 総理（優先順位）／情報省ダ・ヴィンチ（知識編集・候補整理）／科学省（Skillファイル実装）  
> **正本Knowledge**: ダヴィンチ図書館（Gateway v2）  
> **共通プロトコル**: `.claude/skills/_shared/knowledge_growth.md`

---

## 1. 成長ループ（完成形）

```text
① 起動
   各Skill → knowledge_growth.md
   → MCP search_knowledge（軽量）
   → 人格md + session_log
        ↓
② 対話・調査・判断
        ↓
③ 終了時
   session_log（関係の記憶）
   + 学習候補（knowledge / skill / discard）
        ↓
④ 週次（ダ・ヴィンチ＋総理）
   agent_growth_board.md を棚卸し
   → 承認された knowledge → Vault保存
   → 承認された skill → SKILL.md / 人格md を1パッチ更新
        ↓
⑤ 次回起動で①が賢くなる
```

---

## 2. 三層の記憶

| 層 | 置き場 | 役割 |
|----|--------|------|
| A. 関係記憶 | 各省 `*_session_log.md` | 日をまたぐ会話の続き |
| B. 国家知識 | ダヴィンチ図書館 Vault | 再利用する決定・原理・調査 |
| C. 行動OS | `.claude/skills/*/SKILL.md` と人格md | 起動手順・判断の型 |

精度向上は **Aだけ**では足りない。BとCに昇格させる。

---

## 3. 誰が何をするか

| 役割 | すること | しないこと |
|------|----------|------------|
| 各エージェント | 検索して話す／学習候補を残す | Vaultの無断確定編集、Skillの独断大改修 |
| スマートラビット | 朝にKnowledgeを使い優先順位／成長ボードの未承認を1行見る | 図書館の編集官化 |
| ダ・ヴィンチ | 候補の分類・重複整理・共通原理化の提案 | 戦略・日次実行の独断変更 |
| テスラ | Skillファイルの実装パッチ（承認後） | 知識内容の価値判断の主担当 |
| 君主 | knowledge／skill昇格の最終承認 | — |

---

## 4. Skill更新のルール（1パッチ原則）

承認された skill 候補は次だけを更新してよい。

- 起動時に読むファイルの追加（過多にしない）
- 検索ヒント語
- 禁止事項・確認順序の1〜3行
- 失敗から学んだ「やらないこと」

禁止:

- 人格の全面書き換えを学習候補だけで行うこと
- 新規エージェント人格の追加（別案件）
- 旧名称（AI孫子等）の復活

更新後は `agent_growth_board.md` に「適用済み」と日付を残す。

---

## 5. Knowledge保存のルール

- 正本は Vault。国家OSに原本会話を複製しない
- 入口: Claude Code SessionEnd／`aistock`／MCP `save_ai_log`（Gateway v2）
- ChatGPT／Geminiの発散は、**結論要約だけ**回収
- 月商50万に効かない学習の過剰蓄積をしない

---

## 6. 週次儀式（15分）

金曜または日曜、総理またはダ・ヴィンチ起動時:

1. `agent_growth_board.md` の未承認を開く  
2. 各候補を knowledge / skill / discard に確定  
3. knowledgeは保存手順を実行（または君主に依頼）  
4. skillはパッチ案を出し、承認後に反映  
5. ボードをクリア／アーカイブ行へ
