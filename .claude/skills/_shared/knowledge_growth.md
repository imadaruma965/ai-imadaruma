# エージェント知識参照・成長プロトコル（全Skill共通）

> **正本**: 本ファイル（MCP検索手順の唯一の正本。各SKILL.mdには書かない）
> **上位設計**: `05_情報省/エージェント成長OS.md`
> **Knowledge正本**: ダヴィンチ図書館 Vault（`05_情報省/ダヴィンチ図書館/`／互換 `~/imada-knowledge`）
> **MCP**: `imada-knowledge`（Cursorでは `user-imada-knowledge` になり得る。ツール名は同一）

**このファイルは起動時に読まない。** 下記「検索が必要な条件」に当たったときだけ開く。

---

## 1. 検索が必要な条件（これ以外は検索しない）

- BOSSが「前の続き」「以前決めた」と言った
- ブランド名・価格・憲法・名称・方針変更を扱う
- プロジェクト固有の判断で、過去の意思決定を根拠にする
- 新しい提案が過去方針と衝突しそう
- 本人理解や過去の失敗傾向を根拠にする

雑談・簡易な作業・ローカルファイルで足りる依頼では検索しない。

---

## 2. 手順

1. BOSSの問い／当日のローカル内容から **検索語を自分で作る**（固定の定型クエリ禁止）
2. `search_knowledge` を **1〜2回**、`limit` **5〜8**。`folders` は下記の検索順で狭く始める
3. 必要なヒットだけ `read_knowledge`（行範囲指定を推奨）。全ヒットの全文読込・フォルダwalk禁止
4. 応答で **Knowledge参照元**（相対パス）を明示する

### ツール

| ツール | 用途 |
|---|---|
| `search_knowledge` | 主検索。`query`(必須) `limit`(1–50) `folders`(Vault相対パス配列) |
| `read_knowledge` | 必要ノートだけ。`relative_path`(必須) `start_line`/`end_line` |
| `list_knowledge_areas` | 領域俯瞰のみ |
| `recent_ai_logs` | 最終手段。一覧のみ |
| `save_ai_log` | 使わない（保存は §4 の学習候補経由） |

存在しないツール名（例: `recent_knowledge`）を呼ばない。

### 検索順序

```text
01_意思決定 → 02_国家事業 → 03_国家叡智 → 06_館運営/共通原理 → 05_AI対話（最終手段・limit≤3）
```

### 事実・仮説・廃止

- `01_意思決定` の確定ノートを最優先の事実候補とする
- 「候補」「仮説」「未承認」「approval_required」は事実として断定しない
- 「deprecated」「廃止」「捨てた案」は現在方針として使わない
- 情報が衝突したら新しい方を自動採用せず「要確認」とする
- `05_AI対話` の発言だけで意思決定済みと断定しない

### ヒットなし／MCP障害時

- 「Knowledgeに該当情報なし」または「Knowledge未参照・ローカル限定」と明示し、ローカル正本だけで継続する
- 「以前こう決めた」と推測しない。Vaultをローカルパスで直接全探索しない
- 原本会話を `ai-imadaruma` へ複製保存しない

## 4. 対話終了時の成長（学習候補）

価値があるときだけ、対話ログの通常エントリに続けて追記する（雑談は残さない）。

```text
### 学習候補 YYYY-MM-DD
- 種別: knowledge / skill / discard
- 要約（3行以内）:
- 根拠（何が変わったか）:
- 推奨保存先: （Vault相対 or Skill名）
- 承認: 未 / BOSS / ダ・ヴィンチ
```

| 種別 | 次の一手 |
|------|----------|
| knowledge | Vault保存を提案（勝手に大量保存しない。重複はGateway v2） |
| skill | `02_修身省/日次運用/成長ボード.md` に1行 → 承認後に該当 `SKILL.md`／人格mdを1パッチ更新 |
| discard | 残さない |

書き忘れても **学習ループ（`05_情報省/学習ループ/`）が毎晩会話から拾う**。書ける場合は自分で書くほうが正確。

**Skill本体を独断で大きく書き換えない。** 価値判断の主はダ・ヴィンチ／BOSS、承認後のSkill実装パッチの主はテスラ。

---

## 5. 成長の原則

1. 失敗と成功の両方を短く残す
2. 同じ失敗を二度「初めて」にしない
3. 知識を増やすこと自体より、**11/30月商50万に効く知識**を優先する
4. エージェントは図書館の編集官ではない（編集の主はダ・ヴィンチ／BOSS）
