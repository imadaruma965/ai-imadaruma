# エージェント知識参照・成長プロトコル（全Skill共通）

> **正本**: 本ファイル  
> **上位設計**: `08_情報省/agent_growth_os.md`  
> **Knowledge正本**: ダヴィンチ図書館 Vault（`08_情報省/ダヴィンチ図書館/`／互換 `~/imada-knowledge`）  
> **MCP**: `imada-knowledge`（Cursorでは `user-imada-knowledge` になり得る）

各Skillの起動時に本ファイルを読み、以下を守ること。

---

## 1. 目的

エージェントを「毎回ゼロのチャット」ではなく、**図書館の知識＋自省ログで育つ人材**として運用する。

```text
読む（軽量検索） → 判断・壁打ち → 学習候補を残す →（承認後）Knowledge／Skill更新
```

---

## 2. 起動時のKnowledge参照（必須ルール）

### やる

1. MCP `imada-knowledge` が使えるか確認する。
2. BOSSの今回の問いから **検索語を自分で作る**（固定定型クエリ禁止）。
3. `search_knowledge` を **1〜2回**、`limit` は **5〜8**。
4. 必要なヒットだけ `read_knowledge`（全文Vault読込・フォルダwalk禁止）。
5. 応答のどこかで **Knowledge参照元**（パス）または「未参照・理由」を明示する。

### やらない

- Vault全文の一括読込
- 無関係な雑談での過剰検索
- 他省の主管決定の代行
- KG運用として `save_ai_log` を勝手に連打（保存は下記「学習候補」経由）

### MCP障害時

「Knowledge未参照・ローカル限定」と明示し、人格ファイル＋session_log＋国家OSローカル正本だけで継続する。

## 4. 対話終了時の成長（学習候補）

一区切りで、session_log に通常エントリを書いたうえで、**価値があるときだけ**次を追記する。

```text
### 学習候補 YYYY-MM-DD
- 種別: knowledge / skill / discard
- 要約（3行以内）:
- 根拠（何が変わったか）:
- 推奨保存先: （Vault相対 or Skill名）
- 承認: 未 / BOSS / ダ・ヴィンチ
```

| 種別 | 意味 | 次の一手 |
|------|------|----------|
| knowledge | 再利用すべき決定・原理・調査結論 | Claude Code／`aistock`／MCPで Vault へ（重複はGateway v2） |
| skill | 起動手順・判断基準・禁止事項の改善 | `03_内務省/daily_governance/agent_growth_board.md` に1行 → 承認後に該当 `SKILL.md`／人格mdを更新 |
| discard | 雑談・一度きり | 残さない |

**勝手にSkill本体を大きく書き換えない。** 候補を残し、BOSSまたはダ・ヴィンチ（執行官取りまとめ）の承認後に更新する。

---

## 5. 成長の原則（人材育成と同じ）

1. 失敗と成功の両方を短く残す  
2. 同じ失敗を二度「初めて」にしない（ログとKnowledgeを先に見る）  
3. 知識を増やすこと自体より、**11/30月商50万に効く知識**を優先する  
4. エージェントは図書館の編集官ではない（編集の主はダ・ヴィンチ／BOSS）
